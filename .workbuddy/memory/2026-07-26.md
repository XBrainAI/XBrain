## 移动端灯箱右移/需拖动才显示的 Bug 修复（15:26）
- 现象：手机端点击游记缩略图进灯箱，黑屏且灯箱整体偏到屏幕右侧，要拖动才能看到；PC 端正常满屏
- 根因：JS 在 openGallery / openWaterfall 里设置 `document.body.style.overflow = 'hidden'` 锁背景滚动。iOS Safari 下给 body 设 overflow 会让 position:fixed 的遮罩锚定到 body 盒子（body 因 overflow-x:hidden + 横向溢出被撑宽至大于可视宽度），遮罩内容居中后整体右移
- 修复：移除两处 `body.style.overflow` 切换；改为在遮罩 CSS 上加 `overscroll-behavior: contain; touch-action: none`（遮罩不透明，背景滚动不可见，仍有效阻止手势穿透）；遮罩定位显式用 top/left/right/bottom:0 + width/height:100%；html 加 `overflow-x: hidden` 双保险
- 同类的 waterfall 遮罩（图集）一并修复
- 验证：JS 经 node --check 通过；全文已无 `document.body.style.overflow` 实际切换（仅剩一行注释）
