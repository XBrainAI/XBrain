## 二、XBrain IP 边界界定（"不动 IP"保留清单）

依据 `brand/XBRAIN-LOGO-IP.md`（单一来源）与 `README.md` §四/§六/§九，XBrain IP 的构成与重构红线如下。**本报告所有建议均以"以下要素零变化"为前提：**

| IP 要素 | 权威定义 | 保留要求 |
|---------|---------|---------|
| 品牌 Logo 组件 | `.xbrain-brand` 固定胶囊：毛玻璃 + 渐变边框 + 多层阴影 + 12px 圆角，Cerebro SVG（`xb-ring`/`xb-ttai`/`xb-bar-group`/`xb-decor-group` 全元素）+ `<span>X</span>Brain` 文字 | 视觉与交互逐像素不变；不得简化 SVG、不得胶囊圆角化（已有 S3 门禁守卫） |
| Logo 滚动淡出 | `opacity = 1 - ratio*0.7` + `.scrolled` 切换（rAF 节流、passive 监听） | 行为不变 |
| 色彩体系 | `--xb-deep/-mid/-light/-accent/-accent2/-glow/-border/-text/-text-dim` 九变量（`#0a0a1a` 深底 / `#64b4ff` 品牌蓝） | 色值不变；允许**新增**皮肤层变量（现状已有暖金/冷蓝/玉绿皮肤实践） |
| 字体 | Noto Serif SC（标题）+ Noto Sans SC（正文），Google Fonts | 不变 |
| 圆角层级 | 12px（主容器/Logo）/ 8px（导航/标签/表格）/ 4px（小元素） | 不变 |
| 站点架构语义 | 门户卡片入口、子站独立目录、Logo href 回门户层级规则 | 不变 |

**关键判断**：本评估推荐的重构本质是"**实现方式重构**"而非"视觉重构"——把各页内联的品牌壳（Logo 三段代码、top-nav、淡出/渐入 JS、令牌定义）抽为**共享文件**，产物像素不变，天然满足"不动 IP"。唯一样本外事项：`XBRAIN-LOGO-IP.md` §三规定 Logo 代码"插入各页 `<style>` 内联"，改为共享文件引用后**该 IP 文档的插入条款需相应修订**（视觉零变化，但动了 IP 文档文本）——列为决策点 D3（见 §六）。

## 三、逐类对象评估

### 3.1 门户首页（`index.html`）——品牌基准页，结构健康

- **交互设计**：hero 入场动画（Logo/标题/副题错峰 fadeUp）→ Canvas 神经网络粒子背景（60 节点 + 鼠标斥力，`index.html:824-926`）→ 站点卡 IntersectionObserver 错峰渐入（`:965-980`）→ Logo 滚动淡出。层次与节奏是全站标杆。
- **问题**：
  1. hero 区存在**第三套 Logo SVG 变体**（`hero-logo`，id 前缀 `hero*`，`:561-608`）——与品牌胶囊、卡片 fallback 图共三份近似 SVG 内联在同一文件；
  2. 7 张卡片中 6 张用 fallback 占位图（仅四季景点有真实封面）——门户首页视觉丰富度低，首屏说服力弱；
  3. 卡片网格无任何 aria（卡片是 `<a>` 整包可聚焦，尚可，但无分组语义）；
  4. 密码门体验：auth.css 深色登录卡与主题一致（`index.html:13,984-997`），此项无问题。

### 3.2 频道 Hub 页（5 个 index.html）——三胞胎复制 + 一个异类

- 健康/学习与成长/采购与维护三个 hub 页是**同一份代码的三次内联复制**（Logo CSS ~110 行逐行相同、`.sites-grid`/`.site-card`/`back-link`/`@media 640px` 同构）；生活点点 hub 是"轻量变体"，四季景点 hub 是**功能最强形态**（搜索框、卡片/管理双视图、三组筛选 chips、可排序表格、单列时间线卡片）。
- **评价**：四季景点 hub 的搜索 + 筛选 + 双视图是全站最好的列表交互设计，但它是孤例；其余 hub 是静态卡片网格。hub 形态两极分化（最强 JS 动态 vs 纯静态），中间两个形态（轻量变体、三胞胎）无共享代码。
- **问题**：hub 能力没有沉淀为共享组件；新增频道时只能复制某个 hub 再手改，生活点滴 hub 已出现令牌命名漂移（`--accent` 系 vs `--xb-accent` 系并存，见 §四）。

### 3.3 文章/记录页——规范最完整，偏离也最集中

- **标准形态**：`brand/top-nav-template.html`（§十标准：固定顶栏 + 章节锚点 + 滚动高亮 `setActiveNav` + 移动端汉堡下拉）。游记系（四季景点 11 页 + 生活点滴 12 页 + 高考指南）已广泛采用，共 24 个内容页；`src/` 模板 + `gen_travelogue.py` 保证新页合规。
- **模板机制评价**：`src/README.md` 的"单一来源 + COPY BLOCK 复制 + 改模板要回流"约定设计良好，且 §7 已沉淀深色主题对比度硬规则（文字颜色不透明 hex、分号防吞）——这是很宝贵的工程经验。但**"复制 + 回流"靠人工纪律执行，已经出现失守**：`生活点滴/2026/0816/index.html` 的 style 块落后最新版（0925-0926）**16 行**（3 个新令牌 `--danger/--warn/--success` + 注释未回灌），`0823` 页落后 **123 行**且 md5 不同——模板升级无法自动回灌存量页的直接证据。另注：0816↔0823 之间的 109 行差异主体是**换肤差异**（暖色 vs 冷蓝），属 README 认可的逐站换肤设计特性，不构成违规。
- **偏离样本**（详见 §五问题清单）：
  - `健康/爸/腰椎间盘突出/index.html`（1070 行长文）**完全无章节导航**；
  - `健康/哥/20261003.../index.html` 用自研 sticky 胶囊 toc 且 **Logo 为简化版**（违反 IP 禁令；S3.1 门禁放行原因已查明：其断言只查 `.xbrain-brand`/`.xbrain-text`/`<span>X</span>Brain`/`<svg>` 四个存在性标记，**并无四件套类名断言**——tests/README"SVG 四件套齐全"的描述与实现脱节，须补断言）；
  - `采购与维护/大金空调.../index.html` 用悬浮胶囊 nav-chip（无汉堡、小屏横向滚动）；
  - `采购与维护/家用新风机选购指南-完整版.html` 自研 `.navbar` 体系且 viewport meta **缺右引号**（HTML 解析事故级缺陷）；
  - `学习与成长/纪录片推荐.html` GitHub Dark 主题、系统字体、700px 断点；
  - `四季景点/佛山西樵山.../游记/解惑-探秘-科普.html` 米白纸色主题 + **Logo 整套换玉绿色**（品牌识别被改写，属最重 IP 偏离）。
  - 全站文章页导航共 **5 种形态**（标准 top-nav / hero 内 toc / sticky 胶囊 / 悬浮 nav-chip / navbar+nav-links）。
- **正面资产**：生活点滴记录页的媒体画廊（首图自动解析、图名标题、点击/键盘←→/触摸滑动三式切换、竖屏自适应，`src/README.md` §8）是全站交互完成度最高的组件，且 `0925-0926` 页有全站最好的键盘可达性实践（`tabindex=0` + `aria-label`）——重构时应以它为基准组件。

### 3.4 grade-insight——品牌复用模范，可直接作重构基准

- 原生 JS 零构建 SPA：两视图（报告/录入）+ hash 路由 + 旧六路由别名兼容；`css/style.css:7-27` **全量复用 `--xb-*` 令牌**（并健康扩展 `--up/--down/--warn`、`--radius-*`、字体变量）；ECharts PALETTE 首色手工对齐品牌蓝；移动优先成熟（底部 tabbar + safe-area、44px 触控、`100dvh` 全屏弹层、懒绘制）。近期刚完成三页直线化与仪表盘重构（SPEC-2026-0002、ee19946 等）。
- **小裂口**：`details/**/analysis/*.html` 预渲染解析页为浅色白底独立页面（`pipeline/render-analysis.js` 注入紧凑品牌头），从深色弹层新标签打开发生明暗跳变——但有 S3 门禁约束与"试卷解析属数据工件"的定位，属可接受的白名单项。
- **结论**：本站不需要重构，它是"品牌令牌复用 + 移动优先"的现成范本。

### 3.5 query-system——品牌最孤立站，重构主要对象之一

- React 19 + Vite 8 SPA，技术栈全站最现代（TS、vitest 7 个测试文件、IME 组合输入处理、200ms 防抖搜索）。
- **品牌割裂四连**（均有代码证据）：
  1. **浅色自建主题**：`src/App.css:3-30` 定义 `--primary:#1a365d`/`--accent:#d69e2e`/白底，`src/` 全部样式（App.css/index.css/组件 CSS）中 `--xb-*` 计数为 0（`dist/` 未构建入库，以 src 口径复现）——从深色门户点入即"换了一个世界"；
  2. **品牌胶囊死链**：`query-system/index.html:128` `href="#top"`（页内自锚），App 内 grep 无任何回门户入口——用户进得去出不来（对比 grade-insight 胶囊回 `../index.html` + 设置内"返回门户"按钮）；
  3. 图标语言独立（lucide 矢量 vs grade-insight 的 emoji）；
  4. 弹层体系三套并存（DetailDrawer / MarkdownModal z-index 2000 / SchoolDetailModal z-index 20000 / inline toast）互不统一。
- **移动端**：仅 1024/768 两档"桌面缩小"（表格 11px 字号 + 横向滚动），无底部导航、无 safe-area——与 grade-insight 的移动优先形成代差。
- `demo-scheme-B.html`（38.7KB）是已落地的表头设计稿原型，非现役页面，重构时可归档。

### 3.6 模板与生成器体系——机制的成与败

- **成**：模板单一来源（2026-08-17 从 四季景点/src 提升）、占位令牌参数化（`{{SITE_LABEL}}`/`{{RECORD_HEADING}}`）、`--accent` 换肤三处约定、生成器自动填占位符——设计意图正确。
- **败**：产物是**逐页内联的静态 HTML**，模板升级无法自动传播到已生成页（0816 页实证）；品牌壳三段代码（Logo CSS+SVG+JS ≈10KB/页）随之复制到 56 个文件；令牌在模板系是 `--accent/--text` 系、在 README 规范是 `--xb-*` 系，**两套命名无映射层**，导致 `花都周末家庭游-new` 只能直接覆写 `--xb-accent` 值来实现暖色皮肤（`index.html:28-52`）——品牌变量被皮肤语义劫持。
- **健康/哥 生成页未登记**（README §9.8 只登记了妈），生成线清单不完整。

## 五、问题清单（按严重度分级）

**P0（品牌识别/基础缺陷，重构必解）**

4. 品牌/皮肤令牌无映射层，`--xb-accent` 被皮肤直接覆写（花都-new 实证）

**P1（跨站一致性，重构主战场）**
5. 品牌壳 0 共享、56 文件内联重复（~O(10KB)/页），模板升级无法回灌（0816 落后 16 行、0823 落后 123 行实证）
6. 3 个内容页整页异色主题 + query-system 整站浅色（深色品牌基调断裂）
7. 文章页导航 5 种形态并存；健康长文页（爸/腰椎）无章节导航
8. hub 页三胞胎复制、能力未共享（四季景点的搜索/筛选/双视图是孤例）
9. 移动端断点 5 档漂移；query-system 无移动优先（11px 表格字号线）

**P2（体验增强项，重构顺带或分期）**
10. 可访问性系统性短板：focus 样式、aria 覆盖、低对比文字（有局部最佳实践可移植：生活点滴媒体画廊、Chart canvas role=img）

12. 弹层/toast 体系各站自建（grade-insight modal、query-system 三套）
13. 生成线登记不全（健康/哥 未入 README §9.8）；`demo-scheme-B.html` 历史原型未归档
14. 桌面图表/图标语言不统一（emoji vs 矢量）

## 六、重构路径选项（供裁定）

> 三条路径均以 §二 IP 保留清单为硬约束；差异在**机制投入**与**收益上限**。

### 路径 A：共享品牌层（静态增强，零构建）——**推荐**

**内容**：新建共享资产 `brand/brand.css` + `brand/brand.js`（+ 可选 `brand/tokens.css`）——把 Logo 三段代码、top-nav 三件套、淡出/渐入脚本、双层令牌（`--xb-*` 品牌层 + `--skin-accent` 皮肤层映射）原样抽取为被引用文件；56 个存量页分批把内联块替换为 `<link>/<script>` 引用；`gen_travelogue.py` 等生成器改为产出引用形式；tests/ S3 断言扩展为"内联或引用二选一合规"。query-system 增加深色主题层（`--xb-*` 映射到其 CSS 变量）+ 修复胶囊死链。

- **不动 IP 吗**：视觉零变化（逐字节相同的代码换了放置位置）；需配套修订 `XBRAIN-LOGO-IP.md` §三插入条款（决策点 D3）。
- **收益**：消除 ~500KB+ 重复；品牌壳修改成本 O(56)→O(1)；根治导航/令牌漂移；模板演进可回灌（重跑生成器即更新引用页）。
- **成本量级**：中。共享层建设（小）+ 56 页批量迁移（可脚本化大半，生成线页面重跑生成器）+ 测试更新（小）。
- **风险**：文件协议本地打开（`file://`）与相对路径引用（既有 S2.4 禁根路径规则沿用）；迁移期新旧两式并存需门禁兼容；**风险可控、逐页可回滚**（git 单页还原）。

### 路径 B：轻构建管线（模板化编译）

**内容**：引入 Node 构建步（如 11ty/Astro 或自写脚本），页面以模板+数据形式维护，品牌壳/导航/卡片编译期注入，产物仍是纯静态 HTML。

- **收益**：机制上限最高（组件化、条件皮肤、自动 sitemap 等）；彻底消灭复制。
- **成本量级**：大。新依赖（**C5 → L2，须人工决策**）+ 全站页面结构改造 + README"新增子站极轻"的贡献流程改变 + Netlify 构建链调整。
- **风险**：对当前 61 页规模收益/成本比不佳；8 个站点中 2 个已有独立构建（query-system）再叠一层全局构建增加复杂度。

### 路径 C：最小收敛（只修 P0，不动结构）

**内容**：不建共享层，逐项修 P0/P1 中的品牌违规（Logo 两处、死链、viewport、异色 3 页重写成品牌主题），并扩 tests/ 门禁防回归。

- **收益**：最快消除品牌识别风险。
- **成本量级**：小。
- **风险**：结构性问题（0 共享、56 文件重复）原样保留，下次改品牌壳仍是 O(56)；已被 0816 实证的"回灌失守"会继续发生。

### 推荐组合

**A 为主干，C 作为其第一阶段**：**前置**——先修 S3.1 门禁盲区（补四件套类名断言，否则 P0 修复态无法被门禁锁定，AUDIT-006 回执 D1 附条件）；随后修 P0 品牌违规（顺手把 3 个异色页纳入品牌主题）→ 建 `brand/brand.css/js` 共享层 → 生成线页面先迁移（重跑生成器即可）→ 手写页分批迁移 → query-system 深色化与死链修复 → tests 门禁随阶段扩展。B 不推荐现在做，留作站点规模再上台阶后的远期选项（决策点 D1）。
