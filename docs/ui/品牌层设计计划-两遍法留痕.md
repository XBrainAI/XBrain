## 第一遍 · 设计计划

### 题材 grounding（设计的性格来源）

XBrain 是**一个家庭的记忆与知识档案馆**——健康档案、游记、成长记录、采购研究、成绩分析。受众是家人自己（手机为主），设计的首要职责是让家庭的知识可读、可回访、有归属感。视觉性格 = **"自家的书房"**：深空蓝底（既有品牌色，带蓝相而非纯黑）、衬线中文标题（Noto Serif SC 的书卷气）、Cerebro"家庭大脑"Logo。不是 SaaS 产品页，不用产品话术排版。

### Token 系统

**色彩（三层结构，终结双系并存与皮肤劫持）**

| 层 | 变量 | 取值 | 说明 |
|----|------|------|------|
| 品牌层 | `--xb-deep/-mid/-light/-accent/-accent2/-glow/-border/-text/-text-dim` 九值 | **原值平移，IP 锁定不改** | 深空底 `#0a0a1a`、品牌蓝 `#64b4ff` 等 |
| 皮肤层 | `--skin-accent/-accent2/-glow` | 默认映射品牌蓝；暖金/冷蓝/玉绿按站**只覆写此层** | 花都-new 式"覆写 `--xb-accent`"从此非法 |
| 语义层 | `--xb-danger/-warn/-success` | 深底适配红/琥珀/绿 | 吸收 0925-0926 页既有实践入共享层 |
| 表面层 | `--xb-surface-1/-2/-3` | 卡片/浮层/输入三级 rgba 规范值 | 替代各页随意的 rgba 背景 |

**排印（性格载体，升级重心）**

- 双族既有分工保留：Noto Serif SC = 标题（档案馆书卷气所在），Noto Sans SC = 正文；
- **type scale 规范化**（现状各页字号随意）：`--fs-xs 12 / --fs-sm 13 / --fs-base 16 / --fs-md 18 / --fs-lg 22 / --fs-xl 28 / --fs-2xl 36`——正文基准从现状 ~14.4px 提到 **16px**（手机可读性是本轮升级点），正文行高 1.75，衬线标题行高 1.3、字重 700/900 分级；
- **阅读列宽** `--xb-measure: 42em`（中文 35–45 字/行舒适区，即"行长 <80 字符"的中文实现），长文容器 `max-width: var(--xb-measure)`。

**间距/圆角/阴影/动效**

- 间距 4/8 网格：`--sp-1 4px … --sp-6 32px`（现状 padding 随意值收敛）；
- 圆角语义：`--r-lg 12px / --r-md 8px / --r-sm 4px`（IP 层级原样语义化）；
- 阴影/毛玻璃：胶囊三级阴影原值（IP）；卡片 `--shadow-1/-2`、`--glass-bg/--glass-blur` 规范化；
- 动效：`--dur-fast 160ms / --dur-med 320ms / --dur-slow 600ms`（0.6s 为淡出既有值）、`--ease-out cubic-bezier(.22,1,.36,1)`、`--focus-ring` 可见焦点 token；`prefers-reduced-motion` 全局尊重。

### 布局与原则

- **移动优先**：默认单列、内容边距 16px（≥400px 档 20px）、触控目标 ≥44px；`min-width:640px` 起双栏/宽容器（D5 主断点）；`min-width:768px` 桌面增强档（阅读列宽 + hover 反馈），PC 是增强不是缩放；
- **原则五条**：① 书房而非产品页——衬线标题层级是性格载体，不堆装饰；② 深空有层次——表面三级 + 发光分级，拒绝"黑底一色"的扁平；③ **每页一个编排瞬间**——hero 入场序列是唯一非用户触发动效，其余动效一律回答用户操作；④ 内容即装饰——真实照片与数据代替渐变横幅；⑤ 模板 chrome 禁用清单——无 ALL-CAPS 眉标、无 'WORD — fragment' 标签、链接不加 '→' 后缀。

## 第二遍 · 对照反 AI 化校准清单复查记录

| # | tell（AI 生成页特征） | 本计划状态 | 处置 |
|---|----------------------|-----------|------|
| 1 | 暖米底 + 赤陶强调 | 不适用 | 深底品牌，brief 锁定 |
| 2 | 近黑底 + 单亮酸绿 | **有风险**——`#0a0a1a`+`#64b4ff` 形似"深底单强调" | 色值为 brief 锁定（IP 锚点），按 skill"brief 锁定时 follow exactly"保留；**对冲措施**：表面三级分层 + 皮肤层三色实践（暖金/冷蓝/玉绿）+ 语义色，杜绝扁平单色 |
| 3 | 报纸风 hairline/零圆角 | 不适用 | 12-8-4 圆角为 IP |
| 4 | SaaS 卡片套件（同款卡片+同一阴影） | **共享层责任点** | `brand.css` 的 `.xb-card` 不提供"默认同款"——仅 quiet 基线 + 变体钩子（`.is-accent`），hub/门户卡片差异化留给样板波页面层实现 |
| 5 | 模板 chrome（ALL-CAPS 眉标/中点串/'→' 后缀/mono 小标签） | 禁用清单已入原则⑤ | 复查豁免一处：中文间隔号"·"是标点习惯而非英文 'A · B · C' 模板串，既有页面保留 |
| 动效 tell | 逐卡 fade-up / 全卡 hover 过渡 | 现状门户逐卡 IntersectionObserver 渐入**命中此 tell** | `brand.js` 编排收敛：默认仅 hero 单序列（错峰 fadeUp 一次性编排）；`.xb-reveal` 工具保留但**默认关闭**，页面显式启用并须在样板波评审说明理由 |
| 排印 tell | 标题单词异色/全大写标签 | 不适用 | 中文站天然规避；标题强调走衬线字重分级（900/700）而非变色 |

**复查结论**：两处风险点（tell 2、动效 tell）均有明确对冲/收敛措施，其余为 brief 锁定或不适用——计划通过，进入实现。实现物 = `brand/tokens.css`、`brand/brand.css`、`brand/brand.js`；配套 S3.1 门禁"内联/引用双式合规"判定。

## 使用约定（面向阶段 3/4 迁移波）

1. 页面接入 = `<link rel="stylesheet" href="<相对>/brand/tokens.css">` + `brand.css` + `<script src="<相对>/brand/brand.js" defer></script>`；皮肤站只在皮肤层覆写；
2. 内联品牌壳代码段删除（Logo 三段/top-nav 三件套由共享层提供）；
3. 四件套 SVG 与胶囊 HTML 仍内联于页面（SVG 属页面结构，样式与行为外置）——S3.1 断言对引用式页面检查"引用标记 + 四件套内联"双条件；
4. 本计划的 token 值为唯一权威来源，页面不得绕过 token 写死间距/字号（样板波起抽查）。
