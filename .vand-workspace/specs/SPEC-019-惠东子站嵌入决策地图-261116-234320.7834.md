# 一、Requirements（产品视角 · 意图作者填写）

## 1.1 背景与问题

SPEC-018 已交付两方案选点决策图（`四季景点/惠东周末家庭游/maps/map-plan-{a,b}.{png,svg}`，v3 就近短引注版），但其 §1.7 明确"不修改 index.html（嵌入属后续另立规格）"。现状：子站页面 `四季景点/惠东周末家庭游/index.html` 的「行程方案」节只有文字时间轴，读者无法在页内看到两案/酒店的地理关系。用户已拍板："嵌入index.html"。

相似规格互链（背景证据，不承其范围）：SPEC-018-惠东双方案选点决策图-261116-222114.4315（图件产出规格，本规格消费其交付物）；SPEC-008（全站 UI 规范先例：卡片/断点/触控口径）。

## 1.2 目标用户与场景

页内读者（家庭成员）：读完行程方案文字后，紧接着在页内查看两图并排对比，辅助"选方案、选酒店"决策。

## 1.3 业务价值与成功指标

现状 = 首次观测（2026-11-16）：index.html 无任何地图图件引用。指标：新增「决策地图」节含两张图引用（懒加载、点击看原图、含 SVG 入口）+ 导航可达（桌面/移动两套导航）+ 底图来源与 ≈ 近似点说明；页面其余节零改动。

## 1.4 用户故事

- P0 作为读者，我希望在「行程方案」节之后直接看到 A/B 两张决策图（可点击放大），以便页内完成对比判断。
- P1 作为读者，我希望知道图的数据来源与 ≈ 近似点含义，以便对点位精度有正确预期。

## 1.5 验收标准（可验证）

- AC1（行为型）：Given index.html When 打开后导航点「决策地图」Then 定位到 #maps 节且桌面导航与移动下拉各有一条入口。【验证方式：用户演示 + grep 断言】
- AC2（行为型）：Given #maps 节 When 渲染 Then 方案 A/B 两图均以 `maps/map-plan-{a,b}.png` 引用、`loading="lazy"`，点击可新开原图，且节内含 SVG 矢量版入口与来源说明（高德底图 GCJ-02、POI 三源核实、≈ 近似口径、SPEC-018 编制）。【验证方式：grep 断言 + 浏览器目检】
- AC3（边界型）：Given 窄屏（≤640px）When 查看两图 Then 不溢出横向滚动、按容器宽自适应。【验证方式：浏览器目检】
- AC4（边界型）：Given 页面其余节 When 对比改动前后 Then 除导航新增一项与插入节外零改动。【验证方式：git diff 逐行核对】

## 1.6 体验意图

沿用子站既有卡片语言（section-title/section-desc/info-card/img-credit）；两图在宽屏双列并排、窄屏单列；图内即含图例，节内只补一句来源注记；文案基调同全站（实用、标注来源）。

## 1.7 非目标（本期明确不做）

- 不改 maps/ 图件本身（沿用 SPEC-018 v3 交付物）；
- 不做交互式地图（缩放/图层切换）；
- 不改「行程方案」等既有节的任何内容；
- 不同步更新 惠东周末家庭游方案.md（如需另立）。

# 二、Design（技术视角 · Conductor 填写）

## 2.1 方案概述

纯静态 HTML 插入：① 两套导航（top-nav 与 nav-mobile-dropdown）在「行程方案」后各加 `<a href="#maps">决策地图</a>`；② 在 #plans 节 `</section>` 之后、`<!-- ===== 4. 人文背景` 之前插入 `<section class="section" id="maps">`：section-desc（两案差异一句话+点击说明）→ 双列卡片（复用 .hotel-grid 双列布局，窄屏自动单列）各含方案标题、PNG（lazy、点击新开原图）、SVG 入口与一行动线摘要 → img-credit 来源注记行 → section-backtop。图标用内联 lucide 风格 map SVG，与全站一致（SPEC-008 口径）。

## 2.2 影响面

| 维度 | 改动 |
|------|------|
| 前端/客户端 | index.html：两处导航各 +1 链接；新增 1 个 section（静态引用既有 PNG/SVG） |
| 服务端 | 无改动 |
| 数据模型 | 无改动 |
| 对外接口/第三方 | 无（仅静态资源引用） |
| 安全（鉴权/密钥/数据） | 无 |

## 2.3 数据与接口变更

无。图片资源为 SPEC-018 已入库交付物，路径 `maps/map-plan-{a,b}.{png,svg}`。

## 2.4 安全与合规自检

- [x] 不涉及密钥/凭证进入代码或提示词
- [x] 不涉及数据出境
- [x] 不涉及生产数据操作
- [x] 权限模型无放宽

## 2.5 回滚方案

git revert 本次提交即完全回滚（纯新增、无既有内容修改；导航行删除即还原）。
