# 二、Design（技术视角 · Conductor 填写）

## 2.1 方案概述

**双件交付 + 印章，媒体零依赖**：

1. **`游记/README.md`（内容源）**：`## 出行日期`（2026-10-31）+ `## 简介`（时间线叙事散文，西樵山先例体例，纯文字、0 图片嵌入）。叙事骨架取备考资料 §6.1 行车记录时间轴 + 素材时间戳；科普扩写就地取材备考资料六编条目（古村人文/稻田农事/生境物种/水与寺/植物地理），引用时保留来源口径与降级表述；收尾段可含"素材档案"说明（39 件构成与"待压缩入库"注）。
2. **子站 `index.html` 增量（轻量 #log）**：导航加"游记"项；在"行程方案"章节之后新增 `#log` 文字版游记实录章节——叙事精编自 README（不逐字复制，按页内卡片节奏分段），科普点选 3–5 个做"讲给孩子听"卡片（复用 culture-card 样式），章节内注明图文物料待补；planA 按钮加 §15.2 印章（CSS 追加 `.plan-btn .stamp` 段，HTML 在按钮内插 span）。
3. **门户单字段**：SITES 数组佛冈卡片 `updated: '2026-10-30'` → `'2026-10-31'`。

**写作事实纪律**：全部时间/里程/物种/年代结论以备考资料为准（其来源访问日期 2026-10-31）；素材外的行程空白段（午餐）不做细节虚构，待意图评审确认口径后落笔。

**素材压缩与嵌入（v2 增补）**：

1. **备份**：39 件原档先复制至仓库外备份目录 `D:\data\wy25311753\佛冈游记原档备份\`（一次性人工动作，备份件不入库）。
2. **图片**（34 张相机 jpg + 1 张截屏 jpg）：Pillow 重编码——长边 ≤2048、质量 85、保留 EXIF 方向（含翻转后的像素方向处理）、**删除 GPS IFD**（0x8825）、子采样 4:2:0；截屏 P35 无相机 EXIF，仅做长边压缩。
3. **视频**（4 段 mp4）：ffmpeg 转码——H.264（libx264、yuv420p）、长边 ≤1920（竖屏保竖屏，autorotate 生效）、CRF 23、preset medium、`-map_metadata -1` 剥离容器元数据（含位置类标签）、音频 AAC 复刻。
4. **嵌入**：README 按叙事节点 `![]()` 相对路径嵌图；#log 四卡片补 `.media-cover`/`.media-gallery`（自动继承页内缩略图切换/灯箱/syncOrient），视频 `<video controls>`（先例：深圳子站 14 处/西樵山子站）；图注沿用素材文件名主题词作 alt。
