# 一、Requirements（产品视角 · 意图作者填写）

## 1.1 背景与问题

`四季景点/惠东周末家庭游/index.html`（及同目录 `惠东周末家庭游方案.md`）已细化 2 天 1 夜行程：两方案首日一致（海龟湾 + 双月湾观景台/情人堤），次日二选一——方案 A 自然探索线（盐洲岛黑排角赶海 + 双月湾左湾沙滩/礁石酒吧）、方案 B 文化休闲线（平海古城 + 双月湾沙滩）；酒店推荐 11 家（都喜天丽/豪生/华美达/半岛/后海湾/金海假日/华海/迎光/万科公寓/盐晶/泰丽云顶，分布港口镇、大澳村、蔡家村、新寮村、情人湾、云顶等处）。现状问题：全部信息为文字卡片，**缺少空间视图**——方案 A/B 景点的相对方位、各酒店与景点/路线的地理关系无法一目了然，用户难以综合判断"选哪个方案、选哪家酒店"。

相似规格互链（背景证据，不承其范围）：SPEC-2026-0005（同家庭出行决策类调研，目的地不同）；本仓库无惠东选点图相关既有规格。

## 1.2 目标用户与场景

km 家庭 4 口（2 大 2 小）出行决策者：出发前打开两张图，对照行程卡片与酒店推荐，判断方案 A/B 的路线动线与酒店落点孰优。

## 1.3 业务价值与成功指标

现状 = 首次观测（2026-11-16）：`四季景点/惠东周末家庭游/` 下无任何地图图件。指标：产出 2 张决策图（A/B 各一张），每张同时呈现该方案全部景点（Day1 共同 + Day2 该方案专属）、≥11 家候选酒店位置、按游览顺序的路线轨迹与关键段里程/耗时标注；图例可区分景点/酒店/路线/出发返程。质量标准：地理相对位置与实际相符（底图海岸线/道路为真实地理数据或经核实的坐标），不确定坐标以"近似"注明。

## 1.4 用户故事

- P0 作为出行决策者，我希望在一张图上看全方案 A（或 B）的景点顺序与路线轨迹，以便判断动线是否顺、耗时是否合理。
- P0 作为出行决策者，我希望在图上看到全部候选酒店与景点/路线的空间关系，以便按"近景点·方便活动"口径选酒店。
- P1 作为出行决策者，我希望两图并排可比（同一底图、同一投影、同一酒店图例），以便横向对比两案差异。

## 1.5 验收标准（可验证）

- AC1（行为型）：Given index.html 行程方案节 When 打开方案 A 决策图 Then 共同首日节点（出发、港口镇、海龟湾、大星山观景台/情人堤）与 Day2 A 专属节点（盐洲岛黑排角、双月湾左湾沙滩、礁石酒吧）全部以序号标注且路线按游览顺序连线。【验证方式：用户演示 + 与 index.html 行程表逐项核对】
- AC2（行为型）：Given 第五节酒店推荐 When 打开任一决策图 Then 11 家候选酒店全部落点，且首推（都喜天丽）/同区（豪生）/四星（华美达/半岛）/经济（后海湾/金海假日/华海/迎光/万科）/权衡（盐晶/泰丽云顶）分级图例可辨。【验证方式：用户演示】
- AC3（边界型）：Given 无法精确核实的 POI 坐标 When 落点 Then 以"≈近似定位"样式（如空心/虚线圈）区分精确点，并在图注说明近似口径。【验证方式：事实核证（坐标来源清单）】
- AC4（观测型）：Given 两张决策图 When 并排查看 Then 底图范围、投影、酒店图例一致，仅 Day2 路线与专属景点不同。【验证方式：用户演示】

## 1.6 体验意图

图件为静态 SVG（附 PNG 渲染）：海/陆/道路低饱和底色，景点序号圆标 + 名称，酒店按分级配色方块/圆点，路线为带方向感的实线（Day1）与虚线或另色（Day2），关键段标注里程/耗时；含图例、比例尺、指北针；标题注明方案名。基调：信息密度高但一眼可读，供打印或屏读。

## 1.7 非目标（本期明确不做）

- 不修改 index.html / 方案.md（图件是否嵌入页面属后续另立规格）；
- 不做交互式网页地图（Leaflet 等）；
- 不新增酒店/景点调研（POI 以两文件既有清单为准，仅补坐标核实）；
- 不含潮汐/天气/预约信息（已有专节）。

# 二、Design（技术视角 · Conductor 填写）

## 2.1 方案概述

编制安排：交付物 2 张 SVG（+浏览器渲染导出 PNG 同名副本）落位 `四季景点/惠东周末家庭游/maps/`：`map-plan-a.svg/png`、`map-plan-b.svg/png`。数据来源：底图海岸线/道路取 OpenStreetMap（Overpass API，WGS-84，bbox 覆盖稔平半岛东部 114.78–114.98 / 22.55–22.72）；POI 坐标经 Nominatim/联网检索核实，核实不到的按已知村落/片区近似落点并显式标注。生成脚本为一次性工具不入库（会话临时目录执行），产物为纯矢量 SVG + PNG。关键决策点：① 两图共用同一底图与投影（Web Mercator，等视口），仅叠加层不同；② 路线轨迹为按途经道路手选 via 点的折线（不做逐路几何贴合），段标注取 index.html 行程表既有里程/耗时；③ GCJ-02（若用国内源坐标）转 WGS-84 后落点。
