# 一、Requirements（产品视角 · 意图作者填写）

## 1.1 背景与问题

用户指令（2026-11-25 原话）："将本会话的编制游记相关的经验、用户习惯等沉淀至agents.md"。本会话即 SPEC-025（惠东周末家庭游游记编写与实拍媒体入库，已 delivered）全程：三轮用户验收裁决（时间线瀑布式排布、文件名元素融入文案、七条事实缺陷修正）、媒体管线口径收紧（视频单件 ≤50MB）、原档/备份安全清理、大媒体分块发布。仓库既有沉淀范式（2026-11-01 先例，SPEC-016 轮）：知识正文入 `.vand-workspace/project-context.md` 相应小节，`四季景点/AGENTS.md` 尾部"项目规则·必读索引"指向之；AGENTS.md 头部为范式生成区（勿手改）。互链背景（只作背景、不承其范围）：SPEC-025（经验来源）、SPEC-016（先例固化）。

## 1.2 目标用户与场景

后续"补游记/媒体入库"的 AI 会话开工即读到本轮经验，不再重犯已付学费的错误（旧 100MB 口径、间接互证误判、子串吞组、大包推送被拒、未走安全链删档）。

- **AC1（边界型）**：`project-context.md` §8.1 第 1 步自检口径更新为"无单件视频 >50MB（原 100MB）"并载明降级阶梯（CRF 23→26→28→30→32→34、720p/540p 兜底）。
- **AC2（边界型）**：`project-context.md` 新增 §8.1.1（素材映射与删原档安全链：映射表回写纪律、对账→备份哈希核验→删除三步链、hvc1 误报处置）与 §8.1.2（验收与发布节奏：本地提交不推→用户逐条验收→明确指令才推；大媒体 ≤215MB 分块提交逐块推送）。

- **AC5（边界型）**：提交含 `spec:` 与 `ai-assisted:` 标注；不修改 `.vand/template/` 与 `.vand/ci/`。
