# 一、Requirements（产品视角 · 意图作者填写）

## 1.1 背景与问题

用户指示（2026-11-20 原话："查证最新的天气预报，更新方案中相关部分内容"）。现状：#weather 节为 8 月台风季口径（高温/台风/雷阵雨/避暑排程），实际出行窗口为 2026-11-21/22（方案 C 已选定）；最新预报已核实（中国天气网/中央气象台，11-20 查）：D1 多云到晴 10–21℃ 微风、D2 多云 14–22℃ 微风、沿海平稳，23–25 日新冷空气+转雨。天气节与出行实际脱节，需整节换为出行窗口实况口径；顺带修正贴士节残留的"当前高温黄警"表述。

相似规格互链（背景证据，不承其范围）：SPEC-022（Plan C，其晨温/晨雾句联动微调）、SPEC-023（日落锚定，冬 17:40 口径沿用）。

## 1.2 目标用户与场景

出行前/行程中家人查天气影响与穿衣/风险提示，与 11 月底实际天气一致。

## 1.3 业务价值与成功指标

现状 = 首次观测（2026-11-20）：天气节 0 处提及 11.21–22。指标：#weather 标题/desc/三卡全部换为出行两日实况（含逐段风险表 6 行按 11 月条件重写、24–25 新冷空气展望）；贴士"防暑防晒"卡改秋冬口径；Plan C 晨温句同步；其余节零改动。

## 1.4 用户故事

- P0 作为家人，我希望出发前在页上看到的就是 11.21–22 两天的真实预报与穿衣建议。
- P1 作为家长，我希望知道若行程拖延到 23 日后的天气拐点风险。

## 1.5 验收标准（可验证）

- AC1（行为型）：Given #weather 节 When 渲染 Then 标题为「天气预报与影响评估（11.21–22 出行窗口）」，含两日分区预报（广州/惠东、天气/气温/风）与核实日期来源。【验证方式：grep + 目检】
- AC2（行为型）：Given 逐段风险对照表 When 渲染 Then 6 行均为 11 月条件（晨温/晨雾/日落 17:40/涨潮撤离/23 日转雨提醒），无 8 月台风高温表述残留。【验证方式：grep】
- AC3（边界型）：Given 全页 When 检索"高温黄警/台风季/避暑" Then 天气节与贴士卡无失效口径残留（人文历史叙述中的季节背景词除外）。【验证方式：grep 断言】
- AC4（边界型）：Given Plan C When 查看 Then 06:30 行晨温改"10–11℃"、D2 赶海条含晨凉提示。【验证方式：grep】

## 1.6 体验意图

同节结构原样换内容（标题/desc/三卡），保持卡片语言；预报数值带来源与"出行当日晨再核"提示。

## 1.7 非目标（本期明确不做）

- 不改 hero 标签与海龟繁殖季等背景性叙述；
- 不改 A/B 案内容；
- 不新增预约清单卡（上轮已提供、未获指示）。
