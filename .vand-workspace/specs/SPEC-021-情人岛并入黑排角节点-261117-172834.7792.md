# 一、Requirements（产品视角 · 意图作者填写）

## 1.1 背景与问题

调研确认（2026-11-17，见会话留痕）：黑排角海岸（黄埠镇杨屋村）外有**情人岛**——退潮徒步跨礁石滩可上岛的免费小离岛（约 200m、小沙滩、贝壳赶海）；用户拍板"将黑排角情人岛驿站加到景点方案中"。注意：**"情人岛驿站"实为命名混淆**——"山海十二时辰"12 座驿站中黑排角点位是"黑排角驿站"、爱情主题的是"情人堤驿站"，均处概念方案阶段未开工；故落地物=情人岛玩法并入既有④黑排角节点（零新增停靠点/车程），驿站仅作"未来彩蛋"备注。

相似规格互链（背景证据，不承其范围）：SPEC-018（决策地图，④标注联动）、SPEC-020（一页纸，动线摘要联动）。

## 1.2 目标用户与场景

同本子站全场景：A 案 09:00–12:00 黑排角段升级为"赶海 + 徒步上岛"复合玩法；B 案备选段同步。

## 1.3 业务价值与成功指标

现状 = 首次观测（2026-11-17）：页面与方案 md 的黑排角文案均无情人岛。指标：A 案时间表行/时间轴卡、B 案备选行/卡、景点总览黑排角卡、#maps 节 A 卡摘要、决策地图④标注与面板、方案 md 黑排角处，共 7 处同步提及情人岛（含退潮窗口与涨潮撤离安全口径）；不新增停靠点、不加车程；驿站以"未建成、未来彩蛋"口径备注；图片不入库（版权口径未确认）。

## 1.4 用户故事

- P0 作为 A 案家庭，我希望 09:00 黑排角段明确含"情人岛徒步上岛"玩法与安全边界（涨潮前撤离），以便大孩子获得探索升级且放心执行。
- P1 作为读者，我希望知道"驿站"目前未建成，以便不产生错误期待。

## 1.5 验收标准（可验证）

- AC1（行为型）：Given A 案 Given 09:00 时间表行与时间轴卡 When 渲染 Then 均含「情人岛」与退潮/撤离口径。【验证方式：grep + 目检】
- AC2（行为型）：Given 景点总览黑排角卡 When 渲染 Then 含情人岛介绍（上岛方式/时长/安全）与"驿站未建成（2026-06 征集揭晓，未来彩蛋）"备注。【验证方式：grep + 目检】
- AC3（边界型）：Given B 案备选段（13:30 行与卡）When 渲染 Then 同步提及情人岛且不改变 B 案主体结构。【验证方式：grep】
- AC4（观测型）：Given 决策地图 map-plan-a 与 #maps 节 A 卡 When 查看 Then ④标注/面板含情人岛，坐标与地图产物一致更新（SVG+PNG 双格式）。【验证方式：产物 diff + 目检】

## 1.6 体验意图

文案基调延续：探索感 + 安全边界同屏；情人岛作为④的子玩法呈现（不新增序号⑤⑥位移），字数克制。

## 1.7 非目标（本期明确不做）

- 不新增停靠点/不改动 A/B 案时间结构；
- 不把"驿站"写成已建成设施；
- 图片不入库不嵌入（网络图版权未确认，图库仅留会话预览）；
- 不改酒店相关内容。
