# 一、Requirements（产品视角 · 意图作者填写）

## 1.1 背景与问题

用户需求原话："计划本周六区番禺里仁洞吃拉肠，请搜索分析推荐的早餐店、早餐后附近周边的合适景点，要求休闲、有特色、不同于以往去过的景点，制定候选景点方案"（"区"按上下文判读为"去"）。出行窗口：2026-11-28（周六），家庭四人自驾、一日往返。

现状核验（2026-11-25）：① `四季景点/待出行方案/` 现有 13 份方案文稿，无一份涉及番禺里仁洞或番禺区内景点；② `四季景点/` 下 13 个子站目录无番禺条目（番禺仅以"广东科学中心／南汉二陵博物馆／大刀沙岛已去过未入库"见于项目知识 §11.9）；③ 里仁洞村（番禺南村镇西部，长隆／万博旁）正处旧村改造期（越秀地产，2020 年片区策划通过）——村内早餐店铺的**存续与位置可能已变动**，不能凭旧攻略推荐；④ 距出行仅 3 天，天气只能取临近预报。

要解决的问题：哪几家拉肠店值得专程、店是否还在、早餐后去哪里（休闲、有特色、全家未去过），目前没有一份可圈定的候选对比。

相似规格互链（背景证据，不承其范围）：SPEC-012《清远佛冈秋冬一日行程候选分析》——同交付范式（先候选对比、km 圈定后另轮出完整行程）、同落位 `四季景点/待出行方案/`；SPEC-2026-0005《国庆收官日家庭一日游候选挖掘与行程推荐》——同范式，§11.9 铁律出处之一；SPEC-018《惠东双方案选点决策图》——行程规划调研类 L0 先例。三者目的地与出行窗口均不同，非同一任务，故另立本规格。

## 1.3 目标用户与场景

家庭四人（爸驾车、妈、哥、弟，常住荔湾），2026-11-28（周六）自驾一日往返：清早出发 → 里仁洞吃拉肠早餐 → 附近景点休闲半日 → 午餐 → 午后返程。使用者是做出行决策的 km，出发前在手机或电脑上读稿圈定。**v2 补充（2026-11-25 km 实答）：本次同行有老人**——选点须兼顾步行量、台阶、歇脚与老年票。

## 1.4 业务价值与成功指标

现状 = 首次观测（2026-11-25）：`四季景点/待出行方案/` 与 specs/ 中里仁洞及番禺景点候选方案均为 0 件。指标：交付 1 份候选方案稿，含 ① 早餐店推荐 ≥3 家（主推 1–2 家＋备选）；② 候选景点方案 ≥3 条（各含"为何选／为何不选"与时间闭合骨架）；③ 每条关键事实带来源与访问日期。供 km 圈定后续出完整行程。

# 二、Design（技术视角 · Conductor 填写）

## 2.1 方案概述

交付物为单一 Markdown 文稿，结构沿用 SPEC-012 范式：核心结论 → 去过清单核对 → 早餐店推荐（主推＋备选＋停车／排队提示）→ 候选景点方案对比表 → 分方案要点（时间骨架）→ 景点档案（带来源与访问日期）→ 天气研判 → 坑提醒 → 待 km 圈定事项 → 来源清单。

**调研对象（候选集，AC1／AC2 交叉引用）**：

| 类别 | 点位 | 处置口径 |
|------|------|----------|
| 早餐店 | 里仁洞村内及紧邻片区（锦绣香江／万博／南村）的拉肠、肠粉店 | 核实存续、地址、营业时间、招牌、停车；≥3 家 |
| 主候选景点 | 余荫山房；沙湾古镇；宝墨园（含南粤苑）；紫泥堂；莲花山；大岭村 | 用户确认未去过，进入候选方案 |
| 辅点／备选 | 滴水岩森林公园、三善村鳌山古庙群、番禺博物馆、西坊大院、金山湖公园；梁明诚雕塑园、岭南印象园、深井古村、上漖龙舟基地（后四项去过状态未经确认） | 只作主候选的顺路加项或雨天备选，逐项标注 |
| 排除主推 | 大夫山森林公园、长隆系、海鸥岛、广东科学中心、南汉二陵博物馆、大刀沙岛 | 已去过，仅在"去过清单核对"节列示 |

候选集内点位若核实已闭园／停业／当日不开放，移出推荐并在交付物说明原因；候选集外新发现的更优点位可纳入，但须在 5.2 留痕。

信息获取：官方渠道优先（景区公众号／官网／政务网），检索转述类标注"以官方发布为准"；营业时间 ≥2 源交叉（§13.1）；天气 ≥2 源交叉（§13.8）；距出行 3 天，天气结论标注"临近预报、出发前一日须复核"。

**外部依赖（版本化引用）**：`.vand-workspace/project-context.md`（2026-11-25 版）§11 出行偏好与 §11.9／§11.10 铁律、§13.1 营业时间核实、§13.8 出行前天气核实、"Git 协作约定（2026-11-17）"（会话内提交后直接 push）。

**交付物路径（项目自身目录）**：`四季景点/待出行方案/番禺里仁洞拉肠早餐与周边候选景点方案（2026-11-28）.md`。
