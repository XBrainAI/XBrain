# 一、Requirements（产品视角 · 意图作者填写）

## 1.1 背景与问题

用户指令原话："编制子站"。上下文：2026-11-28（周六）出行走法已定（里仁洞本地肠粉早餐 → 余荫山房 → 七星岗古海岸遗址科学公园 → 紫泥堂午餐与散步 → 返程），完整行程文稿（通用版）已由 SPEC-028 交付；现需把它做成四季景点的攻略型子站页面，并接入门户卡片。

两处现状（仓库核验，2026-11-25）：
- `四季景点/` 下无本次出行的子站目录；`四季景点/index.html` 的 `SITES` 数组无对应条目。
- 待办 **TD-015**（open）规定"下次用 `src/site-template*.html` 建站之前必须先做"：`src/` 三个模板仍是旧媒体形态（封面 16:10 定框＋cover 裁切、网格子项未归零最小宽度、无全屏灯箱），而项目知识 §14.11–§14.13 已把三条规则升级为硬规则。本次建站触发该待办。

相似规格互链（背景证据，不承其范围）：SPEC-028（本次出行的完整行程文稿，本规格消费其内容，不重做行程）；SPEC-013（清远佛冈周末家庭游子站页面——同类型"行程 → 攻略型子站"先例）；SPEC-019（惠东子站嵌入决策地图——L1 子站改动先例，含隔离渲染验收方式）；SPEC-025（惠东游记与媒体入库——§14.11–§14.13 三条规则的来源，佛冈子站为其参考实现）。

## 1.2 用户确认记录（2026-11-25 会话，AskUserQuestion 实答）

- **规格绑定与级别**：实答"另立新规格·L1"——另立本规格，按常规开发处理，实现后由用户验收。

# 二、Design（技术视角 · Conductor 填写）

## 2.1 方案概述

分三步，前一步是后一步的前提：

1. **模板同步（承接 TD-015）**：对 `src/site-template.html`、`src/site-template-travelogue.html`、`src/site-template-travelogue-core.html` 各做三处改动——① 网格子项 `min-width: 0` 兜底；② `.media-cover` 改为 contain 完整显示（§14.12 代码块原样移植，`.img-portrait` 保留）；③ 移植 `四季景点/清远佛冈周末家庭游/index.html` 的 `#lightboxMask` 灯箱三件套（CSS／HTML／JS，宿主选择器含 `.media-block`）。`src/README.md` 的媒体画廊功能表补一行灯箱。改完对三个模板做脚本语法检查与预览页浏览器实测（模板自带的占位图即可）；再做生成器回归——两个生成器靠模板里的固定锚点做替换（如 `'../index.html'`、`id="log"` 节、`<!-- ===== 3. 美食` 等节注释、导航文字），新增的灯箱样式／遮罩层／脚本须插在不触碰这些锚点的位置，并在临时副本目录里各生成一条既有记录比对产物（不动仓库里已生成的页面）。
2. **子站页面**：复制同步后的 `src/site-template.html` 到 `四季景点/余荫山房七星岗紫泥堂一日游/index.html`，按占位符填写。结构取舍：保留速览／总览／行程方案／人文背景／营业时间复核／天气／贴士七节，**删除酒店节与游记、美食两节**及其导航项；行程方案做成可切换的两个方案（A 缺省、B 备选），每个方案含四列行程总表与时间线；景点总览四张卡（早餐店、余荫山房、七星岗、紫泥堂与午餐），每张带开放时间行；七星岗卡与对应时间线节点内嵌媒体组件。内容取自 SPEC-028 交付物。页脚版本号取编制时刻。
3. **配图与门户**：把 `四季景点/待出行方案/实景图/C1–C6` 复制到子站目录 `七星岗古海岸遗址/` 下并压缩（原目录文件不动，它们是历史文稿的配图），其中一张作主图（命名 `index.*`），并另存一张为子站封面 `index.html.jpg`。在 `四季景点/index.html` 的 `SITES` 数组追加一条对象。

验证手段（不引入新依赖）：用本机已装的 Chrome 无头模式——指定窗口尺寸截图供目检；另把页面复制到临时目录并注入一段只读测量脚本（横向溢出、图片显示比例与自然比例、灯箱开关状态），用 `--dump-dom` 读回结果。仓库回归用 `npm run test:repo`。

关键决策点：
- **用规划型模板而非纯游记模板**：页面含方案切换；日后补游记时按"游记跟随已执行方案"的门控接入，不必换骨架。
- **未执行页面不带游记节**：按项目知识 §14.6.1 规则 7，未执行的规划页直接去掉执行标记与游记／美食节。
- **门户卡片状态**：有页面但尚无游记，入口页会显示为"未实现"、出行日期"待补"——这是入口页的既定口径（"已实现"以实际执行为准），出行后补游记时再改。
