# 一、Requirements（产品视角 · 意图作者填写）

## 1.1 背景与问题

高一上学期 10 月月考的分析材料以图片形式存于 `grade-insight/details/高一/上学期/10月/raw/`（各科成绩概览、作答原卷、知识点掌握情况、试卷解析逐页、说明等，按分类命名、试卷解析按序号区分题页）。图片不可全文检索、不可在站内外以文本方式引用与比对。用户要求把 raw 内全部图片解析为**同名** markdown，保存到同目录 `md/`（2026-10-22 会话指令）。

相似规格互链：无（0001–0007 均为功能/行程类规格，不承其范围）。

## 1.2 目标用户与场景

家长/学生本人：在 `md/` 目录按同名文件直接阅读某次月考某题的解析文本，可全文搜索、可被后续成绩分析任务引用。

## 1.3 业务价值与成功指标

raw 图片信息首次转为可检索文本资产。指标：`md/` 内 markdown 与 `raw/` 图片一一对应（同名换后缀），无遗漏、无空文件。

## 1.4 用户故事

- P0 作为家长，我希望每张 raw 图片都有一份同名 markdown 转写，以便按原命名习惯直接查找文本。
- P0 作为家长，我希望转写忠实于图片内容（数字、表格、题干不编造不遗漏），以便文本可作分析依据。
- P0（v2 修订新增）作为家长，我希望题目中出现的图形（几何图、函数曲线、流程/模式图等）从原图截取为独立图片并嵌入对应 markdown，以便读文本时能看到原题配图。

## 1.5 验收标准（可验证）

- **AC1**（行为型）Given raw/ 内每张支持的图片 When 转换完成 Then md/ 存在同名（仅后缀换 .md）文件且非空。验证方式：自动化（脚本比对文件名集合与文件大小）。
- **AC2**（边界型）Given 图片中无法辨认的内容 When 转写 Then 相应位置以"（无法辨认）"标注而非编造。验证方式：抽查人审。
- **AC3**（交付后复核型）样本范围=用户日常使用的 md/ 目录；判定口径=用户阅读任一转换产物发现明显失真时反馈；闭环时点=用户反馈即修订对应 md 并回写 5.2。验证方式：用户复核。
- **AC4**（行为型·v2 修订新增）Given 原图中该题含可见图形 When 处理该题的转写件 Then 图形被截取为独立图片文件存于 `md/images/`，且在 md 正文原题位置以相对路径嵌入；图形边界完整（不切掉图形部分、不大面积混入题干文字）。验证方式：逐文件人审 + 图片文件存在性机器校验。
- **AC5**（边界型·v2 修订新增）Given 无法可靠定位图形边界 When 裁剪 Then 保持原"文字描述配图"方式并在 md 内注明未截取原因，不得截取错误区域充数。验证方式：抽查人审。

## 1.6 体验意图

md/ 与 raw/ 同名对应，打开即读；表格保留结构（markdown 表格），数学公式用 LaTeX 文本，其余尽量保留原文顺序与层级。

## 1.7 非目标（本期明确不做）

- 不改 grade-insight 前端页面、不把 md 接入站点渲染。
- 不删除/移动 raw 原图。
- 不做多月光景的批量推广（本次仅 10 月）。

# 二、Design（技术视角 · Conductor 填写）

## 2.1 方案概述

以多模态读图逐张转写为 markdown。按科目分组委派并行子代理执行（每组独占自己的输出文件，单一写入方）；主控会话收尾做文件名一一对应与非空校验。

v2 修订：配图截取——以 Python/PIL 按坐标裁剪原图图形区域，输出 PNG 至 `md/images/`（命名 `<原图名去后缀>-图<k>.png`），并在对应 md 正文原配图描述处以 `![…](images/…)` 相对路径嵌入。定位方式：执行子代理读原图估算图形边界框 → 裁剪 → 回读裁剪件核验 → 迭代修正；无法可靠定位的按 AC5 保留文字描述并注明。

## 2.2 影响面

仅新增 `grade-insight/details/高一/上学期/10月/md/*.md` 文本文件；不改代码、不改数据接口。→ L1

## 2.3 数据与接口变更

无。

## 2.4 安全与合规自检

转写内容为家庭成员本人考试数据，随项目私有仓库跟踪，与客户/个人敏感数据红线不冲突；不含密钥凭证。

## 2.5 回滚方案

删除 md/ 下本次新增文件即可，无副作用。
