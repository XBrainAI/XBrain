# 一、Requirements（产品视角 · 意图作者填写）

## 1.1 背景与问题

会话中已产出 2026-10-05 家庭一日行程规划（Markdown 底稿位于 `四季景点/待出行方案/`，经四轮评审定稿：方案A 日间版 / 方案B 黄昏提早版·灵山岛尖，含黄金周交通对照与既定裁决）。底稿适合留档，不适合出发当晚在手机上边走边查。用户指示"编写对应子站"——为该行程建立 `四季景点` 子站页面。注意语义：**大岗为办事节点，图书馆为（大岗附近的）南沙区图书馆**，命名须如实区分。

## 1.2 目标用户与场景

家庭成员：出发当晚手机核对准备清单；行程中按决策门应对变化、查场所信息（地址/停车/电话/开放时段）；从四季景点导航进入并返回。

## 1.3 业务价值与成功指标

现状 = 首次观测（2026-10-04）：行程仅有 .md 底稿，无移动友好呈现。指标：页面信息与底稿一致（底稿为内容单一事实源）；一页直线读完；`npm run test:repo` 全绿。

## 1.4 用户故事

- P0 作为全家，我希望在页面上切换查看方案A/方案B 两版时间轴并当日二选一，以便按状态定版。
- P0 作为全家，我希望行程中随时查决策触发器与场所档案，以便不临场找信息。
- P0 作为手机用户，我希望表格在窄屏可读、触控目标够大，以便单手查行程。
- P1 作为访客，我希望从四季景点导航卡片进入并一键返回导航。

## 1.5 验收标准（可验证）

- AC1（行为型）Given 打开页面 When 操作方案区 Then 方案A/方案B 按钮切换对应内容（switchPlan 架构），每版含四列行程总表（出发/到达/项目/耗时，四列填满无空 td）与分岔要点。验证方式：页面脚本探测 + 用户演示。
- AC2（事实核证型）Given 底稿定稿内容 When 逐项对照页面 Then 关键时点（11:15 占座 / 16:55 接人 / 19:30 上车 / 20:10–20:30 到家）、晚饭三层策略、黄金周交通结论与预算（高速免费 ¥0）与底稿一致。验证方式：对照核查。
- AC3（行为型·品牌与导航）Given 任意位置 When 检查 Then 完整 Logo（IP 规范三段、SVG 不可简化）、Logo href=`../index.html` 回四季景点导航、首屏 `id="top"`、底部"返回景点导航"链接、top-nav 锚点与页内 `#` 链接均无死链。验证方式：自动化（S2/S3）+ 浏览器。
- AC4（边界型·移动端）Given 375px 视口 When 逐屏检查 Then viewport 存在且无 `user-scalable=no`、正文 ≥16px、触控目标 ≥44px、宽表格在横向滚动容器内、无 `body.style.overflow` 锁滚动。验证方式：自动化（S3/S4 类）+ DevTools 抽查。
- AC5（行为型·导航接入）Given 四季景点导航页 When 查看 SITES Then 新子站条目出现（未实现态、无封面走 empty 占位），统计/筛选/搜索自动生效，卡片链接指向新子站。验证方式：页面脚本探测。
- AC6（边界型·门禁）`npm run test:repo` 全绿；`<div>`/`</div>` 配平。验证方式：自动化。
- AC7（边界型·图片合规，v5 新增）Given 引入的 4 张实景图 When 检查 Then 均来自小红书真实笔记并按「图注 + 小红书 @作者」署名、相对路径引用、WebP 已转 JPG（长边 ≤1600/q85）、`npm run test:repo` 全绿。验证方式：自动化 + 人工目验。

## 1.6 体验意图

书卷气浅色主题（宣纸米白 + 墨蓝 + 金铜，独立于品牌 --xb-* 变量，仅保留 Logo 品牌底座）；hero 渐变+几何纹样（无照片先例：花都站）；直线阅读顺序：总览 → 方案 → 决策门 → 场所 → 交通 → 预算 → 清单 → 预案 → 来源。

## 1.7 非目标（本期明确不做）

- 不做游记/画廊/灯箱/印章（方案未执行，`.plan-btn` 不打 stamp；出行后另立规格补游记与实拍）。
- ~~不引入任何图片文件（无封面资源，导航卡片走 empty 占位）~~ → **v5 评审解除**：用户指示引入小红书实景图（下载入库+署名集成）。图片红线不变：仅真实拍摄笔记、图注署名、模式 A 命名、相对路径引用。
- 不改门户首页（四季景点卡片已存在）；不接认证（本子站无认证）。
- .md 底稿仍是内容单一事实源，页面不新增决策。

# 二、Design（技术视角 · Conductor 填写）

## 2.1 方案概述

新建 `四季景点/大岗办事南沙图书馆一日游/index.html`（单文件、手写、无构建，遵循四季景点"各景点独立视觉主题"模式）：① 品牌按 `brand/XBRAIN-LOGO-IP.md` 三段整段嵌入（href=`../index.html`）；② 长文导航按 `brand/top-nav-template.html` 三段 COPY BLOCK（桌面横排高亮 + 移动端汉堡下拉，颜色适配本页主题）；③ 方案区按项目 §12.2 多方案切换架构（plan-selector + switchPlan + plan-content）；④ 行程总表按 §12.3 四列规范；⑤ 锚点/返回顶部/in-doc-link 按 §13；⑥ 移动端按 §6.9/§14 铁律。`四季景点/index.html` 的 SITES 数组追加一条（type:'攻略'、无 hasLog → 未实现态、无 cover → empty 占位，updated='2026-10-04'）。

| 服务端/数据模型/对外接口 | 无改动 |
| 安全（鉴权/密钥/数据） | 无改动（本子站不接认证，页面无敏感信息，仅家庭称谓） |

## 2.3 数据与接口变更

无。

## 2.4 安全与合规自检

- ☑ 不涉及密钥/凭证进入代码或提示词

- ☑ 不涉及生产数据操作
- ☑ 不引入图片（无 AI 生成图、无未授权图库风险）

## 2.5 回滚方案

删除新目录 + revert SITES 条目即整体回滚；无数据迁移。
