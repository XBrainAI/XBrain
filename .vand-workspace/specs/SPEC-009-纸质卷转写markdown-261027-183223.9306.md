# 一、Requirements（产品视角 · 意图作者填写）

## 1.1 背景与问题

**现状（已核仓库实际）**：高一上学期 10 月月考新增纸质卷素材，存于 `grade-insight/details/高一/上学期/10月/raw/纸质卷/`，共 **16 份 PDF / 98 页**（语文考卷 8、数学考卷 4 + 答案 4、英语考卷 9 + 答案 4、物理考卷 6 + 答案 4、化学「考卷与答案」7、生物考卷 8 + 答案 4、政治考卷 10 + 答案 6、历史考卷 6 + 答案 8、地理考卷 8 + 答案 2；语文无答案件）。逐份探测确认**全部为纯扫描图像、无文字层**（每页 1 张约 2600×3600 像素图，可提取文本字符数为 0），因此不可全文检索、不可在站内外以文本引用与比对。抽样阅读还确认：**考卷件普遍含学生手写作答与草稿笔迹，且与印刷题干、选项、答题空线直接重叠**（化学第 4 页为典型：手写方程式覆盖在印刷题面之上），答案件为纯印刷体。

用户要求（2026-10-27 会话指令）：解析并提取纸质卷内容，输出 markdown 至 `md.纸质卷/`，**质量要求与既有 `md/` 一致**（内嵌 LaTeX 公式、内嵌纸质卷里的截图配图）；考卷内的手写作答草稿**先去除、还原纯净的试卷本体**。

**绑定裁定（用户 2026-10-27 会话裁定）**：① 本任务**另立新规格**（本件），不挂靠 SPEC-000；② 产出粒度 = **每份 PDF 一个 md**（16 份，与 PDF 同名换后缀）；③ 去手写口径 = **剔除但保留作答痕迹注记**（正文只留印刷体试卷本体，手写作答另立摘录节供追溯）。

相似规格互链（背景证据，不承其范围）：**SPEC-000-月考图片转写markdown-261022-173142.5431**——同轮考试的电子截图（`raw/` 85 张）→ `md/` 转写与配图截取先例，其转写纪律（表格原样、LaTeX、无法辨认标注、配图暗像素定界）与"配图截取"用户故事为本规格直接沿用的工艺基线；但素材源不同（PDF 扫描件 vs 手机截图）、产出目录不同（`md.纸质卷/` vs `md/`）、并新增 SPEC-000 没有的"去手写还原试卷本体 + 手写摘录节"工作项，故按"相似任务不共用规格"另立本规格。

## 1.2 目标用户与场景

家长/学生本人：在 `md.纸质卷/` 按科目直接阅读某科**纯净试卷本体**（题干、选项、答题空、分值结构）与**官方参考答案与评分标准**，可全文搜索、可被后续错题与知识点分析任务引用；读题时能看到原题配图。

## 1.3 业务价值与成功指标

纸质卷（试卷本体 + 官方答案）首次转为可检索文本资产，与 `md/`（平台电子解析）互补形成"原卷题面 ↔ 平台解析 ↔ 官方评分标准"三方对照。指标（首次观测 = 本轮交付）：`md.纸质卷/` 内 markdown 与 16 份 PDF 一一对应（同名换后缀）且非空；配图文件存在且引用全部可达；用户复核发现的失真处数量（基线待本轮观测）。

## 1.4 用户故事

- P0 作为家长，我希望每份纸质卷 PDF 都有一份同名 markdown 转写，以便按 PDF 命名习惯直接查找某科试卷或答案的文本。
- P0 作为家长，我希望转写正文只保留印刷体试卷本体、剔除手写作答与草稿，以便拿到一份干净可复用的原卷。
- P0 作为家长，我希望被剔除的手写作答以摘录形式留在文末注记节，以便需要时仍可追溯我孩子当时怎么答的。
- P0 作为家长，我希望试卷中的图形（几何图、装置图、流程图、坐标图、地图等）从扫描件截取为独立图片并嵌入对应位置，以便读文本时能看到原题配图。
- P1 作为家长，我希望公式与化学方程式一律 LaTeX 表达、表格结构原样保留，以便文本可读且可用于比对分析。

## 1.5 验收标准（可验证）

- **AC1**（行为型）Given `raw/纸质卷/` 内每份 PDF When 转写完成 Then `md.纸质卷/` 存在同名（仅后缀换 `.md`）文件且非空，16 份齐备。验证方式：自动化（脚本比对文件名集合与文件大小）。
- **AC2**（行为型）Given 考卷页含手写作答/草稿笔迹 When 转写该页 Then md 正文（"原卷手写作答（转写摘录）"节以外）只含印刷体试卷本体，不出现手写内容、不把手写笔迹当作题干或选项。验证方式：逐文件人审（与渲染页对照）。
- **AC3**（边界型）Given 手写笔迹与印刷体重叠导致印刷内容无法确认，或手写内容无法辨认 When 转写 Then 相应位置以"（被手写覆盖，无法辨认）"或"（无法辨认）"标注，绝不编造补齐。验证方式：抽查人审 + 存疑清单必交。
- **AC4**（行为型）Given 原页含可见印刷图形 When 处理该页转写件 Then 图形被截取为独立图片存于 `md.纸质卷/images/`，并在 md 正文原题位置以相对路径嵌入；图形边界完整（不切掉图形部分、不大面积混入题干文字）。验证方式：逐文件人审 + 图片文件存在性机器校验。
- **AC5**（边界型）Given 无法可靠定位图形边界，或图形区域被手写笔迹污染且无法规避 When 裁剪 Then 保持文字描述配图并在 md 内注明未截取原因，不得截取错误区域充数。验证方式：抽查人审。
- **AC6**（行为型）Given 一份转写件（考卷或答案） When 交付 Then 卷头信息（学校/学年学期/考试名称/科目/满分与时长若原卷载明）与题号层级、大题分值说明按原样保留；答案件保留"参考答案与评分标准"的分值标注；每页页码以分节标注可回溯到原 PDF 页。验证方式：抽查人审。
- **AC7**（观测型·交付后复核）样本范围 = 用户日常使用的 `md.纸质卷/` 全部产物；判定口径 = 用户阅读任一转写件发现明显失真（漏题、编造、手写混入正文、配图错位）时反馈；闭环时点 = 用户反馈即修订对应 md 并回写 5.2。验证方式：用户复核。
- **AC8**（行为型·v2 修订新增）Given 既有 `md/` 产物内存在学生姓名/班级/学号明文 When 执行脱敏（T10） Then 这些明文全部被替换为统一脱敏占位，且题目文字、分数、表格内容零改动（diff 仅含占位替换行）。验证方式：自动化（扫描无残留明文）+ 抽查人审（逐文件 diff）。

## 1.6 体验意图

`md.纸质卷/` 与 PDF 同名对应，打开即读；题目顺序与原卷一致，表格保留 markdown 结构，公式用 LaTeX 文本，配图原位可见（路径含空格与括号用尖括号目标以兼容通用 Markdown 渲染器）；正文干净到可直接打印作空白卷使用。

## 1.7 非目标（本期明确不做）

- 不改 grade-insight 前端页面、不把 `md.纸质卷/` 接入站点渲染，也不并入 `md/`。
- 不删除/移动/改名 `raw/纸质卷/` 的 PDF。
- （v2 修订前原为"不改写既有 `md/` 产物"；现按用户 2026-10-27 裁定移出非目标——**身份信息脱敏**作为 T10 纳入本规格范围，除脱敏以外的 `md/` 内容仍不改写）
- 不做分数登记（`exam.json`/`acceptance.yaml`/`data.js` 数据接入属其他规格范围）。
- 不给 PDF 回写 OCR 文字层、不做 PDF 优化或压缩。
- 不代做缺失素材（语文答案件不存在，不自行从别处补）。
- 不做其他月份/其他轮次考试的批量推广。

# 二、Design（技术视角 · Conductor 填写）

## 2.1 方案概述

**渲染 → 多模态转写 → 配图裁剪 → 机器校验** 四步，工艺基线沿用 `pipeline/transcribe-prompt.md` v1 的转写纪律（逐字忠实、表格原样、行内 `$…$` LaTeX、无法辨认标注、UI/边缘元素简要记录），在其上追加本规格四条扩展约定（见下"本规格扩展约定"）。

1. **渲染**：PyMuPDF 逐页输出 PNG 至临时目录 `.tmp/zb-render/`（不入库），转写基准 **150 dpi**（实测：页面 595pt 宽 → 1240×1700px，110 dpi 样本已可辨读，150 dpi 为公式与上下标留余量）；配图裁剪按 dpi=300 重渲染目标页后裁剪。
2. **转写**：按科目分 **4 批**委派并行子代理（每子代理独占自己批次的输出文件，单一写入方；执行约定 9，L1 委派）：批1 数学+物理（4 份）、批2 化学+生物（3 份）、批3 政治+历史+地理（5 份）、批4 语文+英语（3 份）。每份 PDF 的 md 按页顺序拼接为单一文件，页边界以 `<!-- 原 PDF 第 n 页 -->` 注释标注。
3. **去手写与摘录节**：正文只转写印刷体；每份**考卷** md 末尾统一附 `## 原卷手写作答（转写摘录）` 节，按题号摘录可辨认的手写内容并声明"非试卷本体，仅供追溯"；答案件无手写则不附该节（或注明"本件未见手写作答"）。
4. **配图**：子代理读页图估算印刷图形边界框 → Python/PIL 裁剪 → 回读裁剪件自检 → 迭代修正；输出 `md.纸质卷/images/<PDF名去后缀>-p<页码>-图<k>.png`，在 md 原题位置嵌入 `![…](<images/…>)`。被手写污染且无法规避的图形按 AC5 处理。
5. **校验与收尾**：脚本核对 PDF↔md 一一对应且非空、md 内图片引用目标全部存在、`images/` 无未引用残留、无临时件泄漏入库；汇总各批"存疑/无法辨认/手写覆盖"清单（AC3 人审入口）；清理 `.tmp/zb-render/`。

**本规格扩展约定**（相对 transcribe-prompt v1 的增补，不改固化件文件——改固化件属工艺变更，另议）：① 源为 PDF 时先拆页渲染、md 与 PDF 同名（非与图片同名）；② 印刷体与手写体必须区分，手写不入正文；③ 手写内容进文末摘录节而非丢弃；④ 配图命名含页码段 `-p<n>-图<k>`。

## 2.2 影响面

|------|------|
| 前端/客户端 | 无改动（不接入站点渲染） |
| 服务端 | 无改动 |

| 对外接口/第三方 | 无改动 |
| 文件资产 | **新增** `grade-insight/details/高一/上学期/10月/md.纸质卷/*.md`（16 份）与 `md.纸质卷/images/*.png`（配图）；临时件仅落 `.tmp/`（不入库） |

## 2.3 数据与接口变更

无。产出为纯新增文本与图片资产，不被任何代码读取，不参与回归断言。

## 2.4 安全与合规自检

- ☑ 不涉及密钥/凭证进入代码或提示词。
- ☑ 不涉及数据出境：素材为家庭成员本人考试试卷，处理在本机 + 当前 IDE 内置允许的模型服务内完成（与 SPEC-000 转写同一通道），不发送至清单外服务。
- ☑ 不涉及生产数据操作、无存量数据迁移。
- ☑ 权限模型无放宽。
- ⚠ 隐私提示（交付时呈报，不代改）：考卷扫描件含姓名/班级/学号明文，转写 md 同样含明文并随私有仓库跟踪；与 SPEC-000 存量口径一致，是否脱敏由用户裁定。

## 2.5 回滚方案

纯新增文件，删除 `md.纸质卷/` 下本次新增的 md 与 images 即完全回滚，无副作用；`.tmp/zb-render/` 为临时件，用完清理。
