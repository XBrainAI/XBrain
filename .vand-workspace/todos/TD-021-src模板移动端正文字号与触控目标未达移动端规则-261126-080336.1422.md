## 背景（为什么记）

项目知识 §6.9 的两条强制项——③触控目标不小于 44×44px、⑤移动端正文不小于 16px——对所有新页面生效；而 `src` 模板系页面在 390×844 下两项都未达，且是全站一致的既有状态。SPEC-029 只在新子站页面里用页内补充样式补了触控目标，模板没改（不在该规格范围），所以下一个用模板建的页面还会原样复刻。

## 要做什么

① 三个模板把移动端（≤640px）正文提到不小于 16px（现 `.82rem`＝13.12px、`.78rem`＝12.48px、`.9rem`＝14.4px）。
② 把移动端触控目标补到 44×44：下拉菜单项（现高 33px）、「← 返回」链接（35px）、「返回顶部」（36px）、页脚入口（20px）、正文行内链接热区（19–43px）、品牌标识链接（36px；属品牌组件，改前先核 §6.3 与品牌层回归用例）。写法可参考 `四季景点/余荫山房七星岗紫泥堂一日游/index.html` 样式里「本页补充：触控目标不小于 44px」一段（内边距外扩热区、负外边距抵消占位，截图逐像素一致）。
③ 改完重跑生成器回归与 `npm run test:repo`，并抽两个存量页面实测。
字号调整会改变全站版面节奏，属设计决策：动模板前先请用户定夺是否全站统一。

## 完成口径

三个模板在 390×844 下正文不小于 16px、全部可点元素不小于 44×44（全量探针口径：对页面内全部 `a`／`button`／`[onclick]` 逐一量，分默认与菜单展开两种状态）；生成器回归通过；`npm run test:repo` 全过。
