## 背景（为什么记）

`src/README.md` §7.2–§7.3 与项目知识"约束与陷阱"明令：`--text`／`--text-dim`／`--text-hint` 必须用不透明 hex（正确值 `#ffffff`／`#f0f3f8`／`#c8d0dc`），且 `.section-desc`／`.food-card p`／`.tips-box li`／`.info-card p` 等正文段落必须用 `var(--text)`。但 `src/site-template.html` 及由它派生的全部页面（余荫山房一日游、佛冈、惠东等）仍是 `--text-dim: rgba(200,210,230,0.62)`、`--text-hint: rgba(…,0.35)`，正文也用了 `--text-dim`。**规则早已存在，模板从未同步。**

SPEC-032 建延吉子站时实测（CDP 精确视口、计算与背景的 WCAG 对比度）：正文段落修改前 4.9–5.4:1（刚过 AA 线、偏暗）；**`.spot-hours`（开放时间与票价行，用 `--text-hint`）仅 2.49:1**，远低于 4.5:1——而这是读者最需要看清的信息。延吉页已用页内样式覆盖修正（全页最低 11.63:1），但那是单页补丁，其余模板系页面问题照旧；按范围纪律未动模板，故登记。

## 要做什么

在 `src/` 三个模板里把文字颜色规则同步进去：① `:root` 的三个文字令牌改为不透明 hex；② README §7.3 点名的正文选择器（`.section-desc`／`.info-card p, li`／`.food-card p`／`.tips-box li`／`.hero-quick span`，建议一并覆盖 `.spot-card-body p`、`.culture-card p, li`、`.timeline-content p`、`.plan-summary-table tbody td`、`.spot-hours`）改用 `var(--text)`；`--text-dim`／`--text-hint` 只留给真正的次要标注（页脚、图注等）。写法可直接取延吉页"本页补充：文字颜色改为不透明"一段。

动模板前请用户定夺：这会改变全站模板系页面的观感（已发布页面重新生成后才生效），属设计决策，建议与 TD-021、TD-022 合并处理、一次回归。存量已生成页面是否回迁，与 TD-026 同一性质，一并裁定。

## 完成口径

三个模板的文字令牌为不透明 hex、正文选择器用 `var(--text)`；生成器回归通过；抽两个模板系页面在 390 宽实测，正文与 `.spot-hours` 的对比度均不低于 4.5:1；`npm run test:repo` 全过；延吉页里对应的页内覆盖样式随之删除（避免两处重复）。
