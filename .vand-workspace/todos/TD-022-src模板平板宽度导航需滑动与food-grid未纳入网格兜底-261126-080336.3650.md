## 背景（为什么记）

SPEC-029 实测发现模板的两处样式缺口，都不在该规格的媒体三件套范围内，未改。

## 要做什么

① 平板宽度的顶部导航：导航 9 项时内容宽约 666px，加上左侧留白，视口不到约 820px 就放不下；641–819px 区间既不切换汉堡菜单（断点是 640px）也放不下横排，只能靠 `.nav-inner` 的隐藏滚动条左右滑（768px 下末项只露出一个字，可发现性差）。可选修法：把汉堡菜单断点提到约 820px，或压缩导航项内边距；导航项更多的既有页面阈值更高。
② `.food-grid`：项目知识 §14.11 的兜底写法只列了 `.info-grid`、`.spots-grid`、`.culture-grid`，模板里的 `.food-grid` 不在其中——美食卡若内嵌画廊缩略条，同样会被撑出视口。本次按规则原文移植，未扩大范围；修的时候把 `.food-grid` 纳入模板兜底规则，并同步修订 §14.11 的规则写法。

## 完成口径

三个模板在 641–819px 各宽度下导航项完整可见或改用汉堡菜单（逐宽度实测）；`.food-grid > * { min-width: 0 }` 进模板且 §14.11 规则同步；生成器回归与 `npm run test:repo` 通过。
