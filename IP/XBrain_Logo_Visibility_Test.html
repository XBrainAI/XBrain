各方案改动点汇总

方案 0（当前）：容器 border 0.25 + SVG圆环 stroke-width 2 / opacity 0.55
方案 D（容器增强）：仅增强容器（边框 0.50 + 发光 + 背景微提亮），SVG保持不变
方案 F（圆环+圆圈）：SVG外圆环 stroke-width 2→4 + opacity 0.55→0.95；中心圆外圈加粗 + X线加粗 + 核心圆点放大
方案 G（T台+主体）：T形主体结构 fill 从 #2a4080→#4a70c0 提亮；装饰线 opacity 拉满；侧边条提亮并增强
方案 H（SVG全局增强）：综合 F + G，同时给整个 SVG 加 drop-shadow 发光，图标整体更醒目
