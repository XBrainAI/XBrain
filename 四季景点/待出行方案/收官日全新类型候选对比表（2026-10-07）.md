### B（强候选）药洲遗址（九曜园）

| 项目 | 信息 |
|------|------|
| 地址 | **越秀区教育路 86 号**（南方剧院北侧，紧邻北京路商圈） |
| 开放 | **24 小时全年开放**（也有资料写 9:00–17:30；现场为准） |
| 票价 | **免费、无需预约** |
| 车程 | 从西村 ≈ 25–35 min（老城区停车难，**建议地铁**：1/2 号线公园前站 D 口步行 200m） |

**它是什么**
- 五代南汉乾亨三年（**919 年**），南汉开国皇帝**刘䶮**凿天然池沼为"西湖"（仙湖），湖中建洲，炼丹求仙药，故名**药洲**，又名**九曜园**。
- 园中湖体史称长约 **1600 m**、总面积 **10 hm²**；水北接白云山文溪，东接沙澳流入珠江，**当时可通船只**。
- 是**岭南现存最早的古代园林地面遗迹**（另一表述为"中国现存最早皇家园林地面遗迹"）。
- 1989 年公布为广东省重点文物保护单位。**"药洲春晓"曾是羊城八景之一**。
- 现存占地仅 1400 余 m²（一个篮球场大小），但布局精巧。

**看什么**
- **九曜石**：原九块，今存**八块**，相传刘䶮自太湖采运奇石，依天上星宿布列。每块具"瘦、漏、透、皱"园林石美感。
  - **米芾题"药洲"石**：宋代书家米芾题刻"药洲"二字，清代曾被移走，20 世纪 50 年代迁回原位。
  - **仙掌石**：刻米芾诗作 + 明人关鹏题"仙掌"。
  - **九曜第一石**：形似鳌鱼，1988 年维修时升高约 2 m，底部有明嘉靖年间题刻"此即九曜第一石也"，另有清代**翁方纲**篆书"拜石"、隶书"龙窟"题刻。
- **碑刻**：近百种历代碑刻，涵盖篆隶楷行草；**北宋米芾题"藥洲"牌匾及《九曜石》五言绝句**，堪称岭南最珍贵石刻。
- 270 余年大榕树遮天，古池养睡莲。

**为何是新类型**：这是**地面上直接踩着的千年现场**，不是搬进展柜的文物。家里有"古村古镇"（看的是明清民居）、有"展馆参观"（看的是玻璃柜里的文物），但**没有"城市考古"这一类**——脚下就是 1100 年前的皇家园林。

### C 七星岗古海岸遗址科学公园

| 项目 | 信息 |
|------|------|
| 地址 | **海珠区石榴岗路 67 号** |
| 开放 | **9:00–17:00，逢周二闭园**（10-07 周三**正常开放**） |
| 票价 | **免费** |
| 车程 | 从西村 ≈ 35–45 min |

**它是什么**
- **1937 年由地理学家吴尚时发现**，2026 年是发现 **80 周年**（公园内有发现八十周年纪念亭与吴尚时教授塑像）。
- 分布有**海蚀崖、海蚀平台、海蚀洞**典型海蚀地貌，**是世界公认最深入内陆的古海岸遗址**——距今海岸 **100 公里以上**，突破了此前"世界古海岸线与当前海岸线最大距离 50 公里"的公认说法。
- 保留了海蚀地貌与堆积性海岸地貌（海积地貌）**一整套完整、特征典型的古海岸地貌系统**，见证广州附近**沧海桑田**与现代珠江三角洲的形成演变。
- 2015 年启动建设（一期 2017-05 竣工、二期 2020-06 全面开园），**2018-07-01 正式对外开放**，海珠区政府与国土规划部门牵头，拨款 1 亿元分三期建设。
- 2026-05 第16 个"中国旅游日"全国主会场活动上，被海珠区列为**"绿美新坐标"**之一。

**游园路线**：核心区入口广场 → 古海岸遗址 → 登山径 → 纪念亭 → 地学文化径 → 正门广场 → 二期赏花休闲区

**附加**：马路对面即**廉洁文化公园**（草坪野餐 + 竹林小径 + 廉政文化长廊），两园相距 20 m。

**为何是新类型**：**地质考古**——家里所有景点都是人文或风景，没有一处能回答"广州这块地从海上变过来要多久"。**这是能带进学校地理课的东西**。

### D 建筑模型博物馆广州馆

| 项目 | 信息 |
|------|------|
| 地址 | **白云区黄边三横路一街 1 号 广州设计之都设计殿堂 3F** |
| 开放 | **周三至周日 10:00–17:00（16:30 停止入场），周一、周二闭馆**（10-07 周三**正常开放**） |
| 票价 | **免费，但需提前预约** |
| 预约 | 关注"建筑模型博物馆"微信公众号 →"我要预约"→选广州馆；**每日限流 800 人**，建议提前 1–2 天 |
| 车程 | 从西村 ≈ 30–40 min（白云黄边，近家） |

**看点**
- **岭南主题展区**：镬耳屋、围屋模型 + 复古布景，**一秒穿越岭南古村落**。
- **光影回廊**：阳光透过玻璃洒入。
- **地标模型区**：站在恢弘地标建筑模型前，"掌心里的世界地标"。
- **场馆中庭**：现代极简设计 + 艺术装置。
- 建议参观时长 1.5–2 h。馆内无餐饮区，周边有文创园与咖啡店。

**为何是新类型**：**建筑模型**是一种全新观察尺度——把 normally 仰视的地标压缩到掌心。对 15 岁的空间理解与美术训练有直接作用。
