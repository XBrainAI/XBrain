## 一、为什么这样排（三条硬理由）

1. **A 有展期硬约束**：科博会**仅 9/24–10/08**，10-08 之后不再有→ **必须放在 Day 1 或 Day 2**，不能拖。
2. **10-10 是调休补班日**：国庆挪动补班，**10-10（周六）要上班**→ 因此 C 放10-10 只能安排"**下班后 + 傍晚**"或干脆改期；10-11（周日）才是完整周末 → **F 片区（最需要慢逛的）放 10-11**。
3. **三个模块的节奏需求本就不同**：
   - A 是**深度型**（1.7 万㎡、400余件展品，3h 才逛得透）；
   - C 是**讲解型**（1.12 公顷但要讲地质史，60min 刚好）；
   - F 是**散步型**（四站步行串联，最怕赶）。
   分开三天，每天都能按自己的节奏走。

## 四、Day 2（10-10 周六）C 地球史 · 七星岗古海岸遗址

> ⚠️ **10-10 是国庆调休补班日，需上班。** 本模块设计为"**上班前/早下班后**"或"**午休溜出来**"两种用法；若当天要上班，**建议改到 10-11 之后**（见 §7）。

| 开放 | **9:00–17:00，逢周二闭园** → 10-10 周六**正常开放** |
| 票价 | **免费** |
| 规模 | 1.12 公顷 |
| 停留 | **60–90 分钟**（园内慢走+讲解） |
| 联系 | 020-89440241 |

**行程表（按"早到"版）**

| 时间 | 安排 |
|------|------|
| 08:30 | 西村出发（≈40min） |
| **09:10–09:30** | 抵七星岗（开门即入，人少） |
| 09:30–10:00 | 入口**科普碑刻**（建立"这里是地球史"的认知） |
| 10:00–10:30 | **古海岸遗址**：海蚀崖 / 海蚀平台 / 海蚀洞 |
| 10:30–11:00 | 登山径→ **纪念亭 + 吴尚时塑像** |
| 11:00–11:30 | **地学文化径** |
| 11:30–12:00 | 二期赏花休闲区；对面**廉洁文化公园**（可选） |
| 12:00 | 附近午餐 |
| **12:30** | 返程 |

**60–90 分钟怎么用（这是本模块的灵魂）**

分三段讲给哥弟：
1. **先看碑刻**——先建立"这里是研究地球史的地方"；
2. **走到海蚀崖前，讲一句话**：**这里离现在的海岸 100 公里——脚下这块地，几万年前是海**。
   - **海蚀崖**：海浪长期侵蚀形成的陡崖（今天的海蚀崖都在退缩）
   - **海蚀平台**：海蚀崖后退后留下的平坦岩床
   - **海蚀洞**：海浪掏蚀出的洞穴
3. **纪念亭讲科学史**——1937 年吴尚时在同一块地上发现了改写教科书的东西，**这是给 15 岁孩子最好的科学史样本**。

**为什么值得单独占一天**：这不只是"看风景"，而是**一次可带进学校地理课/科学课的内容**。

**⚠️ 看过实景图后的判断修正（2026-10-06 补充）**

看完官方航拍与遗址实拍后，修正两点此前判断：

1. **纪念亭内"三宝"是此前完全没查到的惊喜** —— 亭内有三方大师手迹碑：**商承祚**（金石大师）题"古海遗迹"四字碑、**曾昭璇**（地质学泰斗）撰写的遗址铭文与示意图碑、**秦咢生**（篆刻书法大师）制作的石碑。**这是现场才能看到的文物级看点**，务必进亭看。
2. **60–90 分钟的预算是合理的，不算赶** —— 园区实为 1.11 万㎡（6409㎡ 核心区 + 4745㎡ 二期），另有登山径与科普长廊。

但也要如实说：从航拍可见**园区周边就是密集城市街区，整体观感偏城市小公园，不会很"壮观"**。它的价值全在"懂"不在"看"——**对15 岁孩子是优点（可带进地理课），对纯观光偏好是缺点**。如果家里对"看风景"期待高，建议压缩到 40 分钟只走核心三样（碑刻 → 海蚀崖 → 纪念亭）。

实景图见 `实景图/`目录与 `ACF实景图集与搜图说明.md`。

## 五、Day 3（10-11 周日）F 千年遗址 · 北京路片区四站

> **本模块是最需要慢逛的一组**，所以放在完整周末。所有四站步行可达，自由度高。

| 站点 | 地址 | 开放 | 时长 |
|------|------|------|------|
| **F1 南越国木构水闸** | 越秀区西湖路 63号光明广场负一层 | **周六日/节假日 12:00–18:00**（工作日 14:00–18:00） | 40 min |
| **B 药洲遗址** | 越秀区教育路 86 号 | 周二至周日 9:00–17:30（周一闭园） | 50 min |
| **F2 千年古道 + 拱北楼** | 越秀区北京路步行街中段 | **全天开放** | 25 min |
| **F3 西城门瓮城** | 荔湾区中山七路富邦大厦东侧约 90m | 09:00–21:00 | 35 min |

**行程表**

| 时间 | 安排 |
|------|------|
| 09:00 | 西村出发（老城区停车困难 → 见 §6停车策略） |
| 10:00–10:40 | **F1 南越国木构水闸**：地下展厅，2200 年木构水利工程 |
| 10:50–11:40 | **B 药洲遗址**：南汉皇家园林，米芾题"药洲"石 |
| 11:40–12:10 | **F2 千年古道 + 拱北楼**：街道玻璃罩下五朝 11 层路面 |
| 12:10–13:30 | 午餐（北京路一带老字号：陶陶居、莲香楼一带） |
| 13:30–14:30 | **午休/咖啡**（正午热，避晒） |
| 14:30–15:10 | **F3 西城门瓮城**：明代城墙残垣，就立在西村旁 |
| **15:10** | 返程 |
| **15:30 前** | 到家 |

**四站看点（按时间线讲给哥弟）**

- **F1 水闸（2200 年前）**：西汉南越国时期的水利枢纽，2000 年施工时发现，2006 年列入**全国重点文物保护单位**。完整保存闸室/进水渠/出水渠。**2200 年前广州人就用木结构防珠江潮水**。
- **B 药洲（919 年）**：南汉皇帝刘䶮的私人药园。**米芾题"药洲"石**、清代翁方纲"拜石"、近百种历代碑刻、遮光碑廊。
- **F2 千年古道（南汉—明清）**：2002 年抢救性发掘，**自南汉以来五朝 11 层路面 + 宋代拱北楼基址**，玻璃罩在步行街正中央。
- **F3 瓮城（1380 年）**：明洪武十三年永嘉侯朱亮祖建城所设，**广州迄今唯一保存较好的明代瓮城遗址**。平面呈 H 形、残高 3.7m。

**看点一句话**：**广州从海退出来的那天（几万年）到南汉皇帝的药园（919）到明代的城墙（1380），全都在步行 2 公里范围内。**

> **F3 开放状态提醒**：有本地居民称瓮城"围蔽十余年后已重新开放"，但**无官方公告佐证**。若现场仍在围挡外，**顺路看一眼即走**，不影响主行程。

**停车策略**：四站全在**地铁 1 号线公园前站/ 6 号线北京路站步行 ≤500m** 范围。**建议**：车停**光明广场地下/周边停车场**，四站全程步行+地铁。若自驾车停西门口附近，F3 就在西村旁。
