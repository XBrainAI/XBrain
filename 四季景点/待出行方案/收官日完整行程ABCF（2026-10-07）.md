## 四、C 七星岗古海岸遗址（★本日重点之一· 海珠石榴岗）

### 为什么把它列为重点

家里所有景点都是人文或风景，**没有一处能回答"广州这块地从海上变过来要多久"**。这一站是能带进学校地理课的内容——而且它的学术价值被明确写进了官方叙述。

| 项目 | 信息 |
|------|------|
| 地址 | **海珠区石榴岗路 67 号** |
| 开放 | **9:00–17:00，逢周二闭园** → 10-07 周三**正常开放** |
| 票价 | **免费** |
| 规模 | 占地 **1.12 公顷** |
| 停留 | **60 分钟**（比常规多留 20min，用于讲地质与看碑刻） |
| 联系 | 020-89440241 |

### 它的学术分量（本段核心）

- **1937 年由地理学家吴尚时发现**，**2026 年正好是发现八十周年**（园内有发现八十周年纪念亭与吴尚时教授塑像）。
- 分布有**海蚀崖、海蚀平台、海蚀洞**典型海蚀地貌。
- **世界公认最深入内陆的古海岸遗址**——距今海岸 **100 公里以上**，**突破了此前"世界古海岸线与当前海岸线最大距离 50 公里"的公认说法**。
- 保留海蚀地貌与堆积性海岸地貌（海积地貌）**一整套完整、特征典型的古海岸地貌系统**，见证广州附近**沧海桑田**与现代珠江三角洲的形成与演变。
- **这项发现直接改写过教科书**——发现之前，学界以意大利距海50 公里的内陆古海岸为世界纪录。

### 建设沿革（哥弟会问"为什么这里能进公园"）

- 2015 年海珠区政府与市国土规划部门牵头启动建设，**拨款 1 亿元分三期**；
- 一期 2017-05 竣工；
- **2018-07-01 正式对外开放**；
- 二期 2020-06 完工。
- 2026-05 第 16 个"中国旅游日"全国主会场活动上，被海珠区列为**"绿美新坐标"**之一。

### 60 分钟怎么用

**游园路线**（官方推荐，全程约 40 分钟，余 20 分钟用于碑刻与讲解）
核心区入口广场 → 古海岸遗址 → 登山径 → 纪念亭 → **地学文化径** → 正门广场 → 二期赏花休闲区

**分三段讲给哥弟（这一站的教育价值全在这里）**
1. **入口先看科普碑刻**（"带娃研学涨知识必备"）——先建立"这里是地球史"的认知；
2. **走到海蚀崖前，讲一句话**：这里离现在的海岸 100 公里——**脚下这块地，几万年前是海**。
   - **海蚀崖**：海浪长期侵蚀形成的陡崖（今天的海蚀崖都在退缩）；
   - **海蚀平台**：海蚀崖后退后留下的平坦岩床；
   - **海蚀洞**：海浪掏蚀出的洞穴。
3. **纪念亭 + 吴尚时塑像**——讲"一个人在同一块地上发现了改变教科书的东西"，这是给 15 岁孩子最好的科学史样本。

**附加（可选，时间有余再进）**：马路对面即**廉洁文化公园**（草坪野餐 + 竹林小径 + 廉政文化长廊），两园相距 20 m。**本日行程紧，不建议加。**

### F1 南越国木构水闸遗址（光明广场负一层）

| 项目 | 信息 |
|------|------|
| 地址 | **越秀区西湖路 63 号 光明广场地下一层** |
| 开放 | **周一至周五 14:00–18:00；周六/周日/节假日 12:00–18:00** → **10-07 周三属工作日 → 14:00 才开** |
| 票价 | **免费、无需预约** |
| 停留 | 40 分钟（地下展厅，避晒凉爽） |
| 交通 | 地铁 1 号线公园前站 / 6 号线北京路站，步行约 5min |

**它是什么**
- 建于**西汉南越国时期（约公元前 203 年—公元前 111 年）**，是南越国都城番禺城南城墙的水利设施，**距今 2200 多年**。
- **2000 年**光明广场施工时意外发现，经抢救性发掘确认为南越国时期大型水利工程。
- **2006 年国务院公布为全国重点文物保护单位**，同年入选《中国世界文化遗产预备名单》。
- 功能：**抵御珠江潮水倒灌、排走城内积水**。遗址**完整保存了闸室、进水渠、出水渠**的遗迹，透过玻璃防护可见历经岁月的古老木构件。
- 展厅完整梳理**遗址发掘、保护、古广州水系**的故事。

**看点一句话**：这是中国现存**发现最早、规模最大、保存最完整的木构水闸遗址**——2200 年前广州人就用木结构做水利工程了。

> ⚠️ **硬约束**：周三 14:00 才开门。本行程 **14:20 到场，刚开门人最少**，这个时间点反而是优势。

### B 药洲遗址（教育路 86 号）

| 项目 | 信息 |
|------|------|
| 地址 | **越秀区教育路 86 号**（南方剧院北侧，紧邻北京路商圈） |
| 开放 | **周二至周日 9:00–17:30，周一闭馆** → 10-07 周三**在开放日**（15:00 到场充裕）；另有源写 10:00–17:00、16:30 停止领票，**以现场为准** |
| 票价 | **免费、无需预约** |
| 停留 | 50 分钟 |

**它是什么**
- 五代南汉乾亨三年（**919 年**），南汉开国皇帝**刘䶮**凿天然池沼为"西湖"（仙湖），湖中建洲，炼丹求仙药得名**药洲**，又名**九曜园**。
- 园中湖体史称长约 **1600 m**、总面积 **10 hm²**；水北接白云山文溪，东接沙澳流入珠江，**当时可通船只**。
- 是**岭南现存最早的古代园林地面遗迹**（另一表述为"中国现存最早皇家园林地面遗迹"）。
- **1989 年公布为广东省重点文物保护单位**；**"药洲春晓"曾是羊城八景之一**。
- 现存占地仅 1400 余 m²（约一个篮球场），但布局精巧。

**必看三样**
1. **米题"药洲"石**：宋代金石书家**米芾**题刻"药洲"二字；清代曾被移走，**20 世纪 50 年代迁回原位**。
2. **九曜第一石**：形似鳌鱼，1988 年维修时升高约 2m；底部有**明嘉靖年间**题刻"此即九曜第一石也"，另有清代**翁方纲**篆书"拜石"、隶书"龙窟"题刻。
3. **碑廊**：近百种历代碑刻，涵盖篆隶楷行草；**北宋米芾题"藥洲"牌匾及《九曜石》五言绝句**，堪称岭南最珍贵的石刻。**碑廊完全遮光**——避晒+读史的组合。

另有**仙掌石**（刻米芾诗作 + 明人关鹏题"仙掌"）、270 余年大榕树、古池睡莲锦鲤。米芾、翁方纲、阮元、苏东坡、陈澧等历代名士都曾在此留下题刻。

**时段优势**：官方提示避正午 12–15 点（园内无空调、露天部分暴晒）。**15:00 后进场正好避开**，且斜阳入池、奇石倒影最出片。

**顺路加餐（步行 3 分钟）**：**黎雪珍凉茶**（老字号草本凉茶，与"药洲古时种药炼丹"呼应）。时间紧可省。

### F2 千年古道遗址 + 千年古楼（拱北楼）遗址

| 开放 | **全天开放** |

**千年古道有多古**
- **2002 年 7 月**北京路步行街整饰工程路面开挖时，出土大量砂岩石条与古城墙砖。
- 经两个多月抢救性挖掘，**掘出自南汉以来共五朝 11 层的路面**和**宋代拱北楼基址**。
- 有关部门决定用**玻璃钢罩覆盖**其上向市民展示——**所以它就躺在步行街正中间，逛街时低头就能看到**。
- 被称为北京路步行街的"**镇街之宝**"。可以对比历代修路的特色与材料。

**千年古楼（拱北楼）遗址**
- 宋代拱北楼基址，就在千年古道旁（<100m）。
- 2026 年 10 月有展览以"千年古楼"为名列入北京路商圈六大千年遗址。

**看点一句话**：**唐宋元明清五朝十一层路面叠在一起，用玻璃罩罩在步行街正中央**——这是全国极少数能把"时间压成薄薄一层"直接踩在脚下的地方。

### F3 西城门瓮城遗址（回程顺路 · 荔湾中山七路）

| 项目 | 信息 |
|------|------|
| 地址 | **荔湾区中山七路富邦大厦东侧约 90m**（西门口地铁站 C 口直行约 50m） |
| 开放 | **全年 09:00–21:00**（围蔽十余年后**近期已重新对外开放**，以现场为准） |
| 票价 | **免费** |
| 停留 | 35 分钟 |
| 距离 | **就在西村旁**，回程几乎不绕路 |

**它是什么**
- **明洪武十三年（1380 年）**，永嘉侯**朱亮祖**扩建广州城时设"正西门"，此即其瓮城遗址。
- 1996 年广州市文物考古研究所发现并首次发掘，**1998 年第二次发掘**。
- **广州迄今发现的唯一保存较好的明代瓮城遗址**。
- 平面呈"**H**"形：**现存东西残长 18.45m、南北宽 18.15m、基址残高 3.7m**；**城垣以红砂岩条石包边、墙芯以黄褐色土夯实**。
- **2010 年**荔湾区政府斥资 390 多万元对遗址南段整饰，改造为人文绿化景点；**2020 年 9 月**文物部门启动瓮城遗址保护利用工程（本体修缮、环境整治及数字化展示）。
- **2023 年 1 月**入选《广州市地名保护名录（第一批）》。
- 2020 年金花街辖内西门口一带完成敬梓里文创社区改造。
- **2025 年 5 月**西门口社区围绕"明城墙文物保护"开展"世界博物馆日"主题宣传。

**周边同在一条街上**（可顺路一眼）：光孝寺（**全国重点文物保护单位**，存南朝洗钵泉、唐代瘗发塔）、六榕寺、怀圣寺、五仙观、宝生大押。

**看点一句话**：**广州仅存的一座明代瓮城，六百年城墙残垣就立在闹市中央**——而且是**刚刚重新开放**的，几乎没有游客。

> **提示**：有当地居民提到"围蔽了十几年的瓮城遗址悄悄对外开放了"，但**开放状态与时段建议现场确认**（可留意现场围挡与告示）。

## 十、人文背景补充（§11.6，看之前先懂）

- **药洲（919 年）**：南汉高祖刘䶮凿湖种药炼丹。北宋时成士大夫避暑吟咏胜地（**米芾、阮元、苏东坡**都来过），明清转为广州文教中心，**"药洲春晓"曾是羊城八景**。
- **七星岗（约几万年前）**：1937 年吴尚时发现时，学界公认的世界记录是"古海岸最多离海 50 公里"；七星岗离今海岸 100 公里以上，**把上限翻了一倍**。**2026 年是发现 80 周年**。
- **南越国水闸（西汉，约公元前 203–111 年）**：都城番禺城南城墙的水利枢纽，2000 年施工时发现，2006 年列入**全国重点文物保护单位**并入选《中国世界文化遗产预备名单》。
- **千年古道**：2002 年北京路整饰工程抢救性发掘，**自南汉以来五朝 11 层路面 + 宋代拱北楼基址**。
- **西城门瓮城（1380 年）**：明洪武十三年永嘉侯朱亮祖扩建广州城时设正西门；**广州迄今发现唯一保存较好的明代瓮城遗址**。
- **国防装备**：99A 坦克、歼-20、辽宁舰——**国家工业能力的上限展示**，且这次难得地允许上手。
