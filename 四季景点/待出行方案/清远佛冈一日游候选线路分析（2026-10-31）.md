> 路线锚点：**上岳古村 + 观音山王山寺**（两处均未实地去过）

## 一、核心结论

1. **天气**：两天都是"夏末体感"——10-31（六）晴 21~30℃、11-01（日）多云 23~29℃，均无雨可出行；**周六略优**（周日珠三角中南部有分散小雨可能）。11-02 起有一股弱冷空气降温，本周末是降温前"热尾巴"。
2. **重大利好**：**王山寺自 2026-05-01 起免门票开放**（8月版按 ¥35–50/人估算，现按 0 元），上岳古村本就免费 → **两大锚点 0 门票**，全家一日总花费约 **¥500–550**（油费+过路费+午餐）。
3. **主推 线路A（观音山上午 → 上岳古村下午）**：30℃+ 的"避正午暴晒"逻辑依然成立，爬山放在最凉时段；**线路B（上岳上午 → 观音山下午）** 摄影更优、末段回程更近。
4. **田野绿世界红枫最佳期为 11 月底–元旦**，本周末枫未红、营业状态待确认 → 本周末不排，留作 12 月红枫季伏笔。

## 四、候选线路对比（同一条环线，两个方向）

```
广州西村
  │  广连/京港澳高速 → 佛冈出口 → S292 英佛公路    ≈ 80 km / 1.5 h
  ▼
观音山王山寺（石角镇）── S292 → S252 南下 ≈ 33 km / 41 min ── 上岳古村（龙山镇）
  ▲                                                          │
  └────────── 汕湛高速 → 广连高速 ≈ 93 km / 1.3 h ────────────┘
```

总里程约 **206 km**，纯驾驶约 4 小时（静态估算，以当日导航为准）。

| 维度 | 线路A · 经典避晒版（顺时针） | 线路B · 摄影优化版（逆时针） |
|------|------------------------------|------------------------------|
| 顺序 | 观音山（上午）→ 龙山午餐 → 上岳古村（下午） | 上岳古村（晨光）→ 午餐 → 观音山（下午） |
| 优势 | 爬山放在一天最凉时段；8月版验证过的节奏；王山寺 08:30 开门即入 | 古村晨光斜射、人少出片；末段观音山→西村仅 80 km，回程轻松 |
| 劣势 | 下午 14 点古村仍热（巷弄有荫、风水塘边可纳凉） | 午后 13:30 进山体感偏热（全程森林荫蔽，可走平缓段） |
| 适合 | 带老人小孩、按表推进不折腾 | 想拍照出片、返程想早收尾 |
| 免票后人流 | 王山寺早到即避峰 | 上岳上午人最少 |

> 两线途经相同、仅顺序对调，临场可按当天状态互换，无需纠结太多。

## 七、景点档案（核实于 2026-10-30）

### 上岳古村（免费 · 全天开放）
- **位置/导航**：佛冈县龙山镇上岳村；导航搜「上岳古村游客中心」。停车说法两源不一（有源称游客中心免费停车，亦有源称无正式游客中心、村中空地停车）→ **待现场确认**，到村口问村民即知。
- **看点**：720 余年南宋古村，朱熹后裔（朱文焕一脉）聚居地；现存明清民居 37 幢 108 座，28 座镬耳楼完好；归仁里上中下三组、朴山/朝瑞朱公祠、五龙过脊、五龙过阶、古井、风水塘；"象棋之乡"。0 商业化、原生态。
- **游玩**：1.5–2.5 h，平缓好走；村道窄开车慢行；**部分无人居住老宅有局部坍塌，勿贸然进入**；村内无餐馆和商店，零食饮水自带。

### 观音山王山寺（2026-05-01 起免门票 · 08:30–17:00）
- **位置**：佛冈县石角镇英佛公路（S292）旁，距广州约 80 km；电话 0763-4882088。
- **免票说明**：2026-05-01 起免门票开放（景区公众号信源，携程票价"0 元起"旁证）→ 若现场仍设票口，以现场公告为准（兜底预算 ¥35–50/人）。
- **看点**：整座山体天然形似仰卧观音；王山寺（明代三面十二臂观音、汉白玉观音等古造像，千年菩提树）、瀑布群/龙潭、原始森林氧吧（华南高负离子区）。
- **游玩**：1–3 h；寺+湖边栈道平缓段适合全家，登顶非必需。
- **⚠️ 导航坑**：必须搜全名「**观音山王山寺风景区**」——附近另有「佛冈观音山风景区」，**那里没有王山寺**，别走错。

## 九、坑提醒

1. **热**：30℃+、体感 32℃，防晒帽/水/驱蚊按夏天备；山里**严禁火种**（森林火险橙色预警生效中）。
2. **导航坑**：王山寺要搜全名「观音山王山寺风景区」，别走到对面的「佛冈观音山风景区」。
3. **吃**：上岳村内无餐馆，午餐锁定龙山镇或佛冈县城；周末热门农庄可先电话订位。
4. **人流**：王山寺免票后周六人流可能上升 → 08:30 开门即入；上岳上午人最少。
5. **落雨预案**：周日珠三角中南部有分散小雨可能 → 优先周六；若周日遇雨，顺延至 **11-08 周末**（冷空气过境后才是真·入秋体感，行程要素不变）。
6. **免票政策**为景区公众号单一信源+OTA旁证 → 门口若收票以现场为准（预算已留兜底）。
