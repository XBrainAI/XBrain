# 广州花都石头记矿物园 · 资讯汇总

---

## 一、概述

石头记矿物园（Istone Mineral Park），全称"广州石头记矿物园"，位于广东省广州市花都区珠宝城大观园路1号，是**世界首座以宝石矿物为主题的主题乐园**，国家AAAA级旅游景区。园区以奇石、化石、宝石为主题，集科普教育、休闲购物、观光旅游为一体，被誉为"地下世界的缩影"和"活着的矿物百科全书"。

| 基本档案 | |
|----------|------|
| **名称** | 石头记矿物园（Istone Mineral Park） |
| **地址** | 广州市花都区珠宝城大观园路1号 |
| **开园时间** | 2009年8月 |
| **占地面积** | 约70亩（主建筑面积17,777平方米） |
| **景区级别** | 国家AAAA级旅游景区 |
| **投资方** | 石头记珠宝有限公司 |
| **投资额** | 超过1亿元人民币 |
| **创始人** | 苏木卿（中国台湾） |
| **主题定位** | 世界首座以宝石矿物为主题的游乐园 |

## 二、地理信息

### 2.1 区位概况

石头记矿物园坐落于广州市花都区新华街，地处**花都珠宝小镇**（花都珠宝城）核心区域。花都区位于广州市北部，珠江三角洲北缘，属亚热带季风气候区，气候温暖湿润，四季分明。

### 2.2 交通指南

#### 公共交通

| 方式 | 路线 |
|------|------|
| **地铁** | 广州地铁9号线至"花都广场站"，换乘公交或打车约15分钟 |
| **公交** | 花都区9路、21路公交车至"石头记站"下车 |

#### 自驾路线

| 路线 | 走向 |
|------|------|
| **路线一** | 广清高速公路 → 赤坭或新华出口 → 风神大道右转至红棉大道 → 直行至迎宾大道左转到底 → 右转约300米到达 |
| **路线二** | 机场高速公路 → 太成出口 → 沿迎宾大道直行到底（约15公里）→ 右转300米到达 |

> 园区设有免费停车位，自驾便利。

### 2.3 周边环境

矿物园位于花都珠宝小镇内，周边汇集七大主题园区（石头记园、矿物园、曼古园、普贺园、玉石园、水晶园、珠宝公园），以及20座珍宝展览馆和印象珠宝剧场，形成了完整的珠宝文化旅游生态圈。

## 三、历史沿革

### 3.1 花都珠宝产业起源

| 时间 | 事件 |
|------|------|
| **2001年** | 首家珠宝企业引进花都区，珠宝产业正式起步 |
| **2004年** | 中国珠宝首饰业驰名品牌"石头记"入驻园区 |
| **2007年** | 石头记获得"中国驰名商标"认证 |
| **2009年8月** | 石头记矿物园正式开园 |

### 3.2 建设缘起

- **灵感来源**：2006年，创始人苏木卿前往奥地利参观施华洛世奇的"水晶世界"，深受震撼，决定在东方创建一个属于中国人的"石头世界"。
- **建设规模**：苏木卿表示，石头记矿物园的规模是施华洛世奇水晶世界的**五倍**，且融入了中华传统文化，内容更为丰富。
- **设计构思**：整座矿物园的设计和构思均由苏木卿亲自完成。
- **投资规模**：由石头记珠宝有限公司投资超过1亿元人民币兴建。

### 3.3 产业转型

花都珠宝小镇经历了从"生产制造集群"向"商贸旅游集群"的重大转型，走出一条"**生产+创意**"的特色发展之路。"工厂变景区、车间变展厅、生产线变观光线"，成为中国珠宝文化产业与工业旅游融合发展的典型范例。

## 四、园区结构与特色

园区分为 **地上石雕公园（芝麻开门）** 与 **地下矿石博览馆（神秘宝藏）** 两大板块。

### 4.1 地上 · 芝麻开门（石雕公园）

| 项目 | 详情 |
|------|------|
| **开放时间** | 9:00 - 21:00 |
| **门票** | **免费** |
| **特色** | 露天公园，绿草如茵，奇石遍布，花草树木与奇石、化石、玉石相映成趣 |

**标志景观**：

- **91颗石球金字塔**：主体建筑前有91颗石球垒成的金字塔，每颗石球重1.5吨、直径100厘米，象征"九九归一，通向永恒"
- **禾雀花长廊**：种植禾雀花（花期3-5月），春季尤为美丽
- **五星级宝石卫生间**：采用大量宝石元素装饰，被誉为"最奢华的公共卫生间"
- **矿物主题雕塑花园**：用真实矿石雕刻的艺术装置，将地质科学与美学完美融合

### 4.2 地下 · 神秘宝藏（奇石世界）

| 项目 | 详情 |
|------|------|
| **开放时间** | 9:00 - 18:00（16:30后停止售票） |
| **建筑面积** | 17,777 平方米 |
| **展品数量** | 10,000余件（矿物品种超2,000种） |
| **展陈方式** | 现代化展陈，大量运用3D互动投影系统及数字展览技术 |

**十大主题展区**：

1. **时空隧道** — 两侧陈列与地壳运动有关的岩石矿物，包含蓝铜矿、石胆、宝石地球仪
2. **流星石** — 展示来自外太空的陨石，地球外的礼物
3. **古代森林** — 硅化木等远古树木化石，距今1亿年以上
4. **古代生灵** — 鹦鹉螺化石、贵州龙化石（2亿年前）、恐龙蛋化石、中华震旦角石等
5. **夜明珠** — 直径近1米、重达2吨的萤石夜明珠，关灯后可见发光奇景
6. **满汉全席** — 四大桌石头盛宴，冠绝古今
7. **海洋之梦** — 水晶帆船、珊瑚展品、骨雕
8. **晶体矿石** — 紫水晶、黄晶、发晶球、白水晶球等
9. **水晶观音** — 世界最大天然水晶观音，镇馆之宝
10. **通灵宝玉** — 《红楼梦》主题展区，含金陵十二钗石雕

## 五、三大镇馆之宝

| 排序 | 名称 | 详情 |
|:----:|------|------|
| **1** | **水晶观音** | 高180厘米，重1.5吨，清澈通透度达90%以上。由高级水晶工艺名师历经三年雕琢而成，世上仅此一件，极具观赏和收藏价值，被公认为"世界最大天然水晶观音" |
| **2** | **满汉全席（石宴大全）** | 石头记历经数十年收集天然"食"材，由上百名能工巧匠三年多创作。共四大桌，包括农家风味、山珍、海味、小吃等。除包子有雕刻外，烧饼、皮蛋、绿豆等均为全天然无雕饰的石头。被誉为"世界第一冠绝古今的石宴大全" |
| **3** | **海洋之梦·水晶船** | 帆船上所有帆布由天然白水晶和施华洛世奇水晶串成，晶莹剔透，工艺卓绝 |

## 七、人文故事

### 7.1 创始人：苏木卿

| 项目 | 详情 |
|------|------|
| **出生** | 1956年，中国台湾彰化 |
| **从业** | 从事玉石珠宝行业超过30年 |
| **信仰** | 佛教，深受佛家"慈悲心"影响 |
| **现任** | 石头记品牌创始人、石头记矿物园创办人、石头记珠宝有限公司董事长；花都文化产业促进会常务副会长、花都旅游协会常务副会长 |

#### 《红楼梦》情缘

- 19岁在台湾当兵时，花一年时间认真读完《红楼梦》
- 20年后，这本书对他的人生产生了巨大影响
- 自认"很像贾宝玉"——"别人都把他看作宝贝，但他自己却把自己当作一个'浊物'"
- **品牌命名**："石头记"商标名称直接来源于《红楼梦》

#### 创业历程

| 时间 | 里程碑 |
|------|--------|
| 1990年 | 来到大陆投资饰品行业 |
| 1997年 | 注册"石头记"商标 |
| 1998年 | 提出经典广告词"世上仅此一件，今生与你结缘"，掀起加盟与销售热潮 |
| 至今 | 在全国拥有超过1200家专卖店，成为珠宝玉石界首屈一指的商业化品牌 |

- **首家专卖店**：开设在素有"石头城"之称的南京市
- **战略转型**：原本主要做外销，南京店成功后转型内销，大力开拓大陆市场

#### 核心金句

> "石头从品性来讲，不卑不亢、无声无息，虽然低调简单，可是它的品质最坚硬、内涵最丰富，这正是石头的魅力所在。"

> "石头很像佛，既与世无争又包容万物，而且每一个石头都记录着一段历史，一块块石头仿佛都在默默诉说着一段段故事。"

> "一个石头一个故事。"

> "石头记的文化底蕴是中国的，我要把石头记做成留名青史、永垂不朽的中国品牌，给中国人脸上增光。"

### 7.2 慈善事业

- 2012年加入慈济慈善事业基金会，在助学、助贫、救灾等方面出钱出力
- 理念："我们把石头最美丽灿烂的一面挖掘出来，吸引消费者来购买，当我们挣了钱之后，就想到怎么回馈社会"

### 7.3 品牌理念

- **品牌灵魂**：文化创意是石头记的核心竞争力
- **产品理念**："一个石头一个故事"——任何化石、宝石的形成都经历了上千万年甚至更久远的时间，承载了地球的信息和历史的记忆
- **文创解读**：在产品中加入文化元素、精神元素，使得产品独一无二、不可复制，让消费者既能得到物质享受、也能得到精神享受

### 7.4 文化内涵

矿物园不仅是旅游景区，更是**中国玉石文化的立体展示平台**。园区融合了：
- 地质科学（矿物形成原理、分类体系、莫氏硬度）
- 古生物学（化石、古生物遗迹）
- 宝石学（宝石鉴赏、选购知识）
- 宗教文化（佛教石雕、禅室）
- 文学经典（《红楼梦》通灵宝玉、金陵十二钗）
- 传统饮食（满汉全席石头宴）

6. **适合人群**：亲子家庭、矿物爱好者、摄影打卡、研学旅行、地质科普

### 9.7 最佳游览时间

- **全年适宜**：地下展馆不受天气影响
- **春季（3-5月）**：禾雀花盛开，地上公园景色最美
- **建议游玩时长**：2-3小时（若连带工业园参观则半天）
