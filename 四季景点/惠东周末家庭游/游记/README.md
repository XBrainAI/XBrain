## 简介

11/21–11/22，把 Plan C——A 线首日＋H10 盐晶酒店＋平海古城——从纸面走成实景。D1 的主角是海龟湾：从入口的山坡到滨海栈道的云海、巨石阵与海龟馆，午后在港口市场落座一顿海鲜午餐，傍晚入住情人湾畔的盐晶酒店——金色落日里划皮划艇、全家自拍，夜里在酒店「魔法季」的驻场歌声与满空泡泡间玩到二十点半。D2 从 06:09 的日出开场：360 观景台、海边栈道的「浪与石」、沙滩拾贝，午后傅记海鲜与平海古城收官，14:48 启程返航、17:26 到家——比计划提前近两小时，躲开了周日返程高峰。

## Day 1 · 11-21（周六）：海龟湾的一天，从晨光到明月

### 07:37 · 沙埔服务区与去程晨光

晨光把 713 的车厢镀成金色。后排的弟戴着耳机、举着望远镜——他把去程当成了侦察任务；天窗外一整片鱼鳞云「高高挂」在蓝得发亮的天上。07:37 沙埔服务区，早餐是出发的仪式：两天的海，从这一口热食开始。

### 09:48–11:54 · 海龟湾：山坡、栈道与海龟

09:48，海龟湾。入口在山脚下，坡度不讲情面，兄弟妈先在坡道上留了影，713 也和保护区标志牌郑重合了影。这里是广东惠东海龟国家级自然保护区——中国大陆唯一的海龟产卵场（栈道 10:31 那张，远处中线处就是海龟产卵地，一句注脚把这片海的来处讲给路人听）；入口那尊「破壳龟」雕塑先上了一课：每只大海龟，都是从一个小小的破壳瞬间出发的。

10:02 起踏上滨海栈道：松针落了一路（10:33），10:40 一片云海压在海平线上，像天河开了道口子；11:03–11:04 悬崖礁石与沧海礁石，11:08 巨石阵到了——兄弟俩与爸在石缝间攀上爬下，把地质时间当成了游乐场（微信批次里还有他们攀岩的沙与背影）。

11:25 海龟馆：兄弟俩贴着展缸看海龟游过，科普展板前也站了许久（弟 10:06 就先在科普点入了迷）；百龟园里大大小小的龟晒着太阳，视频里的大海龟划水、伸头，慢悠悠得像时间在海底也放了假。

11:42–11:54 石滩收官：弟即兴演了一段「醉酒」（假装的，他自己先笑场），又学「鸡公」翘起弯弯的尾；爸往沙滩上一站，摆出服装广告的架势——全家都爱哥伦比亚的衣裳，「哥伦比沙」是只有自家人秒懂的梗。11:54 弟捡起一颗松果郑重收好——大人收藏门票，孩子收藏松果。离园前的小卖部（购物）也逛了一圈，满载而归。
