### 从化吕田狮象岩 copy.html 移动端显示修复
- **问题诊断**：通过 WorkBuddy 分享链接后，本地图片路径无法在服务器端解析（PTitle.jpg 及所有本地 JPG），导致大量图片裂开；backdrop-filter + position:fixed 在某些国产浏览器（微信/QQ X5内核）引起渲染白屏；HTTP 混合内容被移动端浏览器拦截
- **修复措施**：
  - 所有本地图片添加 `onerror` 回退机制，裂开时显示带 alt 文本的彩色占位块
  - 脚本自动检测未加载的本地图片并生成占位提示
  - Hero 背景添加 `#2a3a1e` 纯色回退色，图片加载失败时仍有深色背景
  - 移动端彻底禁用 `backdrop-filter`（用 `!important` 确保覆盖）
  - 远景区政府图片 URL 从 HTTP 改为 HTTPS
  - 新增 X-UA-Compatible / format-detection meta 标签
  - 安全网定时器从 3s 缩短为 1.5s，加快内容显示
  - 新增 `<noscript>` 回退样式
