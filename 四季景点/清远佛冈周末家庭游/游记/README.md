## 出行日期

2026-10-31

## 简介

10/31（周六）一家四口乘 713 出发清远佛冈，开启「禅山 · 稻田 · 古村」的一日环线。07:04 出门，楼下 7-11 的堂食区是这趟旅程的第一张餐桌——哥、弟和兄弟婆的杯面、粽子加卤蛋，吃得干脆利落。行车记录把清晨记得清清楚楚：07:06 西村地铁站 C 口那 0.1 公里也入了账，07:39 正式上路，09:12 抵达观音山王山寺——115.6 公里的晨程，为全天 247.1 公里的里程账本翻开第一页。

![楼下 7-11 早餐（出发前）](西村出发前楼下7-11早餐.jpg)

![去程 713 车内](去程713车内.jpg)

观音山主峰海拔 1288 米，号称"粤中第一高峰"、广东八大名山之一，山形似一尊天然仰卧观音，自北宋起就是民间朝拜之地；王山寺始建于唐代，毁于战乱后重建（据景区与百科口径）。09:13 停车，仿古建筑与竹丛之间先吸一口山里的凉气；09:37，弟在放生池边把一整个纸杯的鱼粮撒了出去，橙红、金黄、白底红斑的锦鲤炸开一圈水花——池边的海芋（滴水观音）叶大如伞，清晨叶尖还会"吐水"，但汁液刺激皮肤，只可看不可摸。09:51 寺院广场，菩提树立在黄墙与坐佛石雕之间，红色祈福带缠上树干——据寺院介绍，这棵树 2012 年自斯里兰卡移植而来，树龄逾 2600 年，"与佛陀同时代"正是它的卖点；它的叶子心形、拖着细长的尾尖，雨水会顺着叶尖滴落——那是热带雨林植物自带的"排水口"。09:56 离寺，上午的禅意收官。

10:30，路边一片金黄稻田把车轮截住了。晚稻正处蜡熟—黄熟期——珠三角与粤北的双季稻，早稻六月收、晚稻十月底十一月收，我们正踩在成熟待收的窗口上；稻穗低头、田面落干龟裂，正是收割前晾田的模样。"越饱满的稻穗头越低"，一碗米饭的谦逊是生物学写好的。对面山脊上一排细高整齐的乔木是桉树人工林——广东山地最常见的"绿色银行"，长得快、轮伐短，只是山坡上若全是一种树，鸟儿和松鼠的菜单就太单调了。

妈的镜头里另有一路风景：爸掌方向盘的背影、车窗框住的稻浪与远山——车窗像一块移动的画框，金黄稻田从框里缓缓流过去（她的行车视频收录在子站游记实录里）。

10:51 抵龙山镇上岳。村前稻田尽头，一整排镬耳山墙的天际线浮在金浪之上——这就是上岳古村：宋末元初由抗元名将朱文焕后裔建村，距今 720 多年，族谱口径的"朱子后裔"聚居地；2008 年第一批广东省古村落、2010 年中国历史文化名村、2012 年第一批中国传统村落。10:54 起，兄弟俩站上田埂，身后是白色书法竖牌与连绵的镬耳楼群——"村在田中央"的构图，一眼值回油钱。

进村先认门牌。全村 18 个里，五家为邻、五邻为里，每个里自有门楼门匾——抬头一块"歸仁里"石匾，就是一个古老"小区"的门牌（"归仁"二字出自《论语》"克己复礼为仁"）。镬耳墙是岭南建筑的"身份密码"：明清时只有出过功名的人家，屋顶才配"竖起两只耳朵"，锅耳高低暗合官位大小；而它更实在的本事是防火——高过屋面的双层青砖墙阻断火势，村中禾秆柴草成堆，这"封火墙"就是古人的消防智慧。11:24 走到朴山朱公祠，黑底金字匾侧写着"乾隆四十六"——1781 年，一座 240 多岁的老祠堂；门侧镬耳与屋脊上的鳌鱼陶塑，藏着"双凤朝阳""独占鳌头"两重彩蛋。

村里处处是活着的生活。11:45，村中篮球场几乎整个被稻谷摊开占据——今天的球场不打球，在"晒秋天"：新谷含水率高，须晒到约 13% 以下才能入仓防霉，耙出的条纹是大地的纹理；场边大肚箩筐、高拱提梁的担篮、粗篾直壁的囤成排码放——没有塑料袋的年代，一个村庄的物流全靠竹子。塘边禾秆草扎成伞形草墩立晒，雨水顺草尖流走、中心通风不易霉烂——古人发明的"防水打包法"。墙根糖水摊卖豆腐花、绿豆沙，弟戴着墨镜举着一杯印"诸事皆宜"的奶茶——700 年古村里最穿越的一杯。11:44 路过"泰怡"老士多，两层青砖铺面房至今还在营业，货架、袋装米与冰柜同框——"士多"是 store 的粤音译词，老招牌要按民国习惯从右往左读。11:13 檐下一条整木斫成的长凳配花岗岩石条凳——没有 WiFi 的年代，村口这条木凳就是朋友圈。

田埂上还有一节自然课。10:59，落干的稻田泥面上散布着数十枚深色小圆球——螺。壳色深褐偏黑、体型圆小，更像本土田螺类，但没抓到成体，不能百分之百确定（游记里诚实的不确定，比编造的确定更值得写）；顺手给兄弟俩立下安全口诀：**粉卵=福寿螺，不要摸；螺尾尖尖壳硬硬，才是田螺**。11:02 一只大蝴蝶掠过稻田——凤蝶科，疑似美凤蝶的雌蝶无尾型，一张飞行照不定论。11:43，村里至少四只狸花猫轮番出镜，窗里的猫与窗外的猫隔窗对望——在这里人才是游客，猫才是原住民；连《礼记》记载的年终大祭"八蜡"里都专门有迎猫之礼，猫有功于农业是有典籍背书的。11:20 老瓦房屋脊上那丛"枯草"，其实是多肉植物棒叶落地生根——叶端锯齿天生一排小植株，落地即生根，所以得了"不死鸟"的名号，老瓦房是它的自由王国。村道下砌石明渠清水流动——700 年前就规划好的"下水道"，明渠暗渠加村前塘，排水、蓄水、消防一体化。11:21 青砖墙上的"佛冈"布艺大字用牛仔布拼出镬耳屋、舞狮、风车、稻垛、荔枝——天然的找名片游戏，兄弟俩在字里找出了五样佛冈的东西。

11:57–12:07，行车记录里那 1.1 公里，是从村委会门口挪到横围新村找车位的一小段——"古村里绕不出去的 1.1 公里"，就当多逛了一遍村。中午在古村岳农庄吃农家菜：清远鸡、河虾炒韭菜、豆角干排骨煲摆满一桌；门口水箱里还养着一缸龟，饭后兄弟婆在店里"帮忙"忙前忙后——农庄的烟火气，不止在桌上。14:01 出发返程，15:29 回到西村的家，96.1 公里给账本收尾——上午在寺、正午在村、下午在路，三段式的一日闭环。晚上 21:02 翻出行车记录截屏对账：全天 247.1 公里，分毫不差。
