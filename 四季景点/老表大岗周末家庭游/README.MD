## 出行日期
2026-08-08

## 简介
今天计划回大岗。
早上出行前，爸先到公寓取螺丝刀，用于更换713空调滤芯。
在公寓楼下并没有直接更换，太热了，反而是进行了全车吸尘；
然后开车到二沙岛，找了个开阔凉爽的位置，开始更换空气滤芯。
完事后开车到油站，加油前加入了燃油添加剂，目的是清积碳。需在燃油低于1/4时注入，然后入满油，利用入油过程进行搅拌；然后需要拉高转速跑高速30分钟以上。刚好适合待会出发去东新高速回大岗，利用高速路段高转来运行燃油添加剂，清洗油路。

到大岗已接近12点，老表也跟在我们到达。

老表是兄弟妈妈表妹的儿子，也是两兄弟，家住顺德，离大岗很近，之前也来过多次。

这是一种机缘巧合？兄弟和老表既然相聚于大岗，或许真是种缘分。

午饭在家吃，地方不大，人多，临时搬了桌子到有空调的客厅吃。
妈提前买了盒马熟食加餐。

兄弟和老表一桌，其余大人另一桌。

午饭后在厅看电视玩耍。

17点出发去潭州金悦海鲜酒楼晚饭。

这饭店没吃过，但意料之外的菜品、环境都不错，大家满意。

回程路上还经过妈之前心心念念的北流小吃街，没有下车去看，下次有机会专门去吗？

回程时妈也说道：下次跟老表相聚是否是高考后？此话既伤感，但也侧面反应我们应该珍惜眼前的时光，不要因为小事而嫌弃或不重视。
