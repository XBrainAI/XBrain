## 一、数据说明

| 字段    | 说明                                                                                                                       |
| :---- | :----------------------------------------------------------------------------------------------------------------------- |
| 学校编码  | 唯一标识，格式：\[类型码]-\[区域码]-\[序号]（如 GB-LW-01 表示公办-荔湾区-01号，MBG-SZ-01 表示民办公费班-全市-01号）                                            |
| 类型码   | GB=公办 / MBG=民办公费班 / MB=民办普通高中                                                                                            |
| 区域码   | SS=省属 / SZ=市属 / LW=荔湾区 / YX=越秀区 / HZ=海珠区 / TH=天河区 / BY=白云区 / HP=黄埔区 / PY=番禺区 / HD=花都区 / NS=南沙区 / ZC=增城区 / CH=从化区 / SW=市外 |
| 隶属    | 省属/市属/校址所在区或市                                                                                                           |
| 学校性质  | 公办/民办                                                                                                                    |
| 学校类别  | 国家级示范性普通高中/广州市示范性普通高中/其他普通高中/民办普通高中公费班/民办普通高中                                                                            |
| 录取批次  | 该校参与的录取批次（第一批/第二批/第三批/第四批，可多选）。其中"第四批"对示范性普通高中表示该校前批未完成的剩余计划在第四批继续招生；对非示范性普通高中表示该校仅在第四批招生                                |
| 梯度    | 2025年第三批录取所处梯度                                                                                                           |
| 补录最低分 | 2025年补录录取最低分数，仅2.18节收录。补录范围为全市，与正常录取分数口径不同（老三区正常录取为户籍生分数，其他区为外区生分数）                                                      |
| 2026年学校地址 | 2026年招生简章中的学校地址                                                                                                                  |
| 2026年招生计划 | 2026年该校在该批次的招生计划人数                                                                                                               |
| 2026年外区招生最大计划数 | 2026年该校面向外区招生的最大计划数（"不限"表示不限制外区招生比例）                                                                                               |
| 2026年学校总计划 | 2026年该校所有批次招生总计划人数                                                                                                                |
| 2026年总宿位 | 2026年该校可提供的总宿位数                                                                                                                   |
