# 第一部分 政策篇

## 1.1 中考改革政策背景

广州市现行中考制度依据《广州市教育局关于深入推进高中阶段学校考试招生制度改革的实施意见》（穗教规字〔2023〕1号）执行，适用于2024-2026年初中应届毕业生。

> - 非示范性普通高中投档：录取参考科目成绩须达到D级及以上

## 1.2 考生类型定义

广州市中考考生按户籍和学籍情况分为以下类型：

| 考生类型        | 定义               | 报考范围                   |
| :---------- | :--------------- | :--------------------- |
| **户籍生**     | 具有广州市户籍          | 可报考面向全市及本区的公办高中        |
| **随迁子女**    | 非广州市户籍，符合政策性照顾条件 | 可报考公办高中（占学校招生计划8%-18%） |
| **往届生/返穗生** | 非应届初中毕业生或从市外返回广州 | 按具体政策执行                |

### 1.2.1 名额分配考生资格条件

报考名额分配计划的学生，必须同时满足：

1. 具有广州市户籍（含政策性照顾学生）
2. 具有同一初中学校三年完整学籍并在该校就读到毕业
3. 或从市外转学到本市并在转入学校就读到毕业的初中应届毕业生

### 1.4.1 各类高中招生范围

| :--------- | :------------------------ |
| 民办普通高中     | 面向全市招生                    |
| 省市属普通高中    | 面向全市招生                    |
| 区属示范性普通高中  | 面向本区招生，外区生比例≤15%（部分区≤25%） |
| 区属非示范性普通高中 | 面向本区招生                    |

### 1.4.2 老三区特殊政策

- **老三区**：越秀区、海珠区、荔湾区
- **区内互报**：老三区考生报考其他两区的区属高中，**视为本区考生**，不受外区名额限制
- **跨区报考**：老三区考生报考天河、白云、黄埔等区的区属高中，**视为外区考生**，受跨区名额限制

# 第二部分 志愿篇

> 本部分整合原文档"志愿填报指导"内容，并补充志愿填报流程与策略。

## 2.1 填报志愿时间与流程

### 2.1.1 志愿填报时间

| 时间                 | 事项               |
| :----------------- | :--------------- |
| **2026年6月1日-6月5日** | **广州中考考前集中志愿填报** |

> **重要提醒**：志愿填报在中考前进行（考前填志愿），而非考后。因此志愿填报需基于平时成绩、一模排名等预测性数据进行决策。

### 2.1.2 志愿填报流程

1. **登录系统**：通过广州市中考服务平台登录志愿填报系统
2. **填写志愿**：按批次依次填写志愿学校
3. **确认提交**：核对志愿信息后提交确认
4. **打印存档**：打印志愿确认表存档备查

> **注意事项**：
>
> - 志愿填报截止后不可修改
> - 建议提前在纸质志愿表上草拟，再录入系统

### 2.1.3 各批次志愿个数

根据《2026年广州市高中阶段学校报考指南》，各批次可填报的志愿数量如下：

| 批次 | 类别 | 可填报志愿数 | 说明 |
| :--: | :-- | :--: | :-- |
| **第一批次** | 特长生招生计划 | 1个学校志愿 | 需通过专业测试 |
| | 自主招生计划 | 1个学校志愿 | 需获得综合能力考核资格 |
| | 外语和艺术类招生计划 | 1个学校志愿 | 需参加校测 |
| | 港澳子弟班 | 2个学校志愿 | 仅限港澳台居民考生 |
| | 中本贯通 | 2个学校志愿 | 每校只有1个专业，应届考生方可填报 |
| | 中职三二分段及省级重点特色专业 | 4个学校志愿 | 每校可填报4个专业，需选择是否服从专业调剂 |
| **第二批次** | 名额分配 | 3个学校志愿 | 仅限符合名额分配资格的考生 |
| **第三批次** | 统招 | 6个学校志愿 | 示范性普通高中、民办高中及综合高中公费班等 |
| **第四批次** | 普通高中和综合高中 | 6个学校志愿 | 非示范性普通高中、综合高中 |
| | 中职学校 | 6个学校志愿 | 每校可填报6个专业，需选择是否服从专业调剂 |

> **重要提示**：
>
> - 同批次类别内志愿学校不能重复
> - 不要求所有批次和志愿都报满，但应充分利用志愿容量
> - 志愿填报情况与录取直接相关，**每一个志愿学校都有可能成为最终的录取结果**

## 2.2 志愿填报基本原则

### 2.2.1 "冲-稳-保"策略

| 层次    | 定位   | 说明                  |
| :---- | :--- | :------------------ |
| **冲** | 冲刺志愿 | 分数略高于自身水平，有希望但非绝对把握 |
| **稳** | 稳妥志愿 | 分数与自身水平匹配，录取概率较大    |
| **保** | 保底志愿 | 分数低于自身水平，确保有学可上     |

### 2.2.2 志愿填报要点

1. **第一志愿极其重要**：同梯度内志愿优先，第一志愿决定投档优先级
2. **梯度合理分布**：志愿间保持适当分数梯度，避免扎堆填报
3. **保底不可少**：必须有至少一个保底志愿，防止滑档
4. **参考往年数据**：结合近三年录取分数和梯度线变化趋势

## 2.3 各批次志愿填报指南

### 2.3.1 第一批次：特殊类招生

**招生类型**：自主招生、外语类、艺术类、体育类等

**该考生可报考**：

- 广州外国语学校（需参加外语能力测试）
- 广州市西关外国语学校（需参加外语能力测试）

> **注意**：普通考生一般不涉及第一批次，需提前参加校测或具备特长资格。

### 2.3.2 第二批次：名额分配

**该考生名额情况**：

- 省市属高中名额：11个
- 荔湾区区属名额：65个
- 合计：76个名额

**志愿填报规则**：

- 仅可填报本校分配到名额的高中
- 与本校同批填报同一高中的考生竞争（非全市竞争）
- 录取控制线：不低于该校第三批统招户籍生最低分减40分

> **名额分配的核心价值**：通过名额分配录取，分数线通常低于第三批统招线（最多低40分），是"低分进名校"的重要渠道。但名额有限，竞争在本校内进行。

### 2.3.3 第三批次：统招

**该考生可报考范围**：

- 省属/市属高中（面向全市招生）
- 荔湾区、越秀区、海珠区区属示范性高中（老三区互报，无外区限制）
- 其他区区属示范性高中（以外区生身份报考，受15%/25%跨区名额限制）
- 民办高中及公费班
- 综合高中公费班（2026年新增，面向全市招生）

### 2.3.4 第四批次：常规录取兜底

**该考生可报考范围**：

- 荔湾区、越秀区、海珠区区属非示范性高中
- 民办普通高中
- 综合高中（2026年新增，部分学校在第四批招生）

> 第四批次作为兜底选择，建议填报录取分数较低的学校确保有学可上。

# 第三部分 录取篇

> 本部分整合原文档"中考录取制度解读"内容，并补充投档规则详解。

## 3.1 四个批次与录取顺序

广州中考录取分为四个批次，**严格按批次顺序依次投档**，前一批次录取后不再参与后续批次：

|  批次 | 名称   | 招生类型                  | 说明                       |
| :-: | :--- | :-------------------- | :----------------------- |
| 第一批 | 特殊类  | 自主招生、外语类、艺术类、体育类等     | 需提前参加校测或具备特长资格，普通考生一般不涉及 |
| 第二批 | 名额分配 | 公办示范性普通高中≥50%招生计划指标到校 | 仅限具有名额资格的考生，在本校分配到的名额内竞争 |
| 第三批 | 统招   | 公办示范性高中+民办公费班+民办高中+综合高中公费班    | 面向全市或全区统招，是大多数考生的主战场     |
| 第四批 | 常规录取兜底 | 公办非示范性高中+民办高中+综合高中         | 分数相对较低的学校，作为兜底选择         |

> **关键**：每个批次独立投档，前一批次被录取则后续批次志愿自动失效。因此志愿填报需合理布局"冲-稳-保"。

## 3.2 梯度投档控制线机制

广州中考采用**梯度投档**制度，核心规则如下：

### 3.2.1 梯度线划定

以报考总人数为基数，按比例划定多条梯度投档控制线。2025年共设6条梯度线+1条普高最低控制线：

| 梯度线     | 划定方式           |
| :------ | :------------- |
| 第一梯度    | 按报考总人数约10%位置划定 |
| 第二至第六梯度 | 以40分为间距依次递减    |
| 普高最低控制线 | 低于此线无法被普通高中录取  |

### 3.2.2 投档规则

1. 从第一梯度线上的考生开始，按志愿顺序投档
2. 同一梯度内，**志愿优先**：先投第一志愿，再投第二志愿，以此类推
3. 第一梯度线上考生全部投档完毕后，再处理第二梯度线上的考生
4. 以此类推，直到所有梯度线上的考生投档完毕

### 3.2.3 实操含义

- 考生分数达到某梯度线，即可在该梯度及以下梯度的学校中竞争
- **第一志愿极其重要**：同梯度内志愿优先，高分考生若第一志愿填错，可能被第二志愿的同梯度学校拒之门外
- 跨梯度填报需谨慎：第二梯度分数的考生填第一梯度的学校，只有该校在第一梯度线上未录满时才有可能

### 3.2.4 2026年特殊政策：10所国家级示范性普高第三批降档

## 3.3 名额分配政策详解

**什么是名额分配**：公办示范性普通高中将不低于50%的招生计划，直接分配到区域内各初中学校，让每所初中的学生都有机会进入优质高中。

### 3.3.1 核心规则

| 规则    | 说明                                                |
| :---- | :------------------------------------------------ |
| 资格条件  | 具有广州市户籍+同一初中3年完整学籍，或符合条件的随迁子女                     |
| 分配方式  | 省市属高中名额面向全市分配；区属高中名额面向本区分配                        |
| 分配公式  | 某初中获得的某高中名额 = 该高中名额分配计划 ×（该初中名额考生数 ÷ 全区/全市名额考生总数） |
| 录取控制线 | 第二批次录取最低分数不低于该校第三批统招户籍生最低分减40分                    |
| 志愿填报  | 在第二批填报，仅可填报本校分配到名额的高中                             |
| 竞争范围  | 仅与本校同批填报同一高中的考生竞争，非全市竞争                           |

### 3.3.2 名额分配投档录取流程

1. **名额计划下达**：市教育局将各高中名额分配计划下达至各初中
2. **考生填报志愿**：符合条件的考生在第二批次填报名额分配志愿
3. **校内竞争**：各初中校内填报同一高中的考生按分数排序
4. **投档录取**：从高分到低分依次投档，录满名额为止
5. **结果公示**：录取结果全市可查

> 名额分配的录取最低分数不一定比统招低。如果某初中尖子生集中，校内竞争激烈，名额分配录取分数可能接近甚至超过统招线。

## 3.4 老三区跨区报考规则

荔湾区、越秀区、海珠区同属"老三区"，享有特殊跨区政策：

- **老三区内互报**：荔湾区考生报考越秀区、海珠区的区属高中，**视为本区考生**，不受外区名额限制
- **老三区外报考**：荔湾区考生报考天河、白云、黄埔等区的区属高中，**视为外区考生**，受跨区名额限制

## 3.5 外区生报考限制

第三批次中，区属示范性高中面向外区招生时，有名额限制：

| 学校类别       | 外区招生比例限制 |
| :--------- | :------- |
| 国家级示范性普通高中 | ≤15%     |
| 市示范性普通高中   | ≤25%     |

> **对该考生的影响**：报考天河、白云、黄埔等区的区属高中时，需竞争有限的外区名额，录取分数可能高于该校本区考生最低分。报考老三区（越秀、海珠）的学校则无此限制。

## 3.6 同分排序规则

当考生投档分相同时，按以下顺序排序：

1. 录取参考科目等级（从高到低）
2. 语数英三科总分（从高到低）
3. 数学单科成绩（从高到低）
4. 语文单科成绩（从高到低）
5. 英语单科成绩（从高到低）

## 3.7 补录机制

普通高中因未录满招生计划或因学生未按规定时间到校注册而空余的计划，通过市招考办统一平台向社会公开补录。

| 项目   | 说明                                      |
| :--- | :-------------------------------------- |
| 补录对象 | 当年未被录取的本市考生                             |
| 补录时间 | 2026年7月下旬                               |
| 补录规则 | 按考生志愿、录取计分科目考试成绩和综合素质评价结果择优录取           |
| 注意事项 | 未经高中阶段学校同意逾期不报到的考生，视为自行放弃入学资格，且不能参加统一补录 |

# 第七部分 常见问题解答

## Q1: 志愿填报后可以修改吗？

A: 志愿填报截止时间后不可修改。请在截止时间前仔细核对并确认。

## Q2: 一模成绩对志愿填报有多重要？

A: 一模是考前唯一官方全市排位参考，其排名是志愿填报的核心依据。请认真对待一模考试。

## Q3: 名额分配和统招可以兼报吗？

A: 可以。名额分配在第二批次，统招在第三批次，两个批次独立投档。

## Q4: 老三区考生报考越秀/海珠区学校受限制吗？

A: 不受限制。老三区（荔湾、越秀、海珠）视为同一招生区域，互报视为本区考生。

## Q5: 中考成绩达到普高线就一定能上高中吗？

A: 不一定。达到普高最低控制线只是获得投档资格，最终能否被录取取决于志愿填报和学校录取情况。

## Q6: 未被录取怎么办？

A: 可参加7月下旬的普通高中统一补录，或考虑中职学校（8月投档录取）。

## 附录：核心概念速查表

> 本表汇总文档中涉及的核心概念，便于快速查阅。

| 概念          | 定义                       |
| :---------- | :----------------------- |
| **梯度投档**    | 按梯度线分层投档，同一梯度内志愿优先       |
| **名额分配**    | 公办示范性高中≥50%招生计划分配到各初中    |
| **老三区**     | 荔湾区、越秀区、海珠区，视为同一招生区域     |
| **外区生**     | 报考非本区（非老三区）区属高中的考生       |
| **跨区生**     | 学籍与户籍不在同一区的考生            |
| **第一志愿**    | 同梯度内优先投档，极其重要            |
| **普高最低控制线** | 低于此线无法被普通高中录取            |
| **自主招生**    | 示范性高中≤10%、非示范性≤5%的自主招生计划 |
| **补录**      | 未录满学校的二次招生机会             |
| **随迁子女**    | 非广州户籍但在广州就读的考生           |
