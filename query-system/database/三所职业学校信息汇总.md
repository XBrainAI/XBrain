## 五、报考建议要点

1. **分数参考**：
   - 贸易职高综合高中录取分约547-582分
   - 天河职高综合高中录取分约511-586分
   - 财经商贸职业学校综合高中为2026年新增，可参考其他两校分数

2. **住宿需求**：
   - 三校中职阶段均**不提供住宿或宿位极少**
   - 财经商贸大坦沙校区有255个宿位，是相对优势

3. **学校等级**：
   - 天河职高和财经商贸为**国家级重点**
   - 贸易职高为省级重点

4. **专业特色**：
   - 贸易职高：艺术设计、服装、无人机
   - 天河职高：计算机网络、金融、软件
   - 财经商贸：会计、电商、物流、眼视光（唯一有眼视光专业的学校）

5. **升学优势**：
   - 财经商贸有**中本贯通3+4**（直升本科），是三校中唯一有本科贯通培养的学校
