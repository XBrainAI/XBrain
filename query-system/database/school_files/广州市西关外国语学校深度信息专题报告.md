- **2017年5月**：荔湾中学（原第四十三中学）整体并入
- **2017年12月**：评定为广州市示范性普通高中
- **2023年**：流花路小学、西华路小学加入西外教育集团

## 二、办学特色与定位

### 2.1 外语特色——学校最核心的竞争力

**① 多语种课程**

开设英语、日语、法语、西班牙语、意大利语、德语、韩语等7个语种课程，配备专职外籍教师担任口语教学。

**② 日语高考班——广州首创，王牌特色**

| 项目 | 内容 |
|------|------|
| 开设时间 | 2012年（广州最早） |
| 已毕业学生 | 82人 |
| 高考日语平均分 | 127分 |
| 140分以上 | 14人 |
| 额外学费 | 无（与英语班一致） |
| 教材 | 人教版课标教材 |
| 教辅费用 | 三年约500元 |
| 招生方式 | 高一零起点，走班制，小班教学 |

日语高考班的优势：高考日语难度普遍低于英语，题型简单（120分选择+30分作文），通过两年学习考120分以上相对容易，而英语考120分难度大得多。绝大多数高校专业对日语考生无限制。

**③ 国际课程**

| 课程类型 | 内容 |
|----------|------|
| AP课程 | 学术+活动+体育三大核心，数学、科学、人文等模块 |
| A-Level课程 | 数学、物理、化学、经济、计算机等，设有国际考点 |
| 雅思/托福/SAT | 辅导课程 |

**④ 国际交流**

- 与美国、英国、加拿大、澳大利亚、新西兰、法国、德国、韩国、新加坡等国中学结为姐妹学校
- 寒暑假组织4-6周英语国家语言实践
- 2024年接待香港九龙工业学校师生交流

### 2.2 排球特色——国家级传统项目

西外排球队是学校最亮眼的体育名片：

- **1981年**获评省、市排球传统项目学校
- **1986年**率先启动"市队校办""教体结合"训练模式
- 逐步发展为**国家级排球传统项目学校**
- 女队曾获**五连冠**
- 男队曾获**四届亚军、一届冠军**
- 排球基础课要求：一分钟垫球/托球50次得满分
- 2025-2026年全国青少年排球联赛获"体育道德风尚奖"

### 2.3 "金苹果"校本课程体系

- 以"金苹果"为校园文化象征
- 构建"培养具有国际视野与本土情怀的现代公民"育人目标
- 四大板块：国家基础课程 + 外语特色课程 + 国际课程 + 语言课程
- 多元选修：书法、粤曲、管乐、钢琴、合唱、舞蹈、机器人、3D打印、金融理财等

### 9.1 综合评价：从"三足鼎立"到"跌落第六"的断裂带

西关外国语学校的民间口碑呈现出一条清晰的下行曲线——2024年尚与一中、四中并称荔湾"三足鼎立"，2025年分数线暴跌42分后已跌至区属第六，仅高于南海中学。这一断裂背后，是多个维度问题的集中爆发。

**官方评价与民间评价的断裂**：

| 维度 | 官方标签 | 民间感受 |
|------|----------|----------|

### 9.5 "留人签约"策略深度剖析——西外最大争议

西外的"留人签约"策略是民间口碑中最具争议的话题之一，涉及多个年级学生的亲身经历：

**① 策略手法**

知乎多位学生描述了一致的留人手法：
- 级长/班主任在初三反复强调"你的成绩绝对考不上你想去的地方"
- 拿签约三年重点班来诱惑（但重点班数量过多，含金量稀释）
- 打压学生自信心，制造恐惧心理
- 免学费、降分进入高中实验班、签约奖学金等条件吸引

**② 直升生的普遍后悔**

知乎答主写道：
> "直升的没几个不后悔的。中考出成绩的那天都想撞墙死，当初被说考不上的人，分数基本上都比那学校的录取分高个十几分。这还不是个例，这就是普遍的现象。"

**③ 知乎答主2020届的完整控诉**

### 11.4 风险提示

**风险一：2025年分数线暴跌后的"锚定效应"**

**风险二：2026年缩招的连锁反应**

**风险三：校园面积的硬约束**

**风险四："外国语"品牌与实际体验的落差**

与广州外国语学校（市属、700分）名称相似但质量差距极大，部分家长可能因"外国语"三字对西外产生不切实际的期望。

## 十二、总结与建议

### 12.1 西关外国语学校的核心画像

> **一所外语特色鲜明、加工能力出色、但硬件条件偏弱、2025年遭遇分数线暴跌的荔湾区属外国语学校。**

### 12.2 三个最核心的判断

1. **外语特色是真优势，不是噱头**——日语高考班、7语种教学、国际课程体系，这些在荔湾区是独一份的存在
2. **加工能力是真实力，但有天花板**——特控率连续三年41%-42%停滞不前，说明在现有生源和硬件条件下已接近极限
3. **2025年分数线暴跌是真风险**——从"三足鼎立"跌至"老六"，市场对西外的信心出现了动摇

### 12.3 给2026年考生家长的建议

**✅ 推荐报考的场景**：
- 英语成绩一般，希望通过日语高考提分（这是西外最不可替代的优势）
- 有排球特长
- 荔湾区非集团初中学生，610-630分，可通过名额分配"低分高录"
- 有出国留学规划，需要国际课程体系

**⚠️ 慎重考虑的场景**：
- 分数640-660分——同分段在一中、四中可能有更好的整体体验
- 对校园环境和住宿条件要求较高——西外的硬件是硬伤
- 以为"外国语"等同于广州外国语学校——二者差距巨大

**❌ 不建议报考的场景**：
- 分数660+——分数足以进入更好的学校
- 非外语特长/无排球特长，且对"加工能力"没有刚性需求

### 12.4 对西关外国语学校最关键的一句话

> **如果你的孩子英语弱想转日语高考，或有排球特长，或有留学规划——西外可能是荔湾区最好的选择；如果你只是想要一所"好高中"——同分段在一中、四中可能有更好的整体体验。**
