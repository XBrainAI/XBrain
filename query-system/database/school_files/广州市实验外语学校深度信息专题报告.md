## 2. 办学性质与历史沿革

### 2.1 办学性质

广州市实验外语学校是**广东外语外贸大学全资所有并直接管理**的国有民办学校。广东外语外贸大学是广东省涉外型重点大学，学校依托大学的外语教育资源和管理体系运营，与大学之间有天然的师资输送和教学联动关系。

**关键性质辨析**：
- **非**区属公办学校——无名额分配，面向全市招生
- **非**纯商业民办——由公立大学全资持有，带有"国有"属性
- **实际定位**：国有民办，体制灵活但有大学背书，兼具民办的自主招生优势和公办的资源保障

### 2.2 历史沿革

| 时间 | 事件 |
|------|------|
| 1993年9月 | 学校创办，原名为"广州市广外附设外语学校"（广外外校） |
| 1995年 | 获教育部认定首批13所具有外语类保送生资格的外国语学校之一 |
| 此后多年 | 逐步发展壮大，成为广东省一级学校 |
| 2022年1月28日 | 正式更名为"广州市实验外语学校" |
| 2022年 | 响应"公参民"改革政策，停招小学一年级新生；初一只接收校内直升生；义务教育学段申请转型为国际学校（广外外籍人员子女学校）；**高中部扩招至500人**，保送生资格不变 |
| 2023年 | 高中招生扩至700人 |
| 2024年 | 高中招生700人，学费调整为76000元/年（一费制） |
| 2025年 | 高中招生700人；2025届高考特控率60.13%、本科率98%；保送62人全部进211及以上高校 |
| 2026年 | 招生计划700人（最终以主管部门批复为准）；3名同学保送北京大学 |

### 2.3 "公参民"改革影响

2022年"公参民"改革是学校发展的关键转折点：

| 改革前 | 改革后 |
|--------|--------|
| 十二年一贯制完整学部 | 小学停招、初中仅校内直升，义务段转型国际学校 |
| 小学→初中→高中完整链条 | 高中部独立发展，扩招成为主力 |
| 招生规模较小 | 高中扩招至700人规模 |

**核心结论**：改革对高中部影响为正向——保送资格不变、招生规模扩大、资源更集中。义务教育段的调整不影响高中部办学。

## 8. 保送生制度——核心竞争优势

### 8.1 保送资格概述

广州市实验外语学校是**教育部认定的全国16所（首批13所）具有外语类推荐保送生资格的外国语学校之一**，也是**广州市唯一**具有此资格的学校。

这意味着：每年有62名学生可以**免参加高考**，直接通过高校组织的保送生招生考试被国内985、211、双一流名校录取。

### 8.2 保送生选拔规则——"三年长跑"

| 环节 | 占比 | 说明 |
|------|------|------|
| 高一、高二4次统考成绩 | 30% | 统一命题期末考试 |
| 高三保送推荐资格考试 | 70% | 校外名师命题，高考标准流程阅卷，分数统计全程加密 |

**竞争格局**：
- 文科方向：约200人竞争约30个名额
- 理科方向：约500人竞争约30个名额

**关键规则**：
- 历史班、物理班分别排序，每4名为一段，同段内文理对等竞争
- 名额未报满自动流转至同段另一科递补
- 选拔全程公开透明，"不看入学排名，也不看某次考试运气"

### 8.3 保送成果

| 年份 | 保送人数 | 211以上录取 | C9录取 | 985录取 |
|------|---------|------------|--------|---------|
| 2024年 | 62人 | 61人 | 7人 | 46人 |
| 2025年 | 62人 | 62人（100%） | 24人 | 71人 |
| 2026年 | 62人 | — | — | 含3人保送北大 |

**说明**：2025年数据中，"C9高校录取24人次、985高校录取71人次"为多份offer统计（一人可能获多校offer），62人全部进入211及以上高校。

### 9.4 争议事件深度分析

#### 9.4.1 2022年"停办"风波——品牌信任的重大考验

| 维度 | 详细分析 |
|------|---------|
| **事件起因** | 2022年4月28日，多张聊天截图在家长群疯传，内容称"外校停办""老师学生逐步分流、解散"，截图提醒家长"可以开始想渠道" |
| **传闻扩散** | 短短半天内从白云区扩散至全市家长群，因学校规模大（近6000学生）且广外教育集团在番禺/南沙/增城/肇庆有多家分校，影响面极广 |
| **家长反应** | 震惊、恐慌、不舍——学生表示"不开心，喜欢外校" |
| **校方辟谣** | 明确表示"停办和分流传言不实"，仅小学一年级暂停招生、初中改为仅校内直升、高中扩招至500人 |
| **白云区政府回应** | "不存在广外外校学校解散的说法"，推荐保送生资格不变 |
| **实际变动** | 小一停招→义务段转型为广外外籍人员子女学校→高中部独立发展并扩招→保送资格不变 |
| **深层原因** | 2022年"公参民"改革要求公办资源退出民办学校，广外外校作为广外大学全资持有的"国有民办"必须转型；义务段转为外籍学校是合规路径 |
| **对高中部影响** | 实际为**正向**——保送资格不变、招生规模扩大、资源更集中；但品牌信任一度受损 |
| **口碑修复** | 至2025-2026年，高考成绩和保送成果持续亮眼，家长信任基本恢复；但仍有部分家长"心里有根刺" |

**时间线梳理**：

| 时间 | 事件 |
|------|------|
| 2022年1月 | 正式更名为"广州市实验外语学校" |
| 2022年4月 | "停办"传闻爆发，校方辟谣 |
| 2022年秋季 | 小一停招、初中仅校内直升、高中扩招至500人 |
| 2023年 | 义务段转型为"广外外籍人员子女学校"获批准 |
| 2023-2025年 | 高中部持续扩招至700人，保送、高考成绩亮眼 |
| 2025年 | 口碑基本修复，开放日家长人数"超出学校预期" |

#### 9.4.2 虚假招生信息——品牌价值的外部验证

| 时间 | 事件 |
|------|------|
| 2025年4月 | 学校发布严正声明：有家长收到以"广州市广外附设外"名义发布的虚假招生信息 |
| 2025年8月 | 广州3所民办学校（含广实外校）联合发布招生声明，提醒家长甄别 |
| 声明要点 | 所有招生依法依规、未授权任何校外机构、谨防"花钱买学位"骗局 |
| 冒用名称 | "广州市广外附设外"（名称不完整，与学校现名及原名均有差异） |

**深层解读**：虚假招生信息的出现，恰恰说明学校的品牌价值和市场需求足够大，才会被不法分子盯上。对比一些无人问津的学校，从未遇到此类问题。

#### 9.4.3 万清华校长离任审计——正常人事更替

| 时间 | 事件 |
|------|------|
| 2015年1月 | 万清华出任广实外校校长 |
| 2023年2月 | 广外教育集团调整：万清华续任校长，熊士军任执行校长 |
| 2025年3月 | 广东外语外贸大学审计工作部公告：对万清华担任校长期间（2015.1.23-2024.12.31）履行经济责任情况进行审计 |
| 2025年7月 | 广外教育集团宣布：万清华到龄退休，熊士军接任校长 |

**舆论分析**：
- 审计公告在离任前发布，属于**高校系统正常程序**——国有企事业单位主要领导人员离任均须经济责任审计
- "到龄退休"为官方表述，非"被免职"或"被调查"
- 熊士军此前已担任执行校长2年，交接平稳
- 社交媒体有个别猜测，但未形成广泛质疑

| 家庭经济紧张 | **谨慎**——三年约23万+支出，需充分评估家庭承受能力 |
| 目标传统理工强校 | **不太适合**——学校优势在外语和保送，理工竞赛非核心特色 |
