## 二、办学理念与特色

### 核心理念："水乡文化，润泽教育"

学校围绕**水乡主题文化**整体打造校园，建构起"水乡文化，润泽教育"特色课程体系，为学生提供个性化、多样化的校本课程。以"适合的教育"理念为导向，推进"自主、合作、探究"和"智慧课堂"融合的课堂教学改革。

### 四大金牌特色

#### 1. 剪纸艺术——"一条龙"高水平美育团队

| 维度 | 详情 |
|------|------|
| **最高荣誉** | 2024年3月被认定为**广州市高中阶段体育美育高水平团队"一条龙"培养学校** |
| **特色方向** | 剪纸团队被认定为高水平美育团队 |
| **招生资格** | 具备**广州市艺术特长生（剪纸方向）招生资格** |
| **2025年特长生** | 剪纸特长生合成成绩线71.9753分 |

> 剪纸是东涌中学最鲜明的艺术标签，也是南沙区高中中唯一的剪纸高水平美育团队，对爱好美术/手工的学生具有独特吸引力。

#### 2. 科技教育——超千项市级以上奖项

| 维度 | 详情 |
|------|------|
| **获奖总量** | 全校师生共获**市级以上科学研究和发明奖超过1000项** |
| **国家专利** | "超重失重演示仪"等**12项发明获得国家实用新型专利** |
| **科创竞赛** | 学生多个项目在广州市青少年科技创新大赛中荣获**一等奖** |
| **承办赛事** | 成功承办全国建筑模型教育竞赛、珠三角创意木飞机大赛、广州市阳光测向竞赛等活动 |
| **相关荣誉** | 广州市青少年科技体育教育工作先进单位、广州市中小学智慧校园 |

### 9.2 核心长板口碑

#### 长板一："低进高出"加工能力——数据支撑的硬实力

连续三年特控达标率超过119%（2021-2023），2022届甚至达到165%的超高完成率。这意味着：
- 入学时预测仅43人能上特控线 → 实际71人
- 入学时预测仅211人能上本科 → 实际298人

在生源质量不占优的情况下，东涌中学展现了超过同档学校的"加工"能力。这对于中考分数不突出但希望在高中逆袭的考生来说，具有极强的吸引力。

#### 长板二：校园硬件——147亩亚运级校园

147亩的校园面积，400米环形塑胶跑道+亚运训练场馆级别的运动设施，9个开放式阅读书吧，2,049.8㎡的图书馆——这些硬件配置在南沙区属高中中属于第一梯队，甚至优于一些市区的名校。

#### 长板三：剪纸艺术——南沙独有

广州市高水平美育团队"一条龙"培养学校（剪纸方向）在南沙区独一无二，全市范围内也极为罕见。对美术特长生而言，这是进入东涌中学的独特通道。

#### 长板四：科技教育——12项国家专利

超1000项市级以上科技奖项、12项国家实用新型专利、广州市青少年科技创新大赛一等奖——在应试教育为主的广州高中生态中，东涌中学的科技教育成绩可圈可点。

### 9.3 核心槽点口碑

#### 槽点一：数据透明度不够

学校官方宣传只用"达标率"（完成预期目标的百分比），从不公布**绝对的特控率和本科率**。第三方推算特控率仅约12-15%——这个数据如果直接公布，对家长的吸引力将大打折扣。

#### 槽点二：2025年分数线回落

2024年逆势大涨17分到612分后，2025年又回落13分至599分。这种波动削弱了"上升势头"的说服力——是否2024年的增长只是偶然？

#### 槽点三：地理位置偏远

东涌镇距离广州市中心50-60公里，对于需要频繁往返市区的家庭和学生而言是现实障碍。住校几乎是唯一选择。

#### 槽点四：宿舍口碑两极

知乎说"比大学宿舍还好"，贴吧说"无花洒、水压小、无插头"。不同楼栋条件差异可能导致体验的极大不同。
