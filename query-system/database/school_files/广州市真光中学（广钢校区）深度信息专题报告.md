## 二、办学特色

### 2.1 "本部直管、零差异"办学模式

| 特色 | 详细说明 |
|------|----------|
| **师资全本部派驻** | 所有任课教师均从真光中学本部高中部择优选拔，确保教学质量与校本部一致 |
| **同教研同备课** | 广钢校区与本部校区同一学科有相同的科组长，实行"同教研、同备课" |
| **课程体系同步** | 实施分层分类培养机制，共享校本部特色课程资源及数字教育资源库 |
| **学生评价** | "本部来的老师教学经验丰富，上课风趣，非常尽职尽责，亦师亦友"（广钢校区学生） |

### 2.2 "3+3+3"育人模型

| 层次 | 内容 |
|------|------|
| **三大核心任务** | 价值引领、思想启迪、品格塑造 |
| **三大核心能力** | 阅读能力、思考能力、表达能力 |
| **三大成长路径** | 学业发展、素质拓展、生涯规划 |

### 2.3 教育品牌定位

- **"低进高出，高进优出，优进尖出"**——这是真光中学的核心教育品牌标签
- 2025年被评为**全国文明校园**（广州市仅少数高中获此荣誉）
- 真光教育集团2024年获评**首批广东省优质基础教育集团**

### 2.4 特色课程与教学

| 特色 | 详细说明 |
|------|----------|
| **STEAM教育中心** | 广钢校区配备智能化实验室、创新工坊及STEAM教育中心 |
| **可升降实验仪器** | "新校区实验室的设备器材又新又好，便利我们的理科学习"（学生评价）——授课时仪器隐藏，实验时自动下降，提升安全性 |
| **校本选修课程** | 大成班和世光香梅班在实施国家课程基础上，提供针对性校本选修课程 |
| **双导师机制** | 与科研院所合作，采取科研院所导师+学校导师的双导师机制，培养有发展潜力的后备人才 |
