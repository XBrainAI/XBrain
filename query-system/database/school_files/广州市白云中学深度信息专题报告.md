## 二、校史沿革

| 年份 | 里程碑事件 |
|------|-----------|
| **1960年** | 前身"江村师范学校"创办 |
| **1964年** | 迁至九佛镇，更名为广州市九佛农业技术学校 |
| **1965年** | 更名为广州市郊区农业职业学校 |
| **1971年** | 更名为广州市郊区师范学校 |
| **1984年** | 迁址至东山（后天河区沙河街道马蹄岗） |
| **1999年** | 由"白云师范"转制为普通高中 |
| **2000年1月** | 正式挂牌更名为"广州市白云中学" |
| **2010年** | 整体搬迁至金沙洲新校区 |
| **2017年12月** | 成功创建为广州市示范性普通高中 |
| **2019年3月** | 启动集团化办学，成为广州市白云中学教育集团核心校 |
| **2021年8月** | 整体接收白云区汇侨中学（民转公），设为初中部 |
| **2023年8月** | 开办九年一贯制棠景校区，形成"一校三区""十二年制"格局 |
| **2025年9月** | 领导班子调整：卢月明转任党委书记，黄巧出任校长 |

## 五、班型设置与教学特色

### 5.1 三种班型

| 班型 | 数量 | 定位 | 入学门槛 |
|------|------|------|---------|
| **名师班** | 2个 | 冲击名校，名师导师团队引领 | 中考高分+签约/排名前列 |
| **科创班** | 2个 | 科技创新方向 | 中考前160名 |
| **平行班** | 8个 | 与重点班共享资源 | 其余学生 |

> ⚠️ 2026年招生宣传中，班型名称调整为"**云班**"和"**科创班**"，实际对应原"名师班"和"科技创新班"。

### 5.2 班型特点

- **师资配备**：各班级教师团队没有明显差异，学校根据教师特长科学匹配
- **资源共享**：平行班学生可自由报名参与选修二、研究性学习等课程
- **班级流动性**：高一第一学期选科时，平行班中成绩优异、达到名师班标准的学生，有机会升入名师班
- **云班/科创班进班参考**：2026年校长直播间预告，市一模排名靠前者进云班和科创班机会大（具体排名未公开）

### 9.1 身份画像：白云中学是什么"段位"的学校？

| 维度 | 定位 |
|------|------|
| **官方身份** | 广东省一级学校 + 广州市示范性普通高中 + 白云中学教育集团总校 |
| **白云区内排名** | 区属公办高中**中下游**（高考出口排名：培英＞华侨＞65中＞大同≈二外＞**白云**＞彭加木≈七十一中） |
| **分数线位置** | 2025年户籍生627分，第三梯度线，在第二/三梯度线间波动 |
| **民间标签** | "五类学校""垃圾中的战斗机""金沙洲top3""重理轻文""云中" |
| **生源画像** | 白云区本地生源为主，外区生比例低；三梯度线附近学生1志愿首选或2志愿保底 |

**一句话总结**：白云中学是一所**名师阵容豪华但出口数据拉胯**的矛盾体——正高级4人+特级3人+名师工作室21个（全区第一），但2025年纯文理特控率仅12%；创客教育全区独一档，但白云区13所公办高中排名倒数第二（2020年数据）。**师资是A级的，出口是C级的**。

### 9.2 核心优势（带原声引用）

#### 优势一：名师工作室21个，全区第一

> "师资优良，文理科的师资在白云区都算是一流的（像陈金华老师和金钟植老师，这里就不一一列举了）。"——知乎用户

**解读**：这不是虚言。白云中学的名师配置放在**整个白云区**都是顶级的：
- **金钟植**：北京师范大学数学系毕业，**"苏步青数学教育奖"**获得者（全国数学教育最高奖），正高级+特级，2018年被白云区按高层次人才引进
- **陈金华**：广东省特级教师，物理高级教师，华南师范大学教育硕士，现任副校长，广州市物理高考研究组成员
- **潘仕恒**：高中物理正高级教师，广东省名师工作室主持人，广州市基础教育系统名教师
- **黄少华**：英语科骨干教师，被知乎学生点名推荐

**但**——好老师集中在哪里？知乎学生已经回答了：**"来了云中就看你有没有好运气和福气遇到这些好老师了"**。名师班/科创班概率高，普通班概率低。

#### 优势二：创客教育，全区唯一联盟基地

> "白云区创客/STEAM教育联盟基地在白云中学落成"——官方报道

**解读**：这不是招生宣传的噱头。373项竞赛荣誉（2016-2024年，国家级5项+省级46项）、800平方米创客中心、3D打印机+激光切割机的高校级配置——这些是**硬数据**。如果孩子对科创/编程/3D打印有兴趣，白云中学是白云区**唯一的选择**。

#### 优势三：全寄宿+地铁750米，白云区稀缺组合

> "学校地处城市中心，周边是大型社区，人文环境好、空气质量优"——2025年招生简章

**解读**：白云区公办高中中，**全寄宿+地铁750米**的组合只有白云中学。其他同梯队学校（彭加木、七十一中）要么宿位有限，要么交通不便。这对白云区远距离学生（太和、人和、钟落潭等）来说是刚需。

#### 优势四：低进高出，"加工能力"有实证

> "不少学生中考入学成绩没达中考第一批投档线，但最终考上985、211大学。"——校方宣传

**解读**：2025年高考600分以上3人（成同学628分、蒋同学607分、陈同学606分），对于入学生源多在600-630分区间的学校来说，这确实说明**部分学生被"加工"出了超出入口水平的结果**。但需注意：这是**个别案例**，不是系统性成果。

### 9.3 核心劣势（带原声引用）

#### 劣势一："垃圾学校中的战斗机"（知乎实锤）

> "在广州市白云中学就读根本就是在'渡劫'，毫无体验之说。这就是一所广州市垃圾学校中的战斗机。假如你不想高考、不想考一个好的大学、想度过一个舒适又快乐的高中三年，这所学校会是你的最佳选择之一。"——知乎用户（2022年6月）

**解读**：这是白云中学民间口碑中**最尖锐、传播最广**的一条评价。虽然措辞极端，但折射出几个真实问题：
- **学习氛围松散**：对于想"拼高考"的学生来说，周围太多"躺平"的同学会严重拉低学习动力
- **普通班"渡劫"**：进不了名师班/科创班的学生，学习体验确实可能很差
- **校风争议**：贴吧热帖第一条就是"云中校风怎么样"，说明这是**最大关切**

**结论**：这条评价虽然偏激，但并非空穴来风。它精准指向了白云中学的核心矛盾——**名师很牛，但普通班的体验配不上这些名师**。

#### 劣势二：重理轻文，文科被系统性忽视（知乎实锤）

> "不得不提的是学校对文科的态度，学校对培养文科尖子生不感冒，相反更注重培养刚刚好过本科线或者是接近本科线的同学，这与理科那边的培养方式有所不同。"——知乎用户

> "我没听到过学校对文科有上线人数要求（指一本线）。"——知乎用户

**解读**：这两条评价组合在一起，勾勒出白云中学**文科方向的结构性弱势**：
- 学校**不重视文科尖子生培养**，目标只放在"过本科线"
- 理科方向**有明确的上线人数要求**，文科方向**没有**
- 这不是个别老师的偏见，而是**学校管理层的资源倾斜决策**
- 2025年高考纯文理特控率12%，如果文科特控率更低（大概率如此），说明文科学生几乎被"放弃"了

**结论**：选历史方向的学生，白云中学可能是白云区**最不该来**的学校之一——即使师资好，资源也不向你倾斜。

#### 劣势三：食堂改革引发学生不满

> "本来十块钱一顿饭有菜有肉，两块钱一碗汤，早餐5块，吃一顿刷一次卡。后来经过改革变成强制性消费，你吃不吃都得交钱，午餐晚餐所有菜品一律12，早餐6块，汤水免费（并不是什么时候都有）。本来价格提升质量也该提升吧？"——知乎用户

**解读**：校方宣传的是"A级食堂、刷脸就餐、品类丰富"，但学生真实体验是：**改革前性价比高，改革后强制消费+价格上涨+质量没跟上**。12元一顿对住校生来说是刚需消费，改革等于**变相涨价**。需要注意的是，这是2022年前后的评价，2024年食堂扩容升级后情况可能已有改善。

#### 劣势四：校区被马路一分为二

> "学校分为两个区，教学楼饭堂男生宿舍操场在南区，女生宿舍小操场艺术楼在北区，两个区之间间隔一条马路。"——知乎用户

**解读**：这不是小事。高中三年每天多次穿越马路（课间换教室、食堂、宿舍），存在**安全隐患**和**时间成本**。虽然校方可能已设置天桥或斑马线，但南北区物理分隔是**无法改变的事实**。

### 9.4 班型分层实录：名师班是唯一的"安全区"

#### 分层结构

| 层级 | 班型 | 入学门槛 | 师资水平 | 选科限制 | 学习氛围 |
|------|------|---------|---------|---------|---------|
| **第一层** | 名师班（云班） | 中考高分+签约/排名前列 | 最优师资（金钟植、陈金华等） | 物理方向为主 | 最好，竞争氛围 |
| **第二层** | 科创班 | 中考前160名 | 优秀师资 | 物理方向为主 | 较好，科创特色 |
| **第三层** | 平行班 | 其余学生 | **良莠不齐** | 含历史方向 | 松散，躺平者众 |

#### 关键发现

1. **名师班是唯一的"值"来白云中学的理由**——知乎学生直言"来了云中就看你有没有好运气和福气遇到这些好老师了"
2. **校方声称"各班级教师团队没有明显差异"**——知乎学生评价直接打脸："老师师资良莠不齐，要课讲的好的负责的老师有，照本宣科上课装装样子的也有"
3. **平行班=渡劫**——如果进不了名师班/科创班，白云中学的学习体验可能大幅下降
4. **高一入学按中考成绩分班**：2026年校长直播间预告"市一模排名靠前者进云班和科创班机会大"
5. **选科后重新分班**：高二选科后，平行班中成绩优异者有机会升入名师班——这是唯一的"翻身"机会

### 9.7 "金沙洲top3"的梗与真相

这是白云中学民间口碑中一个**极具戏剧性的梗**：

**解读**：
- 学生自己拿"top3"来自嘲，说明他们**也知道自己学校在白云区的位置**

- "金沙洲top2"可能更准确——但"top2"没有"top3"有梗
