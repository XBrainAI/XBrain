## 2. 办学性质与历史沿革

### 2.1 办学性质

广州市天河职业高级中学是**天河区教育局直属的公办全日制国家级重点中职 + 首批综合高中试点校**，兼具中职教育和普通高中教育双重办学资质。

**关键性质辨析**：
- **天河区唯一公办中职**——区域垄断性地位，区内无同级竞争对手
- **综合高中试点**——入学获普高学籍，高一结束后可自主决定保留或转入中职
- **奥体教育集团**——与广州奥林匹克中学共享教研资源
- **实际定位**：公办综合高中 = 普高学籍 + 中职技能 + 双赛道 + 天河区第四批唯一公办普高

### 2.2 历史沿革

| 时间 | 事件 |
|------|------|
| 1970年代 | 学校创办（最初为普通中学） |
| 1986年 | 正式开办职业教育，从区办职业高中班起步 |
| 2000年前后 | 被评为国家级重点中等职业学校 |
| 2010-2020年 | 在沙河校区基础上，增设棠德校区、科韵校区，并开办附属幼儿园 |
| 2024年 | 入选**广州市首批5所综合高中试点学校**，首年招200人，录取平均分约600分 |
| 2025年 | 综合高中扩招至400人，录取最低511分、平均580分；校长马新→张毅交接 |
| 2026年 | 综合高中再扩容至500人（计算机网络技术300人+金融事务200人），新招13名在编教师 |

### 2.3 综合高中改革——"职普融通"的天河样本

与贸易职中同为广州首批综合高中试点，天河职中的特色在于：

| 对比维度 | 天河职中 | 贸易职中 |
|---------|---------|---------|
| 隶属 | 天河区 | 越秀区 |
| 综合高中规模 | 500人（2026年） | 324人 |
| 专业方向 | 计算机网络技术 + 金融事务（2个） | 多个中职专业 |
| 三校区分工 | 沙河(中职)/棠德(综合高中)/科韵(成人) | 两校区 |
| 教育集团 | 广州奥林匹克教育集团 | 无 |
| 艺考/特色 | 明确布局艺考、日语、体育 | 无人机、大数据等 |
| 住宿 | 少量宿位（棠德） | 无住宿 |

## 3. 三大校区与硬件设施

### 3.1 校区分布与功能分工

| 校区 | 地址 | 承载功能 | 住宿 |
|------|------|---------|------|
| **沙河校区** | 广州市广州大道中1247号 | 中职教育主校区 | 走读为主 |
| **棠德校区** | 广州市天河区棠德路121号 | **综合高中主校区** | 少量宿位 |
| **科韵校区** | 天河区科韵路 | 成人教育/社区教育/特殊教育 | — |

**校区选择**：综合高中学生主要在**棠德校区**就读；中职专业学生主要在**沙河校区**。两大校区均位于天河核心区，交通便利。

### 3.2 硬件设施

- 校园设施较新，实训设备投入优于多数同类区属中职学校
- 计算机、学前教育专业实训设备为**省重点配置**标准
- 与唯品会等企业有合作实训基地
- 属于老城区公办学校中校园面积和硬件条件中上水平

### 3.3 地理位置优势

- 沙河校区紧邻广州大道中，毗邻天河体育中心、广州东站
- 棠德校区位于棠德花园大型住宅区侧
- 双校区均在天河核心区域，通勤便利
- **天河区第四批次唯一公办普高**——位置优势对于天河考生尤为突出

## 7. 综合高中——核心赛道

### 7.1 学籍互转机制

| 状态 | 说明 |
|------|------|
| **入学时** | 统一注册**普通高中学籍** |
| **高一课程** | 以普高文化课为主，辅以职业认知课 |
| **高一结束** | 学生及家长自主决定保留普高学籍或转入中职学籍 |
| **转入中职** | 专业不变（计算机网络技术或金融事务），改走职教高考路线 |
| **法律保障** | 2026年3月《广州市职业教育促进条例》正式施行，学籍互转上升为法定机制 |

### 7.2 "双轨升学"路径

| 路径 | 保留普高学籍 | 转入中职学籍 |
|------|------------|------------|
| 考试类型 | **夏季高考** | **职教高考（3+证书）** |
| 考试科目 | 语数英+物/历+选考 | 仅语数英三科 |
| 竞争强度 | 全省百万考生 | 仅中职生竞争，远小于夏季高考 |
| 可报考院校 | 全国所有本科/专科 | 省内本科/专科 |
| 适合人群 | 文化课基础好、目标全国名校 | 文化课中等但有技能特长 |

### 7.3 特色升学方向

| 方向 | 进展 |
|------|------|
| **艺考** | 已开设日语课程（满足小语种高考生需求），计划发展美术/传媒艺考 |
| **体育** | 依托广州奥林匹克教育集团资源，对接奥体中心，布局体育高考 |
| **小语种** | 日语课程已落地，适合英语薄弱但有小语种兴趣的学生 |

### 12.6 最终建议

**一句话总结**：广州市天河职业高级中学是**天河区中考520-560分段考生最该填在第四批第一志愿的学校**——没有之一。理由很简单：它是天河区第四批次**唯一**能给你公办普通高中学籍的学校。

**核心价值 = 兜底 + 选择权**：
- "兜底"——即使前三批全部滑档，你仍然有公办普高可上
- "选择权"——高一结束你可以自由选择走夏季高考还是职教高考，哪一种更适合你

**必须接受**：走读（不住宿）、学校"职中"背景标签、综合高中新模式的首届出口还需1-2年才能最终验证。
