| 年份 | 事件 |

| **1917年** | 在西禅寺原址建起**广州模范学堂**，标志这片土地告别暮鼓晨钟迎来朗朗书声 |

| **1945年** | 抗战胜利后，国民政府在此建**广州市立师范学校** |

| **2017年** | 举办百年校庆，成为广州"百年老校" |

## 二、集团化办学格局

广州四中是荔湾区最早推进集团化办学的学校之一，已形成**"一家十园"**办学格局：

| 学段 | 校区 | 备注 |
|------|------|------|
| **高中** | 锐园（本部）、虬园（新扩建） | 2024年9月虬园新教学楼启用 |
| **初中** | 康园（原聚贤中学）、雁园、津园、逸园、茂园、鎏园 | 康园为原四中聚贤中学，荔湾区优质初中 |
| **小学** | 芦园、耀园 | — |

> **集团化优势**：初中-高中贯通培养，子弟兵直升通道；集团统一文化标识，形成"一家十园，一园一'景'（特色）"格局。

### 6.2 分数线趋势解读

| 现象 | 分析 |
|------|------|

> **关键信号**：2025年四中末位志愿序号为2（录到第二志愿），说明报考热度有所下降，这对2026年考生可能是一个"低分搏入"的窗口期。

### 9.2 负面评价与争议

#### 9.2.1 高考出口整体偏弱——"进锐志班是另一个世界"

这是民间口碑中**最核心**的负面评价：

| 问题 | 描述 |
|------|------|
| **普通班出口弱** | 全校特控率41%-42%，但锐志班98%，意味着**普通班特控率仅约15%-20%**，普通班本科率也不高 |
| **两极分化严重** | "进锐志班是另一个世界"——大锐班/小锐班与平行班的教学质量、学习氛围差距极大 |
| **与一中对比** | 一中院士班特控率85%-95%+本科率100%，四中锐志班特控率98%看似更优，但一中整体本科率96.4%远高于四中91%——**四中普通班的出口数据堪忧** |
| **600分以上人数少** | 2023年仅31人600分以上，说明尖子生绝对数量有限 |
| **知乎学生原话** | "1-6都还算不错，但不排除排名比较低的人，7-12班有一些是好但总体寄，老师重心不会放在上面"（小锐班学生） |

> **关键洞察**：选择四中，**本质上就是选择能否进入锐志班**。如果只能进普通班（7-14班），四中并非理想选择。

#### 9.2.2 食堂——"反人类"的伙食

这是四中民间口碑中**被吐槽最猛烈**的负面评价，程度远超一中：

| 问题 | 学生/家长原话或描述 |
|------|-------------------|
| **米饭半生不熟** | "两口能吃完的半生不熟的米饭，周一到周五亘古不变不放任何调味料的菜杆子，翠绿里透着屎黄"（知乎外区生答主） |
| **荤菜极度难吃** | "荤菜像开水烫死的猪直接摆在餐桌上，5块肉里有6块焖烂了的肥肉"（知乎外区生答主） |
| **调味失控** | "对配料的掌控更是个重量级，有时啥也不放，肉比我溺水死了三天后的脸还白。有时又咸到吃一口直接给爷干成脱水"（知乎外区生答主） |
| **单一食堂** | 只有一间饭堂，选择有限，与一中两层+两家公司竞争形成鲜明对比 |
| **会考期间无饭** | "会考期间已经是散学典礼之后，没有食堂阿姨煮饭，晚餐跟早餐只能自己出去吃比较浪费复习时间"（小锐班学生） |
| **乱扣钱** | "四中的饭菜简直了，有时候不吃会乱扣钱特别讨厌"（贴吧用户） |
| **比外面还差** | "四中饭堂的伙食很差，比学校对面的早餐店还差"（贴吧帖子标题） |

> **客观评价**：四中食堂问题是民间口碑中最突出的短板。与一中的"两层食堂+竞争机制+网红水吧"形成巨大反差。2025年4月，四中教育集团启动了"食堂运营服务和食堂食材"招标，说明校方已意识到问题，但改善效果尚待观察。

#### 9.2.3 校长更迭——王金阳离任的连锁冲击

这是2025年四中最受关注的重大变化：

| 时间 | 事件 | 影响 |
|------|------|------|
| **王金阳治校期** | 四中分数线从630分区间涨至655分（2024年），涨幅约20分 | 王金阳被公认为四中近年上升势头的关键推手 |
| **2025年9月** | 王金阳校长调任广州一中 | 被民间解读为荔湾区教育局的重大人事布局——"让四中校长去拯救一中" |
| **2025年分数线** | 四中暴跌28分至627分 | 与一中628分几乎持平，两校地位逆转；2024年四中655分>一中652分，2025年四中627分<一中628分 |
| **继任者未明** | 四中新校长身份未广泛公开 | 家长对四中未来发展方向的担忧加剧 |

> **深度分析**：王金阳离任对四中的冲击是全方位的：
> 1. **招生信心**：家长普遍认为"校长都走了，四中还能不能好？"——信心动摇直接影响报考意愿
> 2. **锐志班师资稳定**：王金阳时期的师资团队是否会随其离任而调整，尚不确定
> 3. **反面对比**：王金阳在一中"新官上任"可能给一中带来提升，此消彼长加剧四中劣势
> 4. **民间质疑**："四中连自己的校长都留不住，说明什么？"——虽然有情绪化成分，但反映了家长的真实担忧

#### 9.2.4 初中部校园霸凌争议

这是四中民间口碑中**最沉重**的负面评价，虽主要涉及初中部，但直接影响家长对四中教育集团的信任：

| 问题 | 详细描述 |
|------|----------|
| **长期校园霸凌** | "初中时在四中聚贤（现广州四中雁园校区）遭遇了长期的校园霸凌""课室里就能当着快40个人的面殴打我"（知乎用户） |
| **校方处理不力** | "钟心级长顾着评比应付上级演戏，必须要营造出来和谐的气氛，所以下面乱成什么样，什么校园霸凌，通通是没有的"（知乎用户） |
| **举报遭威胁** | "你知道你这样在网上骂人是违法的吗""网上骂人违法，但是校园霸凌不违法，你们是真聪明啊"（知乎用户引述校方回应） |
| **班主任管理缺位** | "夏胜管理的一个班级都参与了对我的校园霸凌"（知乎用户） |
| **"红色学校"讽刺** | "红色学校红色学校，指可以见红的学校"——学生将"红色四中"的正面品牌反讽为暴力 |

> **客观评价**：
> - 上述负面评价**主要针对四中初中部（原聚贤中学，现雁园校区）**，不直接代表高中部情况
> - 但对家长而言，**初中部的管理风格往往被视为教育集团整体管理水平的缩影**
> - 四中高中部是否同样存在"重评比轻治理"的管理倾向，**值得2026年家长持续关注**
> - 高中部与初中部在管理层级、教师队伍上并不相同，**不宜以初中部问题直接推断高中部**

### 9.3 "三强走位"——荔湾区一中·四中·西外的竞争格局变迁

2025年后的民间分析认为，荔湾区三强格局已发生**根本性逆转**：

#### 9.3.1 从"一中独大"到"三足鼎立"

| 时期 | 格局 | 核心依据 |
|------|------|----------|
| **2023年及之前** | 一中 > 四中 ≈ 西外 | 一中分数线明显高于四中和西外 |
| **2024年** | 一中 ≈ 四中 > 西外 | 四中655分几乎追平一中652分，但西外意外录得652分 |
| **2025年** | 一中 ≈ 四中 > 西外 | 一中628分vs四中627分，几乎持平；西外610分差距拉大 |

#### 9.3.2 "四中压着一中打"——加工能力反转

民间分析中最具冲击力的判断：

| 对比维度 | 数据 | 解读 |
|----------|------|------|
| **入口差距** | 2024年一中652分 > 四中655分→**实际四中已反超** | 但以更早年份看，一中录取线长期高于四中14分以上 |
| **出口反转** | 2025年四中特控率41%-42% > 一中37.6% | "以流出的数据看……4中超将近10个点"（头条分析文章） |
| **本科率差距** | 一中96.4% >> 四中91%+ | 一中普通班本科率远高于四中——四中"头重脚轻" |
| **民间定性** | "1中短时间落得'区老四'的称呼" | 一中在四中和西外的夹击下暂时掉到第四 |

> **民间核心结论**：
> - **四中和西外近年加工能力得到充分肯定**——"当年同届入口，一中录取分数线可是多14分"
> - **一中"外在会被赶上"**——全宿位+新校园硬件的吸引力不可持续，"考试终归要用成绩说话"
> - 但四中的隐忧是：**如果校长更迭导致锐志班质量下滑，加工能力优势可能不保**
