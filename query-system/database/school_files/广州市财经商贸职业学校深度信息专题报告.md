## 2. 办学性质与历史沿革

### 2.1 办学性质

广州市财经商贸职业学校是**广州市教育局直属的公办全日制中等职业学校**，不涉及综合高中试点，定位纯粹为中职教育，以"升学+就业"双出口为核心竞争力。

**关键性质辨析**：
- **市属公办**——非区属，资源保障更充足，覆盖面更广
- **非综合高中**——不能获得普高学籍、不能参加夏季高考（区别于贸易职中）
- **纯中职**——核心路径为三二分段、高职高考（3+证书），可升本、读研
- **实际定位**：公办全国示范中职 = 职教领头羊 + 三二分段直通车 + 升本通道

### 2.2 历史沿革

| 时间 | 事件 |
|------|------|
| 1960年 | 广州财政学校成立（最早溯源） |
| 1960年代-2020年 | 广州市财经职业学校、广州市商贸职业学校分别发展壮大，均为广州财经商贸类中职标杆 |
| 2020年7月 | **三校整合**：广州市财经职业学校 + 广州市商贸职业学校 + 广州市司法职业学校 → 合并组建"广州市财经商贸职业学校"，隶属广州市教育局 |
| 2021年至今 | 整合后快速发展，成为广东省高水平中职学校建设单位 |

**三校整合的意义**：将原三家各自领域的龙头中职（财经类、商贸类、司法/公共安全类）强强联合，形成了覆盖财金、商务、贸易、物流、法律、公共服务等多领域的全产业链职业教育矩阵。整合后的在校生突破万人规模，成为广州中职"超级航母"。

## 7. 三二分段——核心升学通道

### 7.1 三二分段机制

| 阶段 | 学制 | 学位/证书 |
|------|------|----------|
| 前三年（中职） | 在财经商贸学校就读 | 中职毕业证 + 技能证书 |
| 后两年（高职） | 对口高职院校就读 | **全日制大学专科文凭**（与夏季高考入学者完全一致） |

### 7.2 三二分段优势

| 维度 | 说明 |
|------|------|
| **确定性** | 中考填报即锁定高职学位，无需再参加全省统考 |
| **省时间** | 5年获得全日制大专，比"高中3年+大专3年"节省1年 |
| **免高考** | 转段考核为过程性考核，最终考核合格即可升学 |
| **专本衔接** | 获得大专文凭后可继续通过"专插本（普通专升本）"考取全日制本科 |
| **名企就业** | 合作企业包括京东、唯品会、沃尔玛等 |

### 7.3 2025年三二分段对接高职（16所）

对接的均为省内知名公办高职院校：

| 对接高职 | 类型 |
|---------|------|
| **广州番禺职业技术学院** | 国家示范性高职/双高计划 |
| **广东轻工职业技术学院** | 双高计划 |
| **广东工贸职业技术学院** | 省示范 |
| **广东农工商职业技术学院** | 省示范 |
| 其他12所省内公办高职 | — |

### 7.4 三二分段注意事项

- 独立编班，纳入"中高职一体化"人才培养计划
- **存在淘汰机制，只出不进**——需通过所有对口核心课程
- 学籍为**中职学籍**，不能参加夏季高考
- 若被淘汰，可转为三年制中职班，通过高职高考升学

## 12. 志愿填报建议与决策参考

### 12.1 志愿填报操作指南

| 步骤 | 内容 |
|------|------|
| **目标批次** | 第一批次（三二分段/省级重点特色专业）+ 第四批次（其他全日制中职） |
| **填报建议** | 建议在第一批及第四批的**第一志愿**均填报该校 |
| **招生代码** | 广州考生：**00305**；省内其他地市考生：**8800055** |
| **省内其他地市** | 在当地中考志愿表的"市外中职学校"批次**第一志愿**填报 |

**填报提醒**：
- 三二分段在第一批次录取，录取后不再参与后续批次
- 建议将最想去的三二分段专业填在第一批第一志愿
- 未被三二分段录取的考生，仍可在第四批次被普通中职专业录取
- 自主招生（凭中考成绩）在按志愿录取之后，约8月初开始

### 12.2 适合什么样的考生？

| 非常适合 | 适合 | 不太适合 |
|---------|------|---------|
| ✅ 中考分422-550区间，对财经/商贸/电商/法律等有明确兴趣 | ✅ 想省钱省时拿到全日制大专文凭（三二分段5年拿大专 vs 普高+大专6年） | ❌ 目标985/211本科，不接受中职标签 |
| ✅ 动手能力强，希望学一技之长 | ✅ 公办高中无望（低于普高线502分），但不接受无书可读 | ❌ 坚定走夏季高考路线 |
| ✅ 走"职教升本"路线（中职→3+证书本科→考研） | ✅ 希望"包就业"保障 | ❌ 对全封闭/准军事化管理强烈抵触 |
| ✅ 愿意走"三二分段直通车"锁定公办大专学位 | ✅ 农村户籍（免学费+助学金） | ❌ 必须走读且目标专业在龙归/大坦沙/鹤龙 |

### 12.3 分路径决策矩阵

| 目标 | 推荐路径 | 说明 |
|------|---------|------|
| 确定想上本科 | 三年制中职 → 参加高职高考（3+证书）→ 报考省内本科 | 491人上线23.5%本科率，省内本科如韩山师范、嘉应学院等 |
| 想稳妥拿全日制大专 | 三二分段 → 5年直升大专 | 无需高考，转段考核通过即可；大二/大三可专插本 |
| 对电商/会计/税务有浓厚兴趣 | 第一批次三二分段第一志愿填报 | 锁定学位，5年后拿全日制大专 |
| 中考分低于422 | 第四批次填报三年制中职 | 中职控制线较低，录取概率大 |
| 成绩中等但不确定方向 | 先报三二分段 | 多一层保险——录了直接锁定大专，未录还可走第四批常规中职 |

| 竞争力 | 评级 | 说明 |

| 升学路径 | ⭐⭐⭐⭐⭐ | 三二分段1,695人 + 本科491人（23.5%）+ 专科91.2% |

### 12.5 最终建议

**一句话总结**：广州市财经商贸职业学校是**广州市教育局直属的全国示范性中职"超级航母"**，适合以下三类考生——

1. **"弯道超车型"**：中考400-550分，通过三二分段5年拿全日制大专，省时省钱；
2. **"技能成才型"**：对会计/电商/跨境电商/视光等有浓厚兴趣，学一门手艺即可就业；
3. **"升本潜力型"**：通过三年制中职+高职高考（3+证书），走"中职→本科→考研"的独特上升通道。

**唯一需要说服的是"面子问题"**——当985/211同班同学可能高考落榜、复读、进专科时，你已通过三二分段稳稳拿下了全日制大专学位，还比他们早一年进入职场。这所学校的核心价值在于：**提供了一条比"普高→高考"更短、更稳、更省的通向全日制大专/本科的替代路径**。
