## 2. 办学性质与历史沿革

### 2.1 办学性质

广东实验中学越秀学校是**越秀区教育局直属的公办完全中学**，由**广东实验中学全面管理**。这一独特的"区属+省实管理"架构，使其在体制上属越秀区管，但在教学和管理上直接接受省实本部的指导和资源输出。

**关键性质辨析**：
- **不是省实本部**——省实越秀 ≠ 广东实验中学（本部）
- **区属公办**——与越秀区其他区属高中（如三中、七中、十六中、培正等）属同一行政层级
- **省实管理**——校长由省实派驻或任命，教学体系向省实看齐
- **实际定位**：越秀区属示范性高中 + 省实品牌加持 = "省实系第二梯队"

### 2.2 历史沿革

省实越秀的诞生是越秀区教育布局优化的结果：

| 时间 | 事件 |
|------|------|
| 1954年前后 | 广州市第二十一中学创立（最早可追溯到广州师专附中、广东师范学院附中） |
| 20世纪 | 广州市越秀外国语学校创立（原广州第27中学等合并转型） |
| 2018年5月 | **两大老牌学校合并**：广州市第二十一中学 + 广州市越秀外国语学校 → 组建"广东实验中学越秀学校"，由广东实验中学全面管理 |
| 2018年8月 | 省实越秀正式挂牌运作，天胜校区（原二十一中）+ 盘福校区（原越秀外国语） |
| 2019年至今 | 在省实管理体系下稳步发展，逐步提升品牌知名度和教学质量 |
| 2025-2026年 | "从名不见经传到成为省实系热门校"——社会关注度显著上升 |

### 2.3 合并前的两所学校

| 前身 | 原性质 | 历史底蕴 |
|------|--------|---------|
| **广州市第二十一中学** | 越秀区公办完全中学 | 1954年创立，省一级学校，越秀区老牌中学之一 |
| **广州市越秀外国语学校** | 越秀区公办外国语特色中学 | 越秀区外语教育传统学校 |

**合并意义**：两校地理位置接近（均在越秀核心区），合并后实现资源整合，叠加省实品牌和管理体系，从"区里面中规中矩的两所学校"一跃成为"有省实品牌背书的区域热门校"。

## 4. 师资力量与领导团队

### 4.1 师资概况

- 省实越秀的师资由三部分构成：原二十一中教师 + 原越秀外国语教师 + 省实本部支援教师
- **省实管理输出**：省实本部在教学管理、教研培训、质量监控等方面全程介入
- 教师队伍中高级职称占比实现省一级学校标准

### 4.2 领导团队

| 职务 | 姓名 | 背景 |
|------|------|------|
| **校长** | **戎振纲** | 由省实系统派驻（曾为新教师培训开讲、多次出席学校重要活动并发言） |

**校长对外形象**：省实体系派人，强调教学质量提升和教师队伍建设。在公开场合讲话中多次提及"深度求索，学业登峰"等省实一脉相承的教育追求。

### 4.3 省实管理机制

| 维度 | 省实本部介入程度 |
|------|---------------|
| 校级领导 | ✅ 校长由省实系统派驻 |
| 教学管理 | ✅ 向省实本部看齐 |
| 教研培训 | ✅ 省实本部资源共享 |
| 联考对标 | △ 有尝试与省实本部联考（使用本部命题），"效果可想而知"——说明差距客观存在 |
| 学生流动 | △ 极少数优秀学生有机会到省实本部交流学习 |

**本质上**：省实越秀是"省实的牌子、越秀的底子、两校合并的师资"。省实品牌是真实的加分项，但教学质量与省实本部仍有显著差距。

## 8. 与省实本部的关系

### 8.1 省实越秀 ≠ 省实本部

这是考生和家长最容易产生的**认知误区**。省实越秀与省实本部的关系，可以类比为"加盟店"与"总店"的关系：

| 维度 | 省实本部 | 省实越秀 |
|------|---------|---------|
| 行政归属 | **广东省教育厅直属** | **越秀区教育局** |
| 录取批次 | 第一批/第二批/第三批 | 第三批为主 |
| 2025年分数线 | 户籍735分 | 户籍**627分**（低108分） |
| 2024年特控率 | ~95%+ | 预估30-45% |
| 招生范围 | 全市 | 全市（以越秀为主） |
| 学校定位 | 省市属顶级名校 | 越秀区属示范性高中 |

### 8.2 "省实牌子"的价值

| 价值的真实面向 | 说明 |
|--------------|------|
| ✅ 课程体系 | 向省实看齐，使用省实教研资源 |
| ✅ 教学管理 | 校长由省实派驻，管理体系对接 |
| ✅ 品牌声誉 | "省实"二字在家长心智中有加分 |
| ✅ 师生交流 | 部分教师/学生有机会赴本部交流 |
| ❌ 生源质量 | 627分 vs 735分，差距巨大 |
| ❌ 教学质量 | 教学难度和深度与本部不可同日而语 |
| ❌ 升学出口 | 本部985/211录取率远超省实越秀 |

**一句话总结**："省实越秀可以给你省实的理念和管理，但给不了你省实的生源和出口。"

| 维度 | 口碑内容 |
|------|---------|

| **分数线波动大** | 2021年低至601分，2022年又飙至670分，不够稳定 |
| **普通班被"放养"** | 师资和资源向特色班倾斜，普通班关注度相对不足（网络反馈） |

## 12. 志愿填报建议与决策参考

### 12.1 志愿填报操作指南

| 批次 | 填报建议 |
|------|---------|
| **第一批** | 有特长生资格（足球/美术/女篮/健美操/无线电测向）可填报 |
| **第二批** | 名额分配到校，根据本校往年分配名额和分数线决定是否填报 |
| **第三批** | **户籍生627分、非户籍641分为参考**，第一至第三志愿均可填报 |

**填报提醒**：
- 省实越秀在越秀区属高中属中游，七中/十六中/培正/三中在前，省实越秀在后
- 分数线三年稳定在627-635，处于第三梯度线附近
- 名额分配是重要路径，往年部分初中605-610分即可录取

| ✅ 分数在名额分配线上，可通过本校指标"捡漏" | — | ❌ 误以为"省实越秀=省实本部" |
| ✅ 在越秀区走读方便 | — | — |

### 12.6 最终建议

**一句话总结**：广东实验中学越秀学校是**越秀区620-650分段考生的优质公办选择**——"省实"的品牌背书、越秀核心的地理位置、省实班90%的特控率，都是真实的价值。但它**不是省实本部**，请带着正确的预期来评价它。

**三个关键认知**：
1. **品牌 ≠ 本部**：省实越秀能给的是省实的管理理念和课程体系，不是省实本部的生源和出口
2. **特色班 > 学校**：进省实班/南山班的价值远大于进平行班，建议尽量争取
3. **能走读 = 能选**：有住宿刚需的考生请慎重，280宿位极其紧张
