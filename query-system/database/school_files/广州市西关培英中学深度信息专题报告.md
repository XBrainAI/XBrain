## 二、百年校史·从培英书院到西关培英

### 2.1 培英源流（1879-1927）

| 年份 | 事件 |
|------|------|
| **1879年** | 美国那夏礼博士在广州芳村白鹤洞创办**培英书院** |
| **1912年** | 改称广州私立培英中学 |
| **1919年** | 增由同寅、公理两教会协同襄理 |
| **1926年底** | 教育部颁布私立学校规程，限制外国教会在华办学，校董会全部移交中华基督教会 |

### 2.2 西关分校创立（1927-1952）

| 年份 | 事件 |
|------|------|
| **1927年** | 叶启芳校长倡议增设西关分校，委任区茂泮为分校主任 |
| **1928年** | 正式定名为**培英中学西关分校**（简称"培英西分"） |
| **1931年** | 刘继祖校长在多宝路购地二亩半自建分校舍 |
| **1935年** | 增设幼稚园 |
| **1937年秋** | 抗战爆发，幼稚园停办，仅20余人继续开课 |
| **1938年** | 区茂泮主任率部分教工迁往澳门继续开课；原校址被日伪政府改名"广东省立第一中学" |
| **1945年** | 抗战胜利，余日森主任返广州复校 |

### 2.3 更名与复名（1952-1998）

| 年份 | 事件 |
|------|------|
| **1952年夏** | 与坤维女子中学、长城中学、莞旅中学、培中中学、复旦中学**六校合并**，改名**私立荔湾中学** |
| **1956年** | 改设为**公立广州市第二十九中学** |
| **1996年8月** | 新校友会成立，校友强烈要求复名 |
| **1998年10月13日** | 获批重新更名为**西关培英中学** |
| **1999年5月1日** | 举行更名揭幕仪式 |

### 2.4 现代发展（2001至今）

| 年份 | 事件 |
|------|------|
| **2001年8月** | 荔湾区政府决定将广州市第九十中学与西关培英中学合并 |
| **2003年4月** | 成为**市一级学校** |
| **2023年** | 改扩建项目通过荔湾区发改局审批（区民生实事项目） |
| **2024年12月** | 成功申报**国家级武术进校园试点单位** |
| **2025年12月** | 改扩建项目进入环评审查阶段，计划开工 |
| **2027年（预计）** | 新校区高中教学楼计划投入使用 |

### 9.3 生源困境——"被动接收"的恶性循环

**这是西关培英口碑中最深层、最难解的结构性问题。**

#### 补录生源为主

> 🗣️ *"西关培英的生源相当一部分来自补录，属于被动接收状态，生源质量堪忧。"*
> —— 网易号·荔湾区高中概述

**补录意味着什么**：
- 补录考生是在其他批次/学校落选后"兜底"进入西培
- 这些学生的中考成绩通常低于学校正常录取线
- 补录比例越高，整体生源质量越低

#### 非户籍生扛大旗

> 🗣️ *"年级头部和特控率数据，基本上全靠非户籍生顶住。"*
> —— 网易号·荔湾区高中概述

**非户籍生现象解读**：

| 维度 | 说明 |
|------|------|
| **什么是非户籍生** | 非广州户籍但在广州参加中考的学生 |
| **为什么非户籍生分数线高** | 2025年西培非户籍生线642分 vs 户籍生604分，差38分 |
| **意味着什么** | 非户籍生入学成绩更高、学习动力更强，成为学校高考数据的"顶梁柱" |
| **户籍生的处境** | 入学分数低、竞争意识弱，在年级中处于"被拖着走"的状态 |

> ⚠️ **家长警示**：如果您是户籍生家长，需要清醒认识到——孩子的同班同学中可能有相当比例是分数比自己高38分的非户籍生，"年级排名"的含义与想象中不同。

#### 第四批次的"马太效应"

- 第四批次 = 第三批次落选的考生 → 生源质量天然低于第三批次学校
- 生源差 → 高考成绩差 → 口碑差 → 优秀生源更不愿来 → 生源更差
- 唯一破局点：**新校区硬件升级 + 申报省一级 + 进入第三批次招生**

### 9.4 师资争议——"复读机式教学"与"当众骂哭学生"

**这是西培口碑中最尖锐、最令家长不安的负面信息。**

#### 正面声音

> 🗣️ *"老师师资很不错，基本都是五六年教龄的老师。老师上课很有趣，不怎么拖堂，也很公正主观。"*
> —— 知乎·初中部在读生

> 🗣️ *"学习成绩看自己，校风我觉得是不差的，老师有很多挺尽责的！重点班表示天天磨柱。"*
> —— 百度贴吧

#### 🔴 负面声音一：复读机式教学

> 🗣️ *"很多老师人很好也很多负责，但也有很多的老师不会教学，上课犹如复读机在复述课本或者PPT的内容，没有改述或者不懂得如何换一种方式去陈述给学生，（说人话就是）不懂得怎么解释知识点让学生更容易理解这个知识点。最终的结果就是学生成绩不好，教学效果不理想。"*
> —— 知乎·高中部毕业生（2018届）

> 🗣️ *"也有上课只读PPT，下课撒手不管的老师；还有那种给你布置莫名其妙任务的老师。"*
> —— 知乎·另一毕业生

#### 🔴 负面声音二：打压学生与情绪失控

> 🗣️ *"绝大部分老师是专业负责的，只是有些老师言行会很奇怪（打压学生之类的），高考前一个月老师当众骂哭无辜同学的事也是有的，需要内心足够强大才能面对（当然那位同学委屈也属实正常）。"*
> —— 知乎·2023年高赞回答

#### 🔴 负面声音三：罚抄式管理

> 🗣️ *"我高中的语文老师，不在她课上举手就要被罚抄，答不上来也要被罚抄，作为组长你组员没做好作业被她发现罚抄双倍。"*
> —— 知乎·毕业生

#### 🔴 负面声音四：29中改名后的师资困境

> 🗣️ *"我也承认很多老师都是原29中时代教过很多很好的学生（西培曾经是29中，后改名西培），改了名后的29中即如今的西培高中所招的学生水平参差不齐后导致教学质量直线下降。"*
> —— 知乎·2018届毕业生

**师资争议的核心逻辑**：

| 问题 | 解读 |
|------|------|
| **复读机式教学** | 教师能"读"PPT但不能"讲"PPT——缺少将知识点转化为学生可理解语言的能力 |
| **29中遗产** | 老师们在优质生源时代（29中时期）积累的教学方法，面对参差不齐的生源时失效 |
| **打压与情绪失控** | 个别教师面对不愿意学的学生时，从管理焦虑滑向情绪宣泄 |
| **罚抄式管理** | 用惩罚代替引导，是教学手段匮乏的表现 |
| **"好的老师就是好老师"** | 师资个体差异极大，分到哪位老师全凭运气 |

> ⚠️ **关键区分**：以上负面评价主要来自**普通班**学生，铁军英才班由骨干教师担任班主任，体验可能有显著差异。但这也再次印证了——**进西培，铁军班是必争之地。**

### 9.14 给家长的四条真实建议

1. **"西培最大的期待是2027年新校区"**——如果孩子2026年入学，高一时仍在旧校区，高二起有望搬入配备标准运动场、游泳池、768宿位的新校区。现有硬件的负面评价将在1-2年后得到根本性改善。但**硬件改善不等于教学改善**，家长需理性区分。

2. **"进西培，铁军班是必争之地"**——与十三中一样，西培的重点班（铁军英才班）与普通班的差距明显，甚至更大。普通班"上课打王者""复读机式教学"的负面口碑绝非空穴来风。如果预估分数无法进入铁军班，需认真权衡普通班的学习氛围是否适合孩子。

3. **"不要把'培英'的声誉等同于'西培'的实力"**——两校同源但完全不同层次。抖音24.8万赞的视频说的就是这个道理。西培是广州市一级的保底公办高中，不是培英中学的"荔湾校区"。

4. **"与十三中对比时，要清醒看到差距"**——同为第四批次学校，十三中2025年分数线616 vs 西培604，差12分；但十三中是省一级（参与名额分配）、本科率97%有据可查、口碑中"加工能力"获广泛认可。**西培在数据透明度、本科率绝对值、民间口碑三个维度均弱于十三中。** 604-616分段的考生，建议优先考虑十三中，除非对武术/管弦乐有特长或离家近是刚性需求。
