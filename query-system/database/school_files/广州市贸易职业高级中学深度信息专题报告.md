## 2. 办学性质与历史沿革

### 2.1 办学性质

广州市贸易职业高级中学是**越秀区教育局直属的公办全日制省级重点职业中学**，2024年起同时作为**广州市首批综合高中试点学校**，实现了职业教育与普通高中教育双轨并行。

**关键性质辨析**：
- **公立学校**——按公办标准收费，学费1347-1575元/学期
- **综合高中试点**——学生入学获普通高中学籍，可参加夏季高考
- **职教根基深厚**——同时保留中职专业和三二分段班，出口多元
- **实际定位**：公办综合高中 = 普高学籍 + 中职技能 + 双赛道升学

### 2.2 历史沿革

| 时间 | 事件 |
|------|------|
| 1949年 | 学校创办，与新中国同龄 |
| 1980年代 | 原广州市第37中学高中部改为职业高中 |
| 2003年 | 贸易职中、一商职中、服装职中三校合并为新的广州市贸易职业高级中学 |
| 2004年 | 越秀区成人中等专业学校并入 |
| 此后 | 相继兼并越秀区职业技术学校、中华会计成人中专越秀区分校、广州市财经职业高级中学 |
| 2024年 | 入选**广州市首批5所综合高中试点学校**，首年招224人，录取平均分602.5分排名五校第一 |
| 2025年 | 综合高中扩招至324人；春季高考本科录取59人，蝉联全市第一 |
| 2026年 | 入选广东省普通高中多样化特色发展改革试点培育学校；春季高考本科录取63人，再创历史新高 |

### 2.3 综合高中改革——学校发展的历史转折点

2024年是学校的**根本性转折点**。广州启动综合高中试点，贸易职中凭借深厚的职业教育和优秀的办学基础入选首批名单：

| 改革前 | 改革后 |
|--------|--------|
| 纯中职学校，对口升学为主 | 综合高中 + 中职双轨并行 |
| 学籍为中职学籍 | 综合高中班获普高学籍，可参加夏季高考 |
| 生源分数普遍较低 | 综合高中首年平均分602.5分，高出普高线100分 |
| 主要对接高职院校 | 可冲本科/重本，63人已考入本科 |
| 社会认知"职中"标签 | 综合高中定位"普高学籍+职业素养" |

**核心结论**：综合高中改革让学校完成了从"纯职中"到"普职融通"的质变，一跃成为中低分段学生"弯道超车"的热门选择。

## 7. 综合高中——核心竞争力

### 7.1 什么是综合高中？

综合高中是广州教育改革的新生事物——打破普通教育与职业教育并行壁垒，让学生既有**普高学籍**（可参加夏季高考），又能选修**职业技能课程**（有就业备选方案）。

### 7.2 学籍动态转换机制

学校构建"尊重意愿、双向选择、程序规范、过程透明"的学籍转换机制：

| 转换方向 | 条件 | 时间 |
|---------|------|------|
| 普高学籍 → 中职学籍 | 学生及家长自愿自主选择，无淘汰考核 | 高一结束时 |
| 中职学籍 → 普高学籍 | 需达到综合高中当年最低录取分数线，且学籍有空余 | 高一结束时 |

转换流程：提交书面申请 → 文化课测试 → 学业水平/综合素质评价 → 按空余名额择优确定并公示 → 教育局审批 → 学籍变更。

### 7.3 毕业文凭

综合高中班完成三年学业且成绩合格，颁发**广东省教育厅统一印制的普通高中毕业证书**，与普通高中文凭一致。

### 12.5 最终建议

**一句话总结**：广州市贸易职业高级中学是**中考540-620分段老三区户籍考生**的最佳"兜底+逆袭"选择——普高学籍 + 公办收费 + 低进高出 + 多赛道升学，在任何维度都是超高性价比的组合。

**但必须正视**：不提供住宿意味着仅适合老三区走读家庭；"职中"校名带来的社会偏见可能需要家长主动解释；综合高中新模式的首届完整出口数据还需再等1-2年才能最终验证。
