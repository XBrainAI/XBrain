## 三、校区硬件与环境

### 3.1 校园概况

江南新苑校区原为九十七中初中部校区，2012年启用，位于海珠区核心地段新港西路江南新苑小区旁。2025年起增设高中部，成为初高中混合校区。

| 项目 | 情况 |
|------|------|
| **校园面积** | 中等规模（约1.5万㎡） |
| **绿化** | 绿树成荫，"生态型学校"定位 |
| **教学楼** | 多栋教学楼，常规教室均配多媒体+空调 |
| **实验室** | 常规理生化实验室 |
| **运动场** | 灯光橡塑篮球场、排球场、羽毛球场 |
| **心理辅导** | 专业心理咨询室 |
| **科创设施** | 科创实验室+小程序开发基地 |
| **图书馆** | 共享校本部资源 |

2025年4月，海珠区发改局公示江南新苑校区综合楼新建工程项目审批，2025年8月完成设计招标。这意味着校区正在进行扩容升级，但**新建综合楼在2026年9月入学前能否完工待定**。

### 9.1 "宽松"与"管理严"：97中的双面人设

97中有一个非常矛盾的品牌叙事——官方称"**管理严、校风好**"，但知乎上在读生却说"**宽松、自律**"：

> "97中是一所好学校，如果要用几个词语来形容她，那可能是'**宽松''自律**'。在我目前所知的中学里面，她的教育方式是最接近素质教育的。"——知乎用户（初中部）

> "学校的管理算是很宽松了，这也是我爱97中的其中一个原因。在初三，学校从没有占用周末来补课，也没有提前开学，每天准时6点（有时晚10分钟）放学，一切学习靠自觉。"——知乎用户

> "97中素有'**师资强、管理严、校风正、质量高、特色明**'的社会美誉。"——孔文韬校长寄语（官方）

**矛盾的本质**：

| 维度 | "宽松"叙事 | "管理严"叙事 |
|------|-----------|-------------|
| **来源** | 在读生/校友（体验视角） | 官方/社会评价（品牌视角） |
| **侧重点** | 不补课、不拖堂、不强制、靠自觉 | 校规明确、执行严格、校风正派 |
| **适用对象** | 自律性强的学生 | 需要纪律约束的学生 |
| **真实性** | ✅ 初中部体验属实 | ✅ 高中部的确更严格 |

**关键判断**：97中的"宽松"主要体现在**不占用课外时间**（不补课、不拖堂），而非"不管"。校内纪律（手机管控、校规执行）是严格的，只是不通过延长学习时间来施压。**高中部比初中部更严格**，江南新苑校区全封闭管理更是"宽松"的反面。
