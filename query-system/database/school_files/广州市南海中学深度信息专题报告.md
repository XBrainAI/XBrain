### 1.2 历史沿革

- **1723年**：南海知县捐资创办"南海义学"（学校溯源起点）
- **1803年**：更名为"西湖书院"
- **1904年**：南海士绅在原西湖书院基础上创立简易师范科馆
- **1907年**：西湖书院和南海师范科馆合并为南海中学堂
- **1910年**：学校搬迁至光复中路高第坊芦荻巷
- **1937年**：被当时的国民政府教育部认定为**"全国最优的九所中学之一"**
- **2005年**：被评为广东省一级学校
- **2006年10月**：复名为"广州市南海中学"（此前曾用名"广州市第十一中学"）
- **2007年**：被评为"广东省绿色学校"
- **2009年**：高分通过"广东省普通高中教学水平优秀等级学校"评估
- **2017年12月**：成功创建广州市示范性普通高中，为市民提供超过1200个示范性高中学位
- **2018年**：广州市南海中学教育集团成立
- **2024年10月**：120周年校庆，《猗欤南海百粤光》校史修订稿首发

### 1.3 著名校友

- **马万祺**：全国政协原副主席
- **莫伯治**：中国工程院院士
- **李沛文**：中国果树学家
- **袁伟时**：中国著名文史学家
- **黄天骥**：中山大学研究生院常务副院长、岭南文化名人
- **卢延光**：广东省美协副主席、中国十大连环画家
- **董嘉耀**：著名媒体人

### 1.4 学校定位

南海中学是荔湾区7所区属高中之一，属于荔湾区高中**第三梯队**（与真光汾水、西关培英并列），是荔湾区录取分数线最低的区属高中。

## 二、办学特色

### 2.1 致远教育

南海中学传承百年致远文化，形成了以"责任感教育"为核心的**致远教育特色品牌**：

- **校训精神**："任重致远"
- **三大课程模块**：弘志（品德养成）、弘毅（自主发展）、弘图（实践创新）
- **核心理念**："我们不和别人比起点，要和别人比进步"

### 2.2 适性教育

- **弹性作业制**：解决学有余力的同学"吃不饱"、稍微落后的同学"吃不下"的问题
- **教学方针**："以学定教，以教导学，善学精教"
- **育人目标**：让每位学生发挥主体性，培养自我管理、自我教育、自我学习能力

### 2.3 "一元四次"深度教学

- **"一元"**：以"学"为中心
- **"四次"**：问（问题驱动）、思（思维贯穿）、悟（感悟领悟）、品（提高核心素养、培养道德品格）

### 2.4 三大特色项目

| 项目 | 成就与地位 |
|------|-----------|
| **粤剧** | 第一批全国中小学中华优秀文化艺术传承学校；连年举办荔湾区"香凝杯"中小学生现场书画大赛 |
| **美术** | 悠久的美术教育传统，培育出广东省美协副主席卢延光等一大批书画界校友；广州市首批艺术重点基地学校 |
| **跆拳道** | 连续14年蝉联广州市中学生跆拳道赛团体冠军；第十八次蝉联（2024年） |

### 2.5 信息化建设

- 建有先进的**智慧课室**、全新的多媒体教学平台
- 集融创客、VR实验室、物联网实验室于一体的**"智创空间"**
- 广东省现代教育技术实验学校

## 六、食宿条件

### 6.1 住宿

**当前状况（截至2025年）**：无住宿

南海中学高中部目前无学生宿舍，所有学生走读。

**2026年即将改变**：

学校正在建设综合楼，建成后提供**近800个宿位**：

| 项目 | 详情 |
|------|------|
| 建设内容 | 拆除现状食堂和临时建筑，新建一栋综合楼 |
| 综合楼规格 | 地下一层，地上8层 |
| 建筑面积 | 约8,974平方米 |
| 功能 | 食堂+学生宿舍+教职工休息室 |
| 总投资 | 8,000万元（荔湾区财政统筹） |
| 建设起止 | 2024年8月至2025年12月 |
| 预计投用 | 2026年9月 |

### 6.2 食堂

- 当前食堂规模有限，走读制下需求相对可控
- 综合楼建成后将有全新食堂
- 知乎和贴吧学生评价信息较少（因走读制，多数学生不在校用餐）
- 2025年招生简章提到"学校有食堂"

## 九、民间口碑（深度展开）

### 9.1 综合评价："存在感最低"的荔湾高中——巧妇难为无米之炊

南海中学的民间口碑可以用一句话概括：**"官方说加工能力超强，学生说水分非常重；老师说低进高出，家长说能去别处就别来。"** 这种官方评价与民间评价的巨大断裂，是南海中学口碑生态的最显著特征。

**官方评价与民间评价的断裂**：

| 维度 | 官方标签 | 民间感受 |
|------|----------|----------|
| 加工能力 | "超强""低进高出""高进优出" | "水分非常重""质的飞跃不超过10%" |
| 学校等级 | 省一级、市示范性 | "百度搜出来都是佛山的" |
| 学风建设 | "狠抓学风""善学精教" | "普通班堪忧""作弊抓的不严" |
| 致远班 | "近80%特控率" | "流动制""关系能进""含金量被质疑" |
| 食堂 | "学校有食堂" | "过夜菜""不新鲜""领导洗脑弥补" |
| 管理 | "精细化管理" | "吃完饭不跑回教室就写500字检讨" |
| 百年品牌 | "1937年全国最优九所之一" | "都以为是佛山的学校" |

163.com深度分析文章《荔湾区高中概述》用**"巧妇难为无米之炊"**来形容南海中学——这个八个字比任何长篇大论都精准。生源差是根本困境，无论"加工能力"如何宣传，入口决定出口。

### 9.2 正面评价（7项）

**① 致远班近80%特控率——南海中学唯一的"王牌"**

致远班是南海中学最核心的差异化优势，没有之一：
- 特控率接近80%，本科率接近100%
- 多名学生考取清华、北航、中大、华工、央美等名校
- 教学难度大、进度快，配备最优质师资
- 2018届刘家曦：中考678分→高考604分→华南理工大学生物科学系
- 2024年1月荔湾区统测中致远班成绩优异

**但致远班并非完美**——详见9.3负面评价中的"致远班争议"。

**② 跆拳道全市称霸——连续14年蝉联团体冠军**

- 2024年第十八次蝉联广州市中小学生跆拳道比赛团体总分冠军
- 广东省体育特色学校

### 9.5 "加工能力"之争全解析——官方"超强"vs民间"水分重"

南海中学最大的口碑争议在于"加工能力"——官方说是"超强"，知乎说是"水分非常重"。这一矛盾需要深度解析：

**官方叙事链**：
- 花城+专访 → "加工能力超级强大" → "低进高出""高进优出"
- 教育局官网 → "低进高出"的教学特色
- 2020年数据 → 高优上线增幅444%、本科上线增幅145%
- 连续十年获高考突出贡献奖

**民间质疑链**：
- 知乎在读生 → "加工能力水分非常重""质的飞跃的理科生不超过10%"
- 163.com → "巧妇难为无米之炊""差不多就是文理各自最好的那个班的前半截能上线"
- 贴吧 → "能去好的就别来"

**真相可能在哪里？**

1. **"增幅"数据的陷阱**：高优上线增幅444%听起来惊人，但如果基数极小（比如9人→49人），增幅很大但绝对数量仍有限。"增幅"是相对概念，不能代表绝对水平。

2. **致远班拉高整体数据**：致远班近80%特控率会显著拉高全校特控率数据，但致远班只有2个班（约90人），不能代表全校520人的真实水平。

3. **"低进高出"的衡量标准**：如果中考580分的学生高考考到500分，确实算"高出"了——但500分（2022年广东理科高优线为500分）只是刚刚踩线。**"高出"的定义决定了"加工能力"的评价**。

4. **知乎答主"不超过10%"的判断**：如果致远班有80%的学生实现了质的飞跃，普通班只有不到10%——加权平均后全校确实可能"不超过10%"。这恰好解释了为什么致远班评价好、全校评价差。

**结论**：南海中学的"加工能力"并非造假，但存在**选择性展示**的问题——致远班的成功被放大为全校的成就，而普通班的困境被"增幅数据"所掩盖。

## 十二、核心结论与建议

### 12.1 对南海中学的核心判断

**南海中学是一所"上有一张王牌、下有三大困境"的学校**：

- **一张王牌**：致远班近80%特控率——如果能进入致远班，南海中学的性价比在荔湾区第三梯队中首屈一指
- **三大困境**：存在感低→生源差→普通班学风差→加工能力受限→分数线下行→存在感更低——恶性循环

### 12.2 2026年关键变量

2026年南海中学面临两个关键变化：

1. **扩招96人**——好事还是坏事？扩招意味着更多学生有机会入学，但也可能拉低整体生源质量，进一步增加普通班的学风压力
2. **新建宿舍投用**——如果800宿位如期投用，南海中学将从"走读校"变为"住宿校"，这对吸引外区生源、改善办学条件都是根本性改变

### 12.3 对家长的核心建议

> **如果你能进致远班——南海中学是荔湾区第三梯队中性价比最高的选择；如果你只能进普通班——建议认真考虑其他选项。**

**最关键的一句话**：

> **南海中学的价值完全取决于你能否进入致远班——进去了，近80%特控率护航；进不去，可能只是587分录取线的"保底校"。**
