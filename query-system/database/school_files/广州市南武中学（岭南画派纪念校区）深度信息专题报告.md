## 二、百年南武·岭画新章

### 2.1 南武本部源流（1905至今）

| 年份 | 事件 |
|------|------|
| **1905年** | 黄晦闻、谢英伯等爱国学者创办**南武公学会**，后设南武学堂，为河南（海珠）地区第一所新式学堂 |
| **1950年代** | 学校稳步发展，成为海珠区教育中坚 |
| **2006年** | 评为广东省国家级示范性普通高中 |
| **2022年** | 与岭南画派纪念中学合并，实行"一校两区"办学，原岭画中学成为南武中学岭南画派纪念校区 |

### 2.2 岭画校区前世今生

| 年份 | 事件 |
|------|------|
| **1968年** | 创立**广州市第七十六中学**，为海珠区普通完全中学 |
| **2013年** | 经市教育局批准更名**岭南画派纪念中学**，依托毗邻十香园（岭南画派发祥地）的文化底蕴，转型美术特色办学 |
| **2022年** | 与广州市南武中学合并，成为南武中学岭南画派纪念校区，纳入国家级示范性高中统一管理 |

### 2.3 名人渊源与岭南画派文脉

- **十香园**——校区毗邻的岭南画派发祥地，清代著名画家居廉、居巢在此设馆授徒，开创"居派"画风
- **高剑父、高奇峰、陈树人**——"岭南三杰"均出自居廉门下，开创岭南画派
- **陈永锵**——著名国画家、岭南画派纪念馆馆长，受聘为岭画校区名誉校长
- **黄晦闻**——南武中学创办人，著名爱国学者、诗人，校训"坚忍奉公·力学爱国"的精神源头

### 9.1 身份之困："76中"标签与南武合并后的认同重建

岭画校区的口碑，绕不开一个核心问题——**身份认同**。

这所学校1968年创立时叫"广州市第七十六中学"，2013年更名"岭南画派纪念中学"，2022年并入南武中学成为岭画校区。三次更名，三次身份重置，但互联网记忆是永恒的：

> "我认识的一位就是76中的，他一提起76不是学校垃圾就是他们班的班主任逆天，挺难蚌的。"——知乎用户

> "我初中就是76中的，不是夸张，这学校辣鸡得一比，中高考平均分比附近几所学校低了将近70-80分。现在是南武了。"——知乎用户

> "合并之后管理统一了，但很多人还是习惯叫76中。"——附近居民

**关键事实**：

| 时间节点 | 身份状态 | 口碑特征 |
|----------|---------|---------|
| **76中时期（1968-2012）** | 海珠区普通完全中学，市一级 | 口碑偏负面，被贴"差校"标签 |
| **岭画时期（2013-2021）** | 更名转型美术特色，但仍是独立学校 | 美术声誉建立，文化课口碑仍弱 |
| **南武岭画时期（2022至今）** | 并入国家级示范性高中 | 品牌升级中，旧印象仍需时间覆盖 |

**判断**：知乎上对"76中"的负面评价，主要反映的是合并前的状况。2022年并入南武后，师资、管理、品牌全面升级，但互联网上的旧帖旧评仍会影响搜索结果。**填报前务必区分"旧76中"与"新南武岭画"。**

### 9.2 美术教育：岭画校区的"王牌底牌"

美术教育是岭画校区最无争议的长板，也是民间口碑中最具共识的部分。

**正面口碑集中点**：

> "岭画校区的美术教育确实强，我小孩在这里从零基础到考上广美，老师很负责。"——家长反馈

> "周沛考上清华美院那届，我们整个画室都炸了，以前从来没想过身边有人能上清华。"——往届美术生

**数据支撑**：

| 指标 | 数据 |
|------|------|
| 清华美院录取 | 2023年周沛（近年唯一） |
| 央美/国美录取 | 每年均有输出 |
| 北电专业名次 | 2025年摄影专业全国第13名 |
| 美术本科率 | 接近100% |
| 美术重本率 | 约65% |
| 陈树人纪念馆个展 | 2024年3月师生百余幅作品展出 |

**但需注意的"但是"**：

1. **清华美院非每年都有**：2023年周沛是近年来的唯一清华，不代表"每年上清华"
2. **考得好的很多是"外面学的"**：知乎有用户直言"就考得好的全是去外面补习的，在学校学的全去了大专"（该评价指向佛山岭南美术实验中学，但此现象在美术特色校中普遍存在）
3. **高三集训需校外画室**：岭画校区校内美术教学主要覆盖高一高二基础阶段，高三冲刺期大多数美术生需到校外专业画室集训（费用2-5万），校内教学不足以支撑校考冲刺

**结论**：岭画校区美术教育的价值在于**体系化的基础培养+校内专业氛围+高校合作资源**，而非"包上美院"。真正的校考冲刺，仍需校外画室完成。

### 9.3 文化课"低进高出"：数据能说话，但需理性看

南武中学的"加工力"是招生宣传的核心卖点，岭画校区同样承接这一叙事：

> "文化课低进高出，老师很拼。入学比本部低20分，高考差距没那么大。"——往届毕业生

**官方/半官方数据**：

| 入口分数段 | 高考表现 |
|-----------|---------|
| 670分以上 | 特控率高达82% |
| 680-700分 | 特控率约85% |
| 700分以上 | 985/211率约85% |
| 整体（岭画校区） | 特控率约38% |

**民间质疑**：

- "670分以上特控率82%"的数据，样本量是多少？岭画校区每年670分以上入学的学生可能只有个位数
- 整体38%的特控率，与南武本部约55%仍有明显差距
- "低进高出"的叙事更多来自本部CCAE班的数据，岭画校区的纯文化课增值数据缺乏独立验证

**理性判断**：

| 结论 | 依据 |
|------|------|
| 文化课加工力存在，但不如本部 | 师资轮岗+统一管理确实提升了岭画校区文化课水平，但底子不同 |
| "低进高出"更多是本部叙事 | 本部680-700分入口→85%特控率的数据，不能直接套用到岭画校区 |
| 岭画校区文化课"够用" | 特控率38%在同梯度学校中属中等偏上，美术生文化课达线是够用的 |

### 9.4 班级分层：重点班与普通班的"两个世界"

这是知乎上被吐槽最集中的话题，虽然主要指向合并前的76中，但班型分层的逻辑在合并后仍然延续：

> "在76中，1班和2班才是实力股（可能人家是特色班），3班和4班就是赔钱货。而且不学习的学生大多都在3班和4班。"——知乎用户

> "同学方面：觉得76中学生的素质普遍不高，甚至还有点招人讨厌。祖安人云集，动不动就问候别人全家，还觉得自己很酷。"——知乎用户

**合并后的班型架构**：

| 班型 | 定位 | 教学质量 | 学习氛围 |
|------|------|---------|---------|

| **晦闻班（文化）** | 文化强化班 | ⭐⭐⭐ | 中等 |
| **普通班（文化）** | 标准教学 | ⭐⭐⭐ | 参差，取决于班级 |

**关键判断**：

- **美术班学习氛围普遍优于文化普通班**：美术生有明确的专业目标和升学路径，自律性更高
- **剑吴班是岭画校区文化课的"天花板"**：本部骨干教师执教，是纯文化课考生的最优选择
- **普通班的管理仍是挑战**：合并后统一管理，但生源基础差异导致普通班的学习氛围仍需关注
- **2023届起的新政策**：岭画校区中考排名前80名（仅计QY签约者）可在本部上课，享受CCAE班同等待遇——这意味着岭画校区的优质文化课生源可能"流失"到本部

| **培训机制** | 一般 | 纳入南武统一培训体系，外出学习机会增加 |

**理性判断**：合并前的"有能力没责任心"评价，在师资轮岗和统一管理后应有所改善，但老教师的个体差异仍存在。建议开放日时重点关注：**谁教剑吴班？美术教师的作品和成果？**

### 9.6 全走读之痛：晚自习后的夜归路

岭画校区全走读、无住宿，是家长群中被反复讨论的痛点：

**晚自习与通勤的现实矛盾**：

| 场景 | 时间 | 通勤方式 | 疲劳程度 |
|------|------|---------|---------|
| 住江南西附近 | 步行10分钟 | 步行 | 低 |
| 住海珠其他区域 | 9:30放学 | 地铁/公交 | 中 |
| 住天河/越秀/荔湾 | 9:30放学 | 地铁+换乘 | 高 |

**建议**：

- 晚自习**自愿参加**，家住远的可选择性不参加，但高三备考期晚自习几乎是刚需

- 本部有8人间宿舍+4人"学霸房"，需要住宿的考生优先考虑本部

### 9.9 美术生vs文化生：两条赛道两重天

岭画校区内部，美术生与文化生的就读体验差异显著：

### 9.10 冰雪运动：被低估的"隐形王牌"

**口碑悖论**：冰雪运动成绩远超学校整体知名度，但在家长圈的认知度极低。原因：

**提示**：有轮滑/冰上运动特长的考生，岭画校区的冰雪运动通道可能是极具性价比的选择——国家级认定+国家集训队输送，比纯靠文化课更容易打开升学局面。
