## 二、校史沿革

| 时间 | 事件 |
|------|------|
| **1991年** | 增城县华侨中学创办 |
| **2012年** | 整体搬迁至荔湖新校区，更名为增城市第一中学 |
| **2015年** | 增城撤市设区，学校更名为广州市增城区第一中学 |
| **2019年** | 引进南沙区第一位正高级教师张志明（数学特级教师）；新任校长黄志远到任 |
| **2024年2月** | 增城区第一中学教育集团正式成立（核心校+增城二中+三江中学+港侨中学+福和中学） |
| **2025年9月** | 增设初中部，跃升为完全中学；首批6个班300人入学 |

**校史解读**：增城一中是一所"年轻的国家级示范性高中"——1991年创办、2012年搬迁新校区后才真正走上发展快车道。从2019年高优率2.8%到2024年特控率13.2%，五年间翻了近5倍，说明学校处于**快速上升期**。2024年成立教育集团、2025年增设初中部，标志着学校从"单打独斗"走向"集团化办学"的新阶段。

### 6.2 高考成绩趋势图

```
特控率：2.8% → 7.7% → 8.5% → ... → 13.2%（2019-2024）
本科率： 45%  → 56.9%→ 71.2%→ ... → 83.9%（2019-2024）
```

**趋势分析**：
- 特控率5年翻了近5倍（2.8%→13.2%），增速显著
- 本科率5年提升近39个百分点（45%→83.9%），进步明显

- 获增城区教育质量综合评价一等奖——**但这是增城区内部评比，不代表全市水平**

**重要提醒**：13.2%的特控率放在全市是什么水平？——属于**第四梯队偏下**。对比增城区龙头增城中学的54.5%，差距超过40个百分点。增城一中的定位是"努力在进步的学校"，而非"已经很好的学校"。

## 九、民间口碑深度实录

> ⚠️ 本节内容整理自知乎、百度贴吧、自媒体评论、家长群等互联网公开平台，涵盖正面、中性、负面三类评价。民间口碑具有主观性和时效性，仅供参考，不构成填报建议。

### 9.1 身份画像：增城一中是什么"段位"的学校？

| 维度 | 定位 |
|------|------|
| **官方身份** | 广东省国家级示范性普通高中 + 广东省一级学校 + 增城区第一中学教育集团总校 |
| **增城区内排名** | 区属公办高中**第五名**（增城中学665＞广附增城660＞郑中钧=应元627＞**增城一中608**＞新塘~590） |
| **分数线位置** | 2025年户籍生608分，第三梯度线附近，2024年暴跌35分后2025年小幅回升 |
| **民间标签** | "躺平层""番薯生校长""像监狱""五类学校""增城老五" |
| **生源画像** | 增城区本地生源为主，外区生比例低；三梯度线附近学生1志愿或2志愿选择 |

**一句话总结**：增城一中是一所**"进步是真进步、但起点不高"**的国家级示范性高中——5年特控率从2.8%到13.2%翻了近5倍，但放在增城区仍是中下游；航模海模全国冠军是金字招牌，但贴吧学生直言"有别的选择最好不要来"。**它是一所在努力变好的学校，但还没好到让人放心**。

### 9.2 核心优势（带原声引用）

#### 优势一：5年高考进步惊人

> "近五年办学成绩逐年提升，荣获增城区教育质量综合评价一等奖。"——校方宣传

**解读**：这不是空话。数据说话：

| 年份 | 特控率 | 本科率 |
|------|--------|--------|
| 2019年 | 2.8% | 45% |
| 2020年 | 7.7% | 56.9% |
| 2021年 | 8.5% | 71.2%（纯文理87.2%） |
| 2024年 | 13.2% | 83.9% |

5年特控率翻了4.7倍，本科率提升38.9个百分点——这个增速在增城区**最快**。但需清醒认识：13.2%的起点太低，增城中学54.5%是它的4倍以上。**进步是真进步，但差距仍是鸿沟**。

#### 优势二：航模海模，全国独一档

> "连续三年问鼎全国青少年航海模型总决赛冠军"——官方报道
> "25金30银33铜，国家级奖励逾500人次"——校方数据

**解读**：这不是普通学校能做到的。增城一中的航模/海模项目由**国家体育总局、教育部等六部委**联合举办赛事认证，25枚金牌放在全国任何高中都是硬核成绩。如果孩子对科创/航模有兴趣，增城一中是**增城区唯一的选择**——郑中钧没有、应元没有、新塘更没有。

#### 优势三：246亩新校区，环境优美

> "学校环境好宿舍课室干净有空调"——知乎20届毕业生

**解读**：前拥荔湖胜境、右揽增江画廊、左望万寿古寺——246亩的校园环境在增城区公办高中中**面积最大、环境最优**。与老旧校区的学校相比，新校区的硬件条件有代际优势。但需注意：**环境好≠位置好**，距增城中心约8公里、无地铁直达是硬伤。

#### 优势四：国家级示范性高中牌子

> "国家级示范性高中"——官方认定

**解读**：增城区只有3所国家级示范性高中（增城中学、增城一中、新塘中学），增城一中是其中之一。这个"国家级"牌子在高考招生、大学认可度、教育政策倾斜等方面**仍有实际价值**。

### 9.3 核心劣势（带原声引用）

#### 劣势一："有别的选择最好不要来"（贴吧实锤）

> "我是一中学生，我奉劝各位同学有别的选择的话，最好不要来，说什么学校有麦当劳都是假的，吃一顿饭，你想排上队至少都要十分钟，宿舍是八人间，两个洗澡位，但只有一个厕所。"——贴吧用户（2025年12月）

**解读**：这是增城一中民间口碑中**最广泛传播、最具杀伤力**的一条评价。它并非空穴来风，而是精准指向了增城一中的四个硬伤：
- **"麦当劳是假的"**：校方宣传暗示学校有麦当劳，实际没有——这是**虚假宣传**的铁证
- **食堂排队10分钟**：一栋食堂供全校近3000人用餐，高峰期排队是常态
- **8人2洗1厕**：8人共用1个厕所，早晚高峰"渡劫"——这不是"紧凑"，是**影响日常生活的硬伤**
- **"有别的选择最好不要来"**：这是来自在校学生的忠告，比任何排名数据都更真实

#### 劣势二："番薯生校长"与第九节课争议（知乎实锤）

> "社团活动不算丰富，因为来了一个番薯生校长，要求高一高二轮流上第九节课，所以社团活动就被限制了。"——知乎用户

> "感觉一中管的挺多的？不许迟到，迟到三次就要停宿，之前要是迟到了，你的大名还会被广播出来。"——知乎用户

**解读**："番薯生校长"是学生对时任校长的戏称（谐音），第九节课是增城一中管理争议的核心：
- **第九节课**：高一高二轮流上，等于**压缩了社团活动时间**——校方宣传"30个社团"，实际因第九节课而受限
- **迟到3次停宿**：全封闭管理+严苛惩罚，对自律性弱的学生是高压，对自律性强的学生是束缚
- **广播通报**：迟到后名字被广播——这是**当众羞辱式管理**，在现代教育理念中争议很大
- **高三"赶得不得了"**：知乎学生反映"要跑操，要小测，要午练"——管理风格**重管控轻自主**

#### 劣势三：师资分布极度不均（贴吧实锤）

> "一中的师资分布一点都不均匀，想必某些班对这个一定很清楚，比如说f班是重点班……"——贴吧用户（2025年12月）

> "老师教学有趣人也好，但不免也会有严厉的老师"——知乎20届毕业生

**解读**：两条评价组合在一起，勾勒出增城一中**师资分配的残酷现实**：
- **实验班/重点班享受最优师资**：正高级2人+特级1人大概率集中在上层班
- **普通班师资良莠不齐**：贴吧学生明确指出"师资分布一点都不均匀"
- **来了就看你运气**：知乎学生的潜台词是——遇到好老师是运气，遇到差老师是常态
- **f班是重点班**：贴吧帖子暗示班型编号公开化，重点班和普通班差距**不言自明**

#### 劣势四："像监狱"事件——学校起诉学生（2023年实锤）

> "广东增城一学校学生小鲁，因不满住宿条件和学习压力，制作并在社交媒体发布名为《当代监狱》的短视频，使用该校宿舍、教学楼等实景照片，配以'古代监狱''明代监狱''机关重重、陷阱无数''牢房''防止囚犯越狱所设置的天罗地网''住8-10个囚犯''坐牢、蹲监狱'等侮辱性解说词。"——搜狐新闻

**解读**：这是增城一中历史上**最具争议**的事件，2023年4月引爆全网：
- **学生做法越界**：视频8-10万播放量，使用侮辱性解说词，确实侵犯学校名誉权
- **学校做法引争议**：直接起诉学生而非沟通解决，被舆论质疑"以大欺小""堵嘴式管理"
- **深层问题被掩盖**：学生为什么觉得"像监狱"？——**8人间2洗1厕+全封闭管理+迟到停宿**，这些客观条件确实存在
- **最终结果**：学生认错、学校撤诉——但**住宿条件改善了吗？没有公开信息表明改善了**

**结论**：一个学生会做"像监狱"的视频，说明住宿条件确实让人不适。学校起诉学生解决了法律问题，但**没有解决硬件问题**。

### 9.9 成功案例与逆袭样本

#### 5年高考进步：从2.8%到13.2%

这是增城一中**最大的集体成功案例**——特控率5年翻了4.7倍，本科率从45%到83.9%。放在增城区内部，这个进步速度是**最快的**。

但需清醒认识：
- 13.2%的特控率意味着**87%的学生上不了特控线**
- 83.9%的本科率意味着**16%的学生上不了本科线**
- 与增城中学54.5%的特控率相比，差距仍是**4倍以上**

#### 2024年增城区教育质量综合评价一等奖

这是增城区内部评比，**不代表全市水平**。增城区内互相比较，增城一中进步最快；但放在全市，特控率13.2%仍在第四梯队偏下。

#### "低进高出"案例

校方宣传"不少学生中考入学成绩没达第一批投档线，最终考上985/211"，但**从未公布具体学生姓名和录取院校**——缺乏可验证性，无法评估是系统性成果还是个别案例。

### 9.10 新增初中部的影响：机遇还是挑战？

2025年9月，增城一中增设初中部（首批6个班300人），从纯高中升级为完全中学。这一变化有利有弊：

| 维度 | 潜在机遇 | 潜在风险 |
|------|---------|---------|
| **品牌** | 完全中学牌子更响 | 初中部可能拉低高中部口碑 |
| **资源** | 教育集团加持 | 师资可能被初中部分流 |
| **生源** | 初中部优秀生源直升高中部 | 246亩校园容纳2400+300=2700人，密度增大 |
| **管理** | 统一管理 | 高中+初中混合管理复杂度增加 |

**关键问题**：增城一中现有师资201人，初中部新增6个班需要额外教师，是否会导致高中部师资被稀释？——**这是2026年入学学生最需要关注的风险**。
