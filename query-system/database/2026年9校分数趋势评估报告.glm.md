## 一、宏观环境：2026年中考三大趋势

### 1.1 考生规模持续扩张

| 年份 | 考生总数 | 同比增幅 |
| :--- | :--- | :--- |
| 2023年 | 12.4万 | — |
| 2024年 | 12.9万 | +4.0% |
| 2025年 | 13.9万 | +7.8% |
| **2026年** | **15.1万** | **+8.6%** |

考生总数三年增长21.8%，但普高学位同步大幅扩容（2026年净增11,244个公办学位），供需关系整体趋于缓和，中上游区属校录取线面临**下行压力**。

### 1.2 梯度线演变

| 梯度 | 2023年 | 2024年 | 2025年 | 2026年一模换算(810制) |
| :--- | :--- | :--- | :--- | :--- |
| 第一梯度 | 715 | 702 | 707 | ~707 |
| 第二梯度 | 675 | 662 | 667 | ~627(三梯) |
| 第三梯度 | 635 | 622 | 627 | — |
| 第四梯度 | 595 | 582 | 587 | ~587 |

2026年一模推算第三梯度线约627分，与2025年基本持平。9校中除真光广钢外，其余8校核心定位均在**第三梯度及以下**。

### 1.3 扩招与缩招并存

| 学校 | 2025招生 | 2026招生 | 变化 |
| :--- | :--- | :--- | :--- |
| 真光（广钢） | 300 | 422 | **+122 (+41%)** |
| 南海中学 | 424 | 520 | **+96 (+23%)** |
| 七中（麓湖） | — | 540 | 新校区首招 |
| 真光（汾水） | ~200 | 220 | +20 |
| 广州一中 | ~750 | 815 | +65 |
| 广州四中 | ~700 | 724 | +24 |
| 十七中 | ~400 | 432 | +32 |
| 西关外国语 | 530（普通班） | 526（普通班）+75（中外合作） | **普通班微缩招-4，中外合作+75** |
| 97中（江南新苑） | 220 | 200 | **缩招-20** |

**关键判断**：扩招校占多数，录取线整体承压；西外普通班微缩招4人，但新增中外合作办学75人（单独代码招生，不影响统招线）；97中江南新苑缩招20人，理论上获得支撑，但缩招幅度有限，难以逆转大趋势。

## 六、风险提示

1. **本报告预测基于历史数据和当前舆情，实际录取线受当年报考热度、试题难度、政策调整等多重因素影响，仅供参考。**
2. **特控率数据来源不一**：部分学校存在校方宣传口径与第三方统计口径的差异（如四中41%-42% vs 29.55%），建议以官方报考指南为准。
3. **新校区/新宿舍投用时间**：南海中学新宿舍、十七中东校区住宿等在2026年官方报考指南中宿位均标注为0，存在工程进度不确定性，建议5月开放日实地确认。
4. **2026年梯度线尚未公布**：一模换算数据仅供参考，实际梯度线以官方公布为准。
5. **名额分配控制线**为最低门槛，各初中校内实际录取线可能高于控制线。
6. **第三批次控制线降档**：一中/汾水被列入"第三批控制线=第四梯度"名单，意味着教育局认为两校录取线可能降至第四梯度（~587分），本报告预测区间（615-625分）与此存在张力，实际录取线可能低于预测。
7. **志愿优先规则**：广州中考是顺序志愿（非平行志愿），同梯度内志愿顺序 > 分数高低。西外/十七中末位志愿序号=1，必须第一志愿；一中/汾水末位志愿序号=5，可作为保底志愿。填报时务必注意志愿位置。
