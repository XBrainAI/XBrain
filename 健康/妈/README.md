# 妈 · 个人健康档案子站点

本目录为 XBrain 健康子站点下的"妈"个人健康档案页面，由脚本自动生成。

---

## 一、文件说明

| 文件/目录 | 说明 |
|-----------|------|
| `generate_index.py` | **生成脚本** — 运行后自动生成 `index.html` |
| `index.html` | **自动生成** — 禁止手动编辑，由脚本全量生成 |
| `个人健康档案与深度医学分析报告.md` | 深度医学分析报告（嵌入页面顶部） |
| `p.report.md` | 分析报告生成提示词（不纳入页面） |
| `auth.config.json` | 子站独立访问密码配置 |
| `MR-无需建立子站点/` | MRI 原始 DICOM 文件（不纳入页面） |
| `YYYYMMDD-项目-医院.md` | 单份检查报告（自动纳入时间线） |
| `YYYYMMDD-项目-医院.png` | 对应报告图片（自动关联，支持 `.png/.jpg/.jpeg`） |
| `orphans.json` | 待生成报告工单（脚本自动覆盖写入，列出无同名 MD 的图片） |

---

## 二、更新流程

### 新增检查报告（推荐：只放图片）

**图片即可，解读报告由 AI 生成，无需手工写 MD。**

1. 将报告图片放入本目录，命名为 `YYYYMMDD-项目名称-医院.png`（如 `20260911-妇科超声-省妇幼.png`）
2. 运行生成脚本：
   ```bash
   cd 健康/妈
   python generate_index.py
   ```
   若存在无同名 MD 的图片，脚本会写入 `orphans.json` 并打印 `[TODO]` 清单。
3. 让 AI 读 `orphans.json`，逐张读图，按 `p.report.md` 提示词与现有 MD 格式生成 `target_md`
   （六段式：基本信息 / 检查方法说明 / 检查所见 / 与前次对比 / 综合诊断解读 / 临床建议 + 免责声明）
4. 重跑脚本，确认输出 `image-only: 0`，条目已从「仅图片」升级为常规条目
5. 更新 `个人健康档案与深度医学分析报告.md`（如需要）
6. 验证 `index.html` 输出，推送代码

> 兜底：若跳过第 3~4 步，页面会以「仅图片」降级条目（橙色徽标）先上线，不会报错，但无文字解读。

### 已有 MD + 图片（传统方式）

按现有 `.md` 报告文件照常放入同名图片即可，脚本自动配对，无需 `orphans.json` 环节。

### 修改深度分析报告

1. 直接编辑 `个人健康档案与深度医学分析报告.md`
2. 运行生成脚本重新生成 `index.html`
3. 推送代码

### 排除文件

以下文件不会被纳入生成：
- `个人健康档案与深度医学分析报告.md`（作为深度报告单独展示）
- `p.report.md`（提示词文档）
- `MR-无需建立子站点/` 目录（原始 DICOM 文件）

如需新增排除文件，修改 `generate_index.py` 中的 `EXCLUDE_FILES` 集合。

---

## 三、禁止事项

- **禁止直接编辑 `index.html`** — 会被下次脚本运行覆盖
- **禁止重新编写生成逻辑** — 脚本已存在，直接调用即可
- **禁止使用中文文件名** — 报告文件名必须为英文（日期+项目+医院）

---

## 四、访问密码

本页面设有独立访问密码，配置见 `auth.config.json`。
通过主站登录后仍需输入子站密码方可访问。
