# 哥的个人健康档案 — 子系统约定

> 本文件是 `健康/哥/` 子系统的单一事实源（2026-10-03 确立）。任何 AI/维护者改动本目录前必读。
> 项目级摘要见 `.vand-workspace/project-context.md` §11。

## 1. 生成机制（核心红线）

- `index.html`（档案首页：时间线+搜索+年份筛选）**由 `generate_index.py` 生成，勿直接手改**（会被重建覆盖）。
- 重新生成：`python generate_index.py`（managed python 3.13）。
- 生成器排除：`EXCLUDE_DIRS = {"MR-无需建立子站点", "__pycache__"}`；`EXCLUDE_FILES` 含 `generate_index.py`、`index.html`、`README.md/MD`（本文件不会被误当条目）。

## 2. 条目类型与建法

条目 = 子目录 `YYYYMMDD.标题/`（**日期前缀8位数字+点**，否则降级按原名收录）。

| 类型 | 用途 | 建法 | 卡片表现 |
| --- | --- | --- | --- |
| 就诊/检查（旧式） | 有实际就医/检验的记录 | 建目录放 md（+图片）；可选自带 index.html 详情页 | md 合并为"查看完整报告"折叠全文；有 index.html 则多一个"查看详情页"按钮 |
| **健康咨询（新式，三件套齐全才生效）** | 无就诊的自诉/科普/分析（如身高咨询） | `meta.json` + `index.html`（详情页）+ `README.md`（速览），md 为源稿存档 | 只显示 README 速览 + "查看详情页"按钮，**不渲染 md 全文** |
| 根目录 md | 单文件健康报告 | `YYYYMMDD.标题.md` | 标签"健康报告"，折叠全文 |

- `meta.json` 格式：`{"tag": "健康咨询"}`（缺省标签"就诊记录"）。
- **新式条目缺 index.html 时自动兜底**：保留 md 折叠全文（防内容不可达），建好详情页后自动切回速览模式。

## 3. 内容分工防冗余（km 指定）

- 卡片 = **索引层**：标签 + 标题 + 速览（仅新式条目）+ 按钮；**不重复详情页内容**。
- 详情页（条目级 `index.html`）= **唯一全文图文入口**：图解、图表、清单、导航都在这里。
- 无 meta.json 的旧条目行为完全不变（折叠全文）；**任何全局机制变更必须 meta.json 显式加入（opt-in），严禁用"有无 index.html"等启发式推断——旧条目肾结石自带 index.html 曾被误伤**。

## 4. 详情页规范（条目级 index.html）

- 风格与档案首页一致：暗色 XBrain 主题（--xb-deep #0a0a1a / --xb-accent #64b4ff）、Noto Serif/Sans SC、返回链接 `../index.html`。
- 结构：hero（日期+标签+"非就诊记录"标注）→ sticky 锚点导航 → 分节正文（对应 md 源稿章节）→ 底部返回链接。
- **图解 SVG 配色约定**：蓝色线条=身体姿态；橙色 #EF9F27=被拉伸/关注部位；绿色 #97C459=发力/牵拉方向；灰色虚线=对比姿态。图例写在图前提示中。
- **独立维护**：详情页不随生成器重建，改动直接编辑；md 源稿与详情页内容需人工保持同步（md 仅作源稿存档）。
- 多张 SVG 的 marker id 必须唯一（如 g1-g7），改完跑 XML 校验。

## 5. 措辞红线（面向哥，15岁青少年）

内容必须**正向、不打击**，禁用"定型 / 帮助有限 / 减速 / 收窄 / 抓尾巴 / 永久停转"等表述；
改用"**黄金窗口 / 晚长很常见 / 稳稳收获 / 进入稳定期 / 满分答案 / 每一步都算数**"。
每份报告结尾附"不构成医学诊断，以面诊医生意见为准"。

## 6. 改动验证纪律

1. 改 `generate_index.py` 后必跑：`python generate_index.py` + 逐条目核对（可用 node 脚本断言按钮/内容归属）。
2. **隔离模拟法**（不动真实数据）：import 生成器模块 → monkeypatch `gen.BASE` 指向临时目录夹具 → 断言 `get_items()` 各场景行为。标准夹具5场景：新就诊条目 / 完整新式咨询 / 新式但未建详情页 / 根md报告 / 命名不合规目录。
3. 涉及全仓 HTML/目录结构改动后：`npm run test:repo` 全绿（见 project-context.md 构建命令节）。

## 7. 历史教训

- 2026-10-03：用"有无 index.html"启发式把速览模式套到旧条目（肾结石）上，误删其折叠全文并把 README 病程上卡 → 已改 meta.json 显式加入并还原。教训：**全局变更 opt-in，旧条目展示零影响**。
- `py_compile` 产生的 `__pycache__` 曾被误扫为条目 → 已入 EXCLUDE_DIRS。
