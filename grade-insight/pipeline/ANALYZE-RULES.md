# 系统分析判定规则（ANALYZE-RULES，S4.5 固化件）

- 版本：**v2**（2026-10-28，SPEC-011：§六–八新增题级诊断/跨考演化/行动层 v2；§一–五 v1 规则**冻结不变**）｜ 承载规格：SPEC-006（v1）/ SPEC-011（v2）｜ 一致性：analyze.js 内 RULES 常量与本表逐项对应；改任一必须同步升版并对历史考重跑回归（契约 §4 纪律）。
- 总原则：结论=规则命中+依据数字成对输出；**缺源数据不研判**（输出"–/未参与"声明）；预估一律带"规则估计"标签；错因一律带"AI 预判+人工复核"标签（CAUSE-TAXONOMY v1）。

## 一、风险规则（命中即在全科/逐科节输出）

| 编号 | 名称 | 判据（阈值） | 结论模板 |
|------|------|-------------|---------|
| R1 | 弱科 | 科得分率 < 60% 或 班级等级 ∈ {D,E} | 「〈科〉为当前短板科目（得分率 x%，等级 L）」 |
| R2 | 基础漏洞 | 易题丢分 ÷ 易题满分 ≥ 15% 或 易题错题数 ≥ 3 | 「〈科〉基础题存在失血：易题丢 y 分（占易题总分 z%），优先回补」 |
| R3 | 中档失血 | 中档题丢分 ÷ 全科丢分 ≥ 40% | 「〈科〉主战场在中档题（丢分占比 x%）」 |
| R4 | 难题豁免 | 科得分率 ≥ 60% 且 难题丢分占比 ≥ 50% | 「〈科〉丢分集中于难题，暂不列优先级（正常梯度）」 |
| R5 | 薄弱广度 | 薄弱知识点（rate<60）÷ 入档知识点 ≥ 25%（仅源含 kps 的科） | 「〈科〉薄弱点 x/y 个（占比 z%），面状问题」 |
| R6 | 重点风险 | 重点（key）且 rate<60% 的知识点数 ≥ 3 | 「〈科〉×个【重点】未掌握，直接影响得分基本盘」 |
| R7 | 目标差距 | 总得分率 < student.targetRate | 「总分 x% 距目标 y% 差 zpp；按回收清单执行后规则估计可达 w%（口径见三）」 |

## 二、逐科研判输出序（每科卡片）

得分率/等级 → 难度结构（易/中/难 丢分与占比）→ 题型 top 丢分 → 易题错题清单（逐题号）→ 知识点（薄弱 top5，仅源含科）→ 命中规则结论。

## 三、补救清单"预估回收"口径（规则估计，非事实承诺）

| 来源 | 口径 |
|------|------|
| 易题错题 | 该项丢分 × 80%（回补把握高） |
| 中档题错题 | 该项丢分 × 50% |
| 薄弱【重点】知识点（无题级归属时） | 该科中档丢分 ÷ 薄弱重点数 × 50%，上限 8 分/条 |
| 排序 | 预估回收降序取 top10，跨科统一；每条附依据数字与解析链接（如有） |

## 四、全科均衡口径

得分率极差（max−min）、标准差 σ（总体）、等级构成计数（A/B/C/D/E/–）；平台优势/弱势声明仅对照不采信为判据。

## 五、数据边界声明模板（附录固定输出）

年级均分/排名：源未提供（等待年级视图补录）→ 不参与研判；知识点/题解：仅列实际覆盖科目；integrity fail/warn 逐项列出并说明对结论的影响面。

## 六、题级诊断扩展（D 系列；输入 gi-exam-data/2）

| 编号 | 名称 | 判据（阈值） | 输出 |
|------|------|-------------|------|
| D1 | 难度×题型九宫格 | 每科丢分按 (易/中/难)×(单选/多选/主观/作文) 交叉聚合 | 分科九宫格，格值=丢分；空格不显示 |
| D2 | 错因构成 | 每科丢分按 cause（C1–C6，CAUSE-TAXONOMY v1）分桶求和 | 堆叠构成+占比；无 cause 数据的科整桶"待标注"并声明"未标注≠无问题" |
| D3 | KP 四象限 | X=KP 关联丢分（kps[].qNos 映射到 questions 丢分求和；qNos 缺失时退化=wrong × 该科主观题均丢，**标注退化口径**）；Y=掌握率 rate；分界线 rate=60（沿用 R5） | 四象限散点：右上=高价值补强（丢分多·未掌握）、右下=稳定得分区、左上=低效防护（丢分少·未掌握）、左下=安全区；【重点】KP 星标 |

## 七、跨考演化（E 系列；输入 GI_JOINT（gi-joint/1）；单考或缺源时输出"下考激活"占位，不编造）

| 编号 | 名称 | 判据（阈值） | 输出 |
|------|------|-------------|------|
| E1 | KP 演化 | 同 kpKey 相邻两考掌握率差 ≤ −15pp → 回落告警 | 演化折线+告警标记 |
| E2 | 顽固薄弱 | 同 kpKey 连续 ≥2 考 category ∈ {薄弱,待提升} → 顽固标记 | 顽固清单；参与 A1 加权 |
| E3 | 跨考错题本 | GI_JOINT.wrongQuestions 聚合，支持考次/科目/错因/难度筛选 | 跨考错题视图（含 analysisRef 直达） |

## 八、行动层 v2（A 系列）

**A1 补救优先级（在 v1 §三口径上叠加错因维度）**

回收估 = v1 基础回收（易×80% / 中×50% / 重点薄弱摊派上限 8 分/条）× w(错因) ×（顽固 ×1.3）；**难题档来源一律再 ×0.3**。

| 错因 | w | 口径声明 |
|------|---|----------|
| C3 算错了 | 0.9 | 思路在，纠正成本低 |
| C4 看错了题 | 0.9 | 审题习惯可矫正 |
| C1 概念没吃透 | 0.6 | 需重教重练 |
| C2 方法不会用 | 0.6 | 需专项训练 |
| C5 步骤丢分 | 0.6 | 表述/规范改进中速见效 |
| C6 待标注 | 0.5 | **乐观假设声明**：未标注错题按中位可补性估计（AUDIT-010 风险 2），经 AC9 抽检修订环校准 |

**A2 复习计划生成器（确定性，4 周结构）**

| 周 | 主题 | 内容口径 |
|----|------|----------|
| 第 1 周 | 止血 | R2 易题错题全清单重练 + C3/C4 类错题（可补性最高） |
| 第 2–3 周 | 主攻 | D1 B 区中档主战场按 KP 群组推进：D3 四象限右上区优先，E2 顽固加权；每 KP 配错题重练清单 |
| 第 4 周 | 验收 | 本期重练清单 topN 回测；仍未掌握 KP 转入下期计划 |

每项输出：KP 群、重练题清单（题号+analysisRef 链接）、预估回收（A1 口径）、资源指向（md 解析 / analysis html / raw 原卷）。参数：每周重练清单 ≤10 题（超出按 A1 回收估降序截断）；资源指向缺源时声明。
