# 系统分析判定规则 v1（ANALYZE-RULES，S4.5 固化件）

- 版本：v1（2026-10-23）｜ 承载规格：SPEC-006 ｜ 一致性：analyze.js 内 RULES 常量与本表逐项对应；改任一必须同步升版并对历史考重跑回归（契约 §4 纪律）。
- 总原则：结论=规则命中+依据数字成对输出；**缺源数据不研判**（输出"–/未参与"声明）；预估一律带"规则估计"标签。

## 一、风险规则（命中即在全科/逐科节输出）

| 编号 | 名称 | 判据（阈值） | 结论模板 |
|------|------|-------------|---------|
| R1 | 弱科 | 科得分率 < 60% 或 班级等级 ∈ {D,E} | 「〈科〉为当前短板科目（得分率 x%，等级 L）」 |
| R2 | 基础漏洞 | 易题丢分 ÷ 易题满分 ≥ 15% 或 易题错题数 ≥ 3 | 「〈科〉基础题存在失血：易题丢 y 分（占易题总分 z%），优先回补」 |
| R3 | 中档失血 | 中档题丢分 ÷ 全科丢分 ≥ 40% | 「〈科〉主战场在中档题（丢分占比 x%）」 |
| R4 | 难题豁免 | 科得分率 ≥ 60% 且 难题丢分占比 ≥ 50% | 「〈科〉丢分集中于难题，暂不列优先级（正常梯度）」 |
| R5 | 薄弱广度 | 薄弱知识点（rate<60）÷ 入档知识点 ≥ 25%（仅源含 kps 的科） | 「〈科〉薄弱点 x/y 个（占比 z%），面状问题」 |
| R6 | 重点风险 | 重点（key）且 rate<60% 的知识点数 ≥ 3 | 「〈科〉×个【重点】未掌握，直接影响得分基本盘」 |
| R7 | 目标差距 | 总得分率 < student.targetRate | 「总分 x% 距目标 y% 差 zpp；按回收清单执行后规则估计可达 w%（口径见三）」 |

## 二、逐科研判输出序（每科卡片）

得分率/等级 → 难度结构（易/中/难 丢分与占比）→ 题型 top 丢分 → 易题错题清单（逐题号）→ 知识点（薄弱 top5，仅源含科）→ 命中规则结论。

## 三、补救清单"预估回收"口径（规则估计，非事实承诺）

| 来源 | 口径 |
|------|------|
| 易题错题 | 该项丢分 × 80%（回补把握高） |
| 中档题错题 | 该项丢分 × 50% |
| 薄弱【重点】知识点（无题级归属时） | 该科中档丢分 ÷ 薄弱重点数 × 50%，上限 8 分/条 |
| 排序 | 预估回收降序取 top10，跨科统一；每条附依据数字与解析链接（如有） |

## 四、全科均衡口径

得分率极差（max−min）、标准差 σ（总体）、等级构成计数（A/B/C/D/E/–）；平台优势/弱势声明仅对照不采信为判据。

## 五、数据边界声明模板（附录固定输出）

年级均分/排名：源未提供（等待年级视图补录）→ 不参与研判；知识点/题解：仅列实际覆盖科目；integrity fail/warn 逐项列出并说明对结论的影响面。
