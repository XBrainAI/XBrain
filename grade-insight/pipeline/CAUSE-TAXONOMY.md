# 错因分类学 v1（CAUSE-TAXONOMY，S4.6 固化件）

- 版本：v1（2026-10-28）｜ 承载规格：SPEC-011 ｜ 下游：ANALYZE-RULES v2（权重表）/ convert.js v2（回填）/ transcribe-prompt v2（标注任务）
- 性质纪律：**错因是推断不是事实**——一切错因输出（report/图/tooltip/exam.json）必须带"AI 预判+人工复核"口径标签；未确认的预判不得进入 exam.json。

## 一、分型定义（C1–C6）

| 代码 | 名称（对外文案） | 判定要点 | 典型证据形态 |
|------|------------------|----------|--------------|
| C1 | 概念没吃透 | 知识点本身的定义/定理/性质未掌握或记忆缺失；读完解析涉及的概念仍无法复述 | 我的答案撞入概念误区；解析首步即用到的定义在作答中缺位 |
| C2 | 方法不会用 | 概念知道但思路/技巧/方法链欠缺；读完解析能懂、独立做不出 | 作答方向错误或空白；解析展示的方法（如对称性距离比较、向量法）未在作答中出现 |
| C3 | 算错了 | 思路正确，运算/书写/代入笔误导致结果错 | 作答过程与解析路径一致，仅数值/符号处偏离 |
| C4 | 看错了题 | 审题偏差：漏条件、看错问、答非所问 | 作答对象与题目所问错位；忽略题目给定条件 |
| C5 | 步骤丢分 | 主观题部分得分：过程不完整/表述不规范/跳步/漏答小问 | score>0 且 score<point 的主观题（缺省判定，除非证据指向 C1/C2） |
| C6 | 待标注 | 解析缺失、作答不可辨认或证据不足——**诚实桶，不强行归类** | 复核件中明确写"证据不足" |

## 二、判定优先级（确定性顺序）

1. 主观题/作文题 且 0 < score < point → **C5**（缺省；仅当解析与作答对照显示整段思路错误才改判 C1/C2，须注明理由）。
2. score = 0 的任何题型 → 按下方"证据判据"在 C1–C4 中判定；证据不足 → C6。
3. 客观题 score = point → 无错因（不标注）。
4. **难题档（diff=难）+ C3 为罕见组合**——复核时强制二次确认（回执须含"已二次确认"注记）。

## 三、证据判据（score = 0 时，按序检查）

1. 作答与参考答案"对象错位"（答的不是问的）→ C4；
2. 作答路径与解析前几步一致、仅在运算处分叉 → C3；
3. 作答完全空白/照抄题目 → 解析所用核心方法是否超纲或强技巧？是 → C2；否 → C1；
4. 作答方向明确但起点即偏离解析思路 → 对照该题知识点：若该 KP 掌握率 <60% → 倾向 C1；掌握率 ≥60% → 倾向 C2；
5. 以上均无法判定（作答不可辨认、解析过简）→ C6。

## 四、流程与文件形态

- **AI 预判**（证据引用型）：逐错题输出 `错因代码 + 说明(≤40字) + 依据（解析原文摘录或对照陈述）`；禁止无依据的裸代码。
- **人工复核件**：`<考>/md.错因复核-<科>.md`——表格列：`题号 | 错因 | 说明 | 依据 | 确认`；确认列非空（✓）的行才被 convert.js v2 收录回填 exam.json；整件头部标注复核状态与确认人/时间。
- **回填**：convert.js v2 只读确认行；未确认/缺件 → 该科错因覆盖 integrity 检查报 pending（warn），引擎按"待标注"桶呈现。
- **后续考次**：transcribe-prompt v2 的错因标注任务产出预判草案（`md.错因预判-<科>.md`），经人工确认并入复核件后回填——与本件同一格式。

## 五、与权重的关系

可补性权重 w(C1–C6) 固化于 ANALYZE-RULES v2 §八（引擎唯一消费入口）；本表只定义分型与判定，不重复权重数字，防双源漂移。
