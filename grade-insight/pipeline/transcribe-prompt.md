# 转写提示词模板 v1（S2 固化件）

- 版本：v1（2026-10-23）｜ 提炼自 SPEC-000 实战纪律 ｜ 用途：每轮考试 raw→md 转写的**唯一提示词母本**；改其内容必须升版（v2…）并同步 exam.json 重生成回归（契约 §4）。
- 执行体：多模态 AI（非本地 OCR，SPEC-000 决策）。

## 提示词正文（复制使用，替换〈〉占位）

你负责把考试截图忠实转写为 markdown（写文件任务）。

基准目录 BASE = 〈项目内该轮考试目录，含 raw/ 与 md/〉
图片在 BASE/raw/，输出到 BASE/md/。

处理以下图片：〈文件清单——建议每批 ≤12 张，按科目分组〉

对每张图：先用 Read 工具读取该图片（支持图片），再用 Write 工具写出同名 .md（照抄原名含空格与括号，仅换后缀）。

转写纪律：
- 逐字忠实转写图中全部内容，不概括、不评价、不添加图中没有的内容。
- 表格数据用 markdown 表格，数值原样保留；表头沿用原图文字（如 `| 题号 | 题型 | 分值 | 难度 | 得分 |`）。
- 数学公式一律 LaTeX（行内 $…$）。
- 手写笔迹尽力辨认；无法辨认处写（无法辨认），绝不编造。
- 长截图按带分块读取，拼接重复行按原样保留并以"注："行标明疑似拼接重复，不自行删行。
- 题目配图需裁剪：定位图形区域（暗像素投影定界，不目测估算），存 `md/images/<原图名去后缀>-图k.png`，在 md 原描述位置嵌入 `![…](<images/…>)`（路径含空格括号用尖括号目标）；无法可靠定位的注明（原图未截取：无法辨认图形边界）。
- 手机状态栏/页签/按钮行等 UI 元素按先例格式简要记录（如"（状态栏：…）"），不计入正文数据。

完成后只回报：写出文件数、每文件一句话概况、存疑/无法辨认/去重位置清单（勿贴大段正文）。临时切片/脚本产物用完清理，不落仓库。

## 验收口径（与 S1 准入、S3 转换的接口）
- 输出文件集 = raw 图片集同名换后缀（机器可校验，SPEC-000 AC1 先例）。
- 存疑清单是 S4 人审与 exam.json 的 confidence/integrity 输入，**必交**。
