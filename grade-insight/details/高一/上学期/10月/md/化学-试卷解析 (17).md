### 参考答案与解析要点

参考答案 **B**。要点：

- 判定标准："由亮变暗 → 熄灭 → 复亮"要求反应把溶液中的离子**几乎全部移走**（生成沉淀＋极弱电解质水），恰好反应点自由离子浓度趋近于零；随后过量试剂重新提供离子，灯复亮。
- B 正确：$MgSO_4 + Ba(OH)_2 = Mg(OH)_2\downarrow + BaSO_4\downarrow$，$Ba^{2+}$ 沉走 $SO_4^{2-}$、$OH^{-}$ 沉走 $Mg^{2+}$，恰好反应时溶液里只剩水——熄灭；继续滴加的过量 $Ba(OH)_2$ 使离子浓度回升——复亮。
- A（学生所选）：$H^{+} + OH^{-} = H_2O$ 只消掉 $H^{+}$ 与 $OH^{-}$，溶液里留下 $Na^{+}$、$Cl^{-}$（生成可溶强电解质 NaCl）——灯变暗但**不会熄灭**。
- C：$Ba^{2+} + SO_4^{2-} = BaSO_4\downarrow$ 之后溶液中仍剩盐酸（$H^{+}$、$Cl^{-}$）——变暗不熄灭。
- D：$Ag^{+} + Cl^{-} = AgCl\downarrow$ 之后生成强电解质 $HNO_3$——变暗不熄灭。

### 考点定位

- 核心考点：**溶液导电性的决定因素**（自由移动离子的浓度与离子所带电荷数，而不是"有没有离子"）；**离子反应与实验现象的对应**（沉淀＋水 → 离子趋零；可溶盐或强酸残留 → 只降不清零）；**复分解沉淀型离子方程式**（$Ba^{2+} + 2OH^{-} + Mg^{2+} + SO_4^{2-} = BaSO_4\downarrow + Mg(OH)_2\downarrow$）。
- 教材模块：人教版（2019）必修第一册·第一章 物质及其变化（第二节 离子反应：电解质的电离与离子反应）。
- 能力层级：综合。

### 缺漏诊断

1. **导电性概念停在"有没有离子"，没到"离子浓度多大"**——证据：草稿把 $H^{+} + OH^{-} = H_2O$ 圈起后即选 A；A 项中和后 $Na^{+}$、$Cl^{-}$ 仍大量存在，灯不可能熄灭。把"消掉一对离子"当成了"消掉了离子"。本题难度"中"而得 0 分，与草稿完整度形成反差，概念断层明确。
2. **从方程式回推"离子浓度变化"的最后一步没走**——证据：B 项草稿已正确写出 $Mg(OH)_2$ 与 $BaSO_4$ 两种沉淀，却未得出"恰好反应点只剩水 → 熄灭"；产物写对了、现象判断断了链。
3. **"沉淀之外还残留什么"未扫描**——证据：C、D 两错项的共同设错结构是"沉淀掉一部分、留下强电解质"；作答时未对每项做全离子盘点。
