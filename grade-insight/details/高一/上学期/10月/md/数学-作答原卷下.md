19. 解(1) 若 $f(x) < -2$ 的解集为 $R$，
则（划线删除：$(m+1)x^2 - (m-1)x + m - 1$）
$(m+1)x^2 - (m-1)x + m - 1 < -2$ 的解集为 $R$。
$(m+1)x^2 + (1-x)(m-1) < -2$
∴ $m + 1$（未写完）

(2) $f(x) \ge (m+1)x$
$(m+1)x^2 - (m-1)x + m - 1 \ge (m+1)x$
$(m+1)x^2 - (m+1)x + (1-x)(m-1) \ge 0$
（划线删除：$2 - (m+1)$）
$x[(m+1)x - (m+1)] + (1-x)(m-1) \ge 0$
$x(m+1)(x-1) + (1-x)(m-1) \ge 0$
$x(m+1)(x-1) - (x-1)(m-1) \ge 0$
$[x(m+1) - (m-1)](x-1) \ge 0$
$[x(m+1) + (m+1)](x-1) \ge 0$
$(x+1)(x-1)(m+1) \ge 0$
∴ $\begin{cases} (x+1)(x-1) \ge 0 \\ m+1 \ge 0 \end{cases}$ 或 $\begin{cases} (x+1)(x-1) \le 0 \\ m+1 \le 0 \end{cases}$
∴ $\{x \mid -1 \le x \le 1\}$ 或 $\{x \mid -1 \le x\}$（第二个集合书写不完整，存疑）
∴ $\{x \mid -1 \le x \le 1\}$。
