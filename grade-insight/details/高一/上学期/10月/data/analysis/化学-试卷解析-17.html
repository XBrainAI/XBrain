在电解质溶液的导电性实验（装置如图所示）中，若向某一电解质溶液中逐滴加入另一溶液时，则灯泡由亮变暗，至熄灭后又逐渐变亮的是（　）

A. 盐酸中逐滴加入氢氧化钠溶液

B. 硫酸镁溶液中逐滴加入氢氧化钡溶液

C. 硫酸中逐滴加入氯化钡溶液

D. 盐酸中逐滴加入硝酸银溶液

我的答案：A（作答原卷填涂）　｜　参考答案：B　｜　得分：0 / 4（难度：中）

注：纸质卷第 4 页草稿（本题旁）：写有 HClHClHCl、NaOHNaOHNaOH、NaCl+H2ONaCl + H_2ONaCl+H2​O，并把 H++OH−=H2OH^{+} + OH^{-} = H_2OH++OH−=H2​O 整式圈起；对 B 项草写 MgSO4+Ba(OH)2=Mg(OH)2+BaSO4↓MgSO_4 + Ba(OH)_2 = Mg(OH)_2 + BaSO_4\downarrowMgSO4​+Ba(OH)2​=Mg(OH)2​+BaSO4​↓——中和路径完整演算，B 的两种沉淀也写对了。

参考答案与解析要点

参考答案 B。要点：

  • 判定标准："由亮变暗 → 熄灭 → 复亮"要求反应把溶液中的离子几乎全部移走（生成沉淀＋极弱电解质水），恰好反应点自由离子浓度趋近于零；随后过量试剂重新提供离子，灯复亮。
  • B 正确：MgSO4+Ba(OH)2=Mg(OH)2↓+BaSO4↓MgSO_4 + Ba(OH)_2 = Mg(OH)_2\downarrow + BaSO_4\downarrowMgSO4​+Ba(OH)2​=Mg(OH)2​↓+BaSO4​↓，Ba2+Ba^{2+}Ba2+ 沉走 SO42−SO_4^{2-}SO42−​、OH−OH^{-}OH− 沉走 Mg2+Mg^{2+}Mg2+，恰好反应时溶液里只剩水——熄灭；继续滴加的过量 Ba(OH)2Ba(OH)_2Ba(OH)2​ 使离子浓度回升——复亮。
  • A（学生所选）：H++OH−=H2OH^{+} + OH^{-} = H_2OH++OH−=H2​O 只消掉 H+H^{+}H+ 与 OH−OH^{-}OH−，溶液里留下 Na+Na^{+}Na+、Cl−Cl^{-}Cl−（生成可溶强电解质 NaCl）——灯变暗但不会熄灭。
  • C：Ba2++SO42−=BaSO4↓Ba^{2+} + SO_4^{2-} = BaSO_4\downarrowBa2++SO42−​=BaSO4​↓ 之后溶液中仍剩盐酸（H+H^{+}H+、Cl−Cl^{-}Cl−）——变暗不熄灭。
  • D：Ag++Cl−=AgCl↓Ag^{+} + Cl^{-} = AgCl\downarrowAg++Cl−=AgCl↓ 之后生成强电解质 HNO3HNO_3HNO3​——变暗不熄灭。

考点定位

  • 核心考点：溶液导电性的决定因素（自由移动离子的浓度与离子所带电荷数，而不是"有没有离子"）；离子反应与实验现象的对应（沉淀＋水 → 离子趋零；可溶盐或强酸残留 → 只降不清零）；复分解沉淀型离子方程式（Ba2++2OH−+Mg2++SO42−=BaSO4↓+Mg(OH)2↓Ba^{2+} + 2OH^{-} + Mg^{2+} + SO_4^{2-} = BaSO_4\downarrow + Mg(OH)_2\downarrowBa2++2OH−+Mg2++SO42−​=BaSO4​↓+Mg(OH)2​↓）。
  • 教材模块：人教版（2019）必修第一册·第一章 物质及其变化（第二节 离子反应：电解质的电离与离子反应）。
  • 能力层级：综合。

缺漏诊断

  1. 导电性概念停在"有没有离子"，没到"离子浓度多大"——证据：草稿把 H++OH−=H2OH^{+} + OH^{-} = H_2OH++OH−=H2​O 圈起后即选 A；A 项中和后 Na+Na^{+}Na+、Cl−Cl^{-}Cl− 仍大量存在，灯不可能熄灭。把"消掉一对离子"当成了"消掉了离子"。本题难度"中"而得 0 分，与草稿完整度形成反差，概念断层明确。
  2. 从方程式回推"离子浓度变化"的最后一步没走——证据：B 项草稿已正确写出 Mg(OH)2Mg(OH)_2Mg(OH)2​ 与 BaSO4BaSO_4BaSO4​ 两种沉淀，却未得出"恰好反应点只剩水 → 熄灭"；产物写对了、现象判断断了链。
  3. "沉淀之外还残留什么"未扫描——证据：C、D 两错项的共同设错结构是"沉淀掉一部分、留下强电解质"；作答时未对每项做全离子盘点。
