下列离子方程式中，正确的是（　）

A. 铜和硝酸银反应：Cu+Ag+=Cu2++AgCu + Ag^{+} = Cu^{2+} + AgCu+Ag+=Cu2++Ag

B. 稀硫酸滴到铜片上：Cu+2H+=Cu2++H2↑Cu + 2H^{+} = Cu^{2+} + H_2\uparrowCu+2H+=Cu2++H2​↑

C. 向澄清石灰水中通入过量的 CO2CO_2CO2​：CO2+OH−=HCO3−CO_2 + OH^{-} = HCO_3^{-}CO2​+OH−=HCO3−​

D. 碳酸氢钠与稀盐酸混合：CO32−+2H+=CO2↑+H2OCO_3^{2-} + 2H^{+} = CO_2\uparrow + H_2OCO32−​+2H+=CO2​↑+H2​O

我的答案：A（作答原卷填涂）　｜　参考答案：C　｜　得分：0 / 4（难度：中）

注：纸质卷第 3 页页顶草稿（对应本题 A、B 两项）：Cu+AgNO3=AgCu + AgNO_3 = AgCu+AgNO3​=Ag（末字划去）、H2SO4+Cu=CuSO4+H2↑H_2SO_4 + Cu = CuSO_4 + H_2\uparrowH2​SO4​+Cu=CuSO4​+H2​↑——对 A 项动笔验算过，但只写到化学方程式、未转入离子形式查守恒。

参考答案与解析要点

参考答案 C。要点：

  • C 正确：过量 CO2CO_2CO2​ 通入石灰水，终点产物是 HCO3−HCO_3^{-}HCO3−​；CO2CO_2CO2​ 保留分子式不拆、强碱拆成 OH−OH^{-}OH−——CO2+OH−=HCO3−CO_2 + OH^{-} = HCO_3^{-}CO2​+OH−=HCO3−​ 成立。
  • A（学生所选）错在电荷不守恒：左边 +1、右边 +2，电子转移数也不匹配；正确写法 Cu+2Ag+=Cu2++2AgCu + 2Ag^{+} = Cu^{2+} + 2AgCu+2Ag+=Cu2++2Ag。
  • B 错在反应事实：Cu 金属活动性排在 H 之后，与稀硫酸不发生反应。
  • D 错在拆分原则：NaHCO3NaHCO_3NaHCO3​ 是弱酸酸式盐，电离出的是 HCO3−HCO_3^{-}HCO3−​，不能拆成 CO32−CO_3^{2-}CO32−​；应为 HCO3−+H+=H2O+CO2↑HCO_3^{-} + H^{+} = H_2O + CO_2\uparrowHCO3−​+H+=H2​O+CO2​↑。
