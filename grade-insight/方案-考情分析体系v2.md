## 2. 设计目标与原则

1. **从"丢了多少分"到"为什么丢、丢在哪个知识节点、怎么补"**——四层模型递进。
2. **规则驱动、确定性**：错因标注是"证据引用型"AI 输出（附解析依据句）+ 人工复核；结论文本仍全部规则生成，禁止 LLM 即兴（SPEC-006 纪律延续）。
3. **缺源不研判、诚实降级**：无 KP/无解析/无错因的科目显式声明"未标注≠无问题"（SPEC-006 AC3 口径延续）。
4. **向后兼容**：gi-exam-data/1 旧件全兼容（v2 字段全 optional）；R1–R7 冻结，只增不改。
5. **移动端优先**：承接 SPEC-006 v5–v8 全套纪律（触控 ≥44px、320 无横向溢出、tab 短标签、touch-action:pan-y）。
6. **家长可读**：内部编号（C1–C6/R1–R7/D/E/A）不外露，图自解释（AC8 口径延续）。
7. **无新依赖**：ECharts 已在 vendor。

## 3. 数据层设计

### 3.1 gi-exam-data/2（增量，向后兼容）

```jsonc
// questions[] 增量字段（全 optional，v1 件缺省合法）
{
  "no": 8, "type": "单选题", "point": 5, "diff": "易", "score": 0,
  "analysisRef": "md/数学-试卷解析 (8).md",        // v1 已有
  "cause": "C4",                                    // v2 新增：错因代码（见 §4）
  "causeNote": "把对称轴判断为 x=0，距离比较思路未展开" // v2 新增：≤40字依据短句
}
// kps[] 增量字段
{
  "kpId": "kp-0001", "name": "函数的对称性", "rate": 0, "wrong": 1, ...,
  "kpKey": "math::函数的对称性",                     // v2 新增：全局稳定键（§3.2）
  "qNos": [8, 14]                                   // v2 新增：关联题号（KP↔题目映射）
}
```

- 契约版本在 `meta.contract` 标 `gi-exam-data/2`；读取端对 v1/v2 双兼容。
- integrity 新增校验：`cause 覆盖率`（有解析的错题应 100% 有 cause 或显式 C6）、`kp.qNos ↔ questions 双向一致`。

### 3.2 KP 全局字典（pipeline/kp-dictionary.json，schema gi-kp-dict/1）

```jsonc
{
  "schema": "gi-kp-dict/1", "version": 1,
  "subjects": {
    "math": [
      { "key": "math::函数的对称性", "name": "函数的对称性",
        "aliases": ["函数的对称性（北师）"], "firstExam": "ex-2026-10-10", "chapter": null }
    ]
  }
}
```

- **归一化规则**（固化进 DATA-CONTRACT）：去除"【重点】"前缀与括注来源（如"（北师）"）、生物层级路径取叶子名、去首尾空白——同名即同 KP；别名表兜底转写差异。
- converter 产出 exam.json 时按 `(subject, 归一化名)` 查字典回填 kpKey，新 KP 自动注册；字典随项目 git 跟踪、可人工审校。
- 首版登记：数学 51 条 + 生物 21 条（含"长截图拼接接缝处重复行"这类脏名的处置：识别为拼接瑕疵 → 并入真名 KP，登记 alias）。

### 3.3 跨考联合数据（pipeline/joint.js → js/joint-data.js，schema gi-joint/1）

```jsonc
window.GI_JOINT = {
  "schema": "gi-joint/1", "generatedAt": "...", "kpDictVersion": 1,
  "exams": [ // 仅收有 dataRef 且 exam.json 可读的考
    { "examId": "ex-2026-10-10", "date": "2026-10-10",
      "subjects": { "math": {
        "kps":   [{ "kpKey": "math::函数的对称性", "rate": 0, "wrong": 1 }],
        "causes": { "C1": 0, "C2": 30, "C3": 0, "C4": 5, "C5": 0, "C6": 0 }, // 丢分分解
        "wrongQuestions": [ { "no": 8, "point": 5, "score": 0, "diff": "易",
                              "cause": "C4", "kpKeys": ["math::函数的对称性"],
                              "analysisRef": "md/数学-试卷解析 (8).md" } ]
      } }
    }
  ],
  "kpTimeline": { "math::函数的对称性": [ { "examId": "...", "rate": 0 } ] }
}
```

- **形态选型**：JS 全局（`<script src="js/joint-data.js">`）而非运行时 fetch——file:// 亦可、无缓存/路径坑（SPEC-006 B5 踩坑先例）、与 data.js 快照同模式；文件头注明"由 pipeline/joint.js 生成，勿手改"。
- **确定性**：输入=各考 data/exam.json + kp-dictionary；输出幂等；GI_JOINT 缺失时引擎自动降级单考模式（不阻塞站点）。

- 沿用"缺源不研判"；新增 cause 覆盖率与 qNos 一致性校验（§3.1）；

## 4. 错因模型（pipeline/CAUSE-TAXONOMY.md v1，固化件）

| 代码 | 名称（对外文案） | 判定要点 | 可补性权重 w |
|---|---|---|---|
| C1 | 概念没吃透 | 知识点本身未掌握/记忆缺失（解析涉及定义定理不会用） | 0.6 |
| C2 | 方法不会用 | 思路/技巧欠缺：读完解析能懂、独立做不出 | 0.6 |
| C3 | 算错了 | 思路正确，运算/书写笔误 | 0.9 |
| C4 | 看错了题 | 审题偏差：漏条件/看错问/答非所问 | 0.9 |
| C5 | 步骤丢分 | 主观题部分分：过程不完整/表述不规范/跳步 | 0.6 |
| C6 | 待标注 | 解析缺失或证据不足（诚实桶，不强行归类） | 0.5 |

- **判定流程**：AI 转写预判（transcribe-prompt v2 新增错因标注任务：输入=题干+我的答案+参考答案+解析，输出=cause+causeNote+解析依据句）→ **人工复核**（复核清单 `details/<考>/md.错因复核-<科>.md`：逐题预判+依据+确认列；确认后回写 exam.json）。
- **口径纪律**：错因是推断不是事实——报告、图、tooltip 一律标注"AI 预判+人工复核"；难题+C3（罕见组合）复核时强制二次确认。
- 与 SPEC-010（数据文件身份信息脱敏，in-progress）对齐：复核件不新增身份信息，若 SPEC-010 裁定 details 脱敏则复核件随其口径执行。

## 5. 分析模型（四层；ANALYZE-RULES.md 升 v2）

```
L1 现状层（冻结保留）  三重归一 + R1–R7 + 既有仪表盘全部组件
L2 题级诊断层（新增）
  D1 难度×题型九宫格   每科丢分按 (易/中/难)×(单选/多选/主观/作文) 交叉定位
  D2 错因构成          每科丢分按 C1–C6 分解；无 cause 科整桶"待标注"
  D3 KP 四象限         X=KP 关联丢分(qNos 求和) × Y=掌握率；重点 KP 星标
L3 跨考演化层（数据到位自动激活）
  E1 KP 演化           kpTimeline 跨考折线；掌握率回落 ≥15pp → 回落告警
  E2 顽固薄弱点        连续 ≥2 考 薄弱/待提升 的 KP → 优先级 ×1.3（stubbornBoost）
  E3 跨考错题本        GI_JOINT.wrongQuestions 聚合，科目/KP/错因/难度筛选
L4 行动层（升级）
  A1 补救优先级 v2     回收估 = 沿用 R2/R3/R6 口径 × w(cause) × (顽固 ×1.3)；难题档 ×0.3
  A2 复习计划生成器    确定性 4 周计划（见下）
```

**A2 复习计划生成器（确定性规则，RULES v2 固化）**：

- 第 1 周「止血」：R2 易题错题全清单重练 + C3/C4 类错题（可补性最高）；
- 第 2–3 周「主攻」：B 区中档主战场按 KP 群组推进——四象限右上区（丢分多·未掌握）优先，顽固薄弱加权；每 KP 配错题重练清单；
- 第 4 周「验收」：本期重练清单 topN 回测 + 仍未掌握 KP 转入下期计划；
- 每项含：KP 群、重练题清单（题号 + analysisRef 链接直达解析）、预估回收（A1 口径）、资源指向（md 解析 / data/analysis html / raw 原卷）；
- 单考数据即生成第 1–4 周框架；跨考数据到位后 E2 加权自动生效。
