## 2. 标题参数化（子站无关）

模板里凡是「站点名 / 记录章节名」这类会随子站变化的文案，已抽成两个占位令牌，**不再写死「四季景点 / 游记」**：

| 令牌 | 含义 | 四季景点取值 | 生活点滴取值 |
|------|------|--------------|--------------|
| `{{SITE_LABEL}}` | 子站显示名（页脚、移动端返回导航） | `四季景点` | `生活点滴` |
| `{{RECORD_HEADING}}` | 记录章节标题（顶部导航 + `#log` 大标题） | `游记实录` | `生活实录` |

> 其它 `{{...}}` 是内容占位符（标题、日期、同行人等），与子站无关，照常填。
> 换肤只需改 `:root` 的 `--accent / --accent2 / --hero-grad` 三处（暖金为记录默认，生活点滴可改冷色/其他色相）。

**生活点滴的标题约定（请确认）**：`{{RECORD_HEADING}}` 用「生活实录」还是「点滴实录」？模板默认按「生活实录」演示；若你偏好「点滴实录」，建记录时直接写该词即可（纯文本，无需改模板）。

## 3. 引用规则（各子站如何复用，避免冗余）

1. **单一来源**：模板只存在于 `home/src/`。任何子站**不要**再在自家目录里放一份 `site-template*.html` 副本。
2. **新建一条记录**（以纯记录型为例）：
   - 复制 `home/src/site-template-travelogue.html` → `<子站>/<记录目录>/index.html`
     - 例：`四季景点/老表大岗周末家庭游/index.html` 或 `生活点滴/2026/0816/index.html`
   - 把 `home/src/assets/ph*.svg` 换成该记录的真实图片（主图命名 `index.*` 放画廊首位，不命名也会自动取第一张），图片与 `index.html` 同目录。
   - 填占位符：先填 `{{SITE_LABEL}}` / `{{RECORD_HEADING}}`（按上表映射），再填其余 `{{...}}`。
   - 顶部导航首条为 `← 返回`（链接到子站首页 `../index.html`）。
3. **记录核心模块绝不本地另写**：`.log-chapter` / `.food-card` 的源码来自 `site-template-travelogue-core.html`（COPY BLOCK 三段约定）。要改样式/结构，**改这里（`home/src` 的核心文件），再重新复制 COPY BLOCK 到用到的模板**，禁止在各子站本地漂移一份。
4. **改模板要回流**：在子站实践时发现模板需要增强，请改 `home/src` 的源文件，再重新复制到受影响的子站页面，保持单一来源。
5. **自动化填充（可选）**：`home/src/gen_travelogue.py` 是「复制模板 + 填占位符」的自动化实现——读取 `home/src/site-template-travelogue.html`，读懂 `<记录目录>/README.MD` 的 `## 实录` 分段与日期/简介，扫描该目录真实媒体（按文件名时间戳自然归章），产出静态 `index.html`。用法：`python home/src/gen_travelogue.py <YYYY>/MMDD`（在 `home/` 下运行）。**产物仍是静态 HTML（非运行时动态），与手动复制模板填占位符完全等价**；手动方式同样有效，按团队习惯选。
   - **README 是「叙事底稿 / 组织线索」，不是页面内容源**：`## 简介` 内若夹带 ```` ```markdown ```` 围栏长文（如某篇背景文章），生成器**剥离**该围栏块、不当作页面内容显示（绝不「开篇照搬」原样 markdown）。该素材若要呈现，由作者按模板「美食 & 随手发现」卡片手工组织。
   - **章节切割规则（对齐 四季景点 AGENTS.md §14.5 / §14.6）**：`.log-chapter` 的时间锚点来自 README 的 `### HH:MM 标题`（作者裁剪好的时间窗 + 标题 + 叙述）；每个媒体文件按**自身文件名时间戳**归入最近的锚点章——即「按 readme.md 与图片/视频文件的时间共同切割」。§14.6.2 R5：无真实素材支撑且非显式文本章的章节不产出。

### COPY BLOCK 三段约定（记录核心模块）
| 段 | 内容 | 粘贴到 |
|----|------|--------|
| `COPY BLOCK 1/3` | `.log-chapter` / `.food-card` 家族 CSS | 目标模板 `<style>` 内任意位置 |
| `COPY BLOCK 2/3` | `#log` + `#food` 两个 section 的 HTML 骨架 | 目标模板 `<body>`（攻略型放在「行程方案」之后） |
| `COPY BLOCK 3/3` | 入场动画选择器扩展（把 `.log-chapter, .food-card` 并入已有 reveal 选择器） | 目标模板已有 `<script>` 的 reveal 选择器 |

## 4. 配图组件通用规则：首图自动解析（index.* 优先，缺失回退）

两个模板的 `.media-block` / `.culture-card` / `.timeline-content` 共用同一套画廊逻辑：

- **数据源是画廊**：每个需要图片的卡片，把该卡片对应的「图片文件夹里的全部图片」列进 `.media-gallery`（含 `index.*` 若有）。
- **首图自动选**：JS 加载时自动解析主图（`.media-cover`）——
  - 画廊中**命名 `index.*` 的图优先作主图**（index.jpg / index.png / INDEX.webp 都认）；
  - 若**漏命名 `index.*`**，回退为画廊第一张——兼容缺失，不会空白。
- **不重复展示**：当前主图会从缩略图条隐藏；点击任意缩略图即切换为主图（原主图重新回到条中）。
- **单图场景**：画廊只有一张图时，缩略图条自动隐藏，仅显示主图。
- **切换不丢首图**：`index.*` 缺失时仍按第一张稳定展示。

> 直接改 HTML 里 `<img class="media-cover">` 的 `src` **不会**生效——首图由 JS 从画廊推导。要定首图，请在画廊里正确命名 `index.*` 或调整顺序。

## 7. 深色主题文字对比度硬规则（防回归）

> 提炼自 2026-08-18 三轮"文字看不见"修复。以下规则对**所有深色主题 HTML 页面**强制执行。

### 7.1 CSS 变量声明行尾必须有分号

- `:root` 块内**每个变量声明行尾必须有 `;`**。
- **曾因 `--hero-grad` 行漏 `;`**，CSS 解析器把下一行 `--text: #ffffff;` 当作 `--hero-grad` 值的一部分吞掉 → `--text` 未定义 → `color: var(--text)` 回退到浏览器默认**黑色** → 全页文字在深色背景上完全不可见。
- 生成器（`gen_travelogue.py`）做字符串替换换肤时，**替换值必须保留结尾 `;`**（曾因 `HERO_GRAD` 常量漏 `;` 导致此 bug）。
- 校验方法：读生成文件的 `:root` 块，逐行确认不以 `;` / `}` 结尾的行（注释行除外）。

### 7.2 文字颜色用不透明 hex，禁止 rgba 透明度

- `--text` / `--text-dim` / `--text-hint` **必须用不透明 hex**（如 `#ffffff`、`#f0f3f8`），**禁止 `rgba(...,0.X)`** 透明度写法。
- 半透明文字（如 `rgba(232,236,244,0.62)`）在深色背景上视觉等同"深色文字"，用户报"看不见"。
- 当前正确值：`--text: #ffffff` / `--text-dim: #f0f3f8` / `--text-hint: #c8d0dc`。

### 7.3 正文段落用 `var(--text)`，不用 `var(--text-dim)`

- 以下选择器的 `color` **必须用 `var(--text)`（全亮）**，不得降级为 `var(--text-dim)`：
  `.section-desc` / `.log-chapter p` / `.food-card p` / `.tips-box li` / `.info-card p, .info-card li` / `.hero-quick span`
- `var(--text-dim)` 仅用于**非正文次要标注**：`footer` / `.log-video-cap` / `.media-caption` 等。

## 8. 媒体画廊功能规范（模板 JS 已内置）

> 纯记录型 / 攻略型模板的 `.media-block` 组件已内置以下 4 项功能，由 JS 动态注入，生成器无需改 HTML。

| 功能 | 说明 |
|------|------|
| 首图自动解析 | 画廊中命名 `index.*` 的图优先作主图；缺失回退第一张 |
| **图片名称标题** | 主图上方动态插入 `.media-caption`，绑定 `thumb.alt`（取自文件名中文主题），每次切换同步更新 |
| **左右切换** | 多图时动态创建 `.media-nav-btn` 圆形箭头（prev/next）覆盖在主图两侧；支持**点击**、**键盘 ← →**、**触摸滑动**（横向 >45px）三种方式循环切换 |
| 竖屏自适应 | `syncOrient()` 按图片真实方向给容器加 `.img-portrait` 类，避免裁切 |

**生成器责任**：确保每个 `<img>` 的 `alt` 属性包含有意义的中文场景描述（从文件名提取主题词），因为该 `alt` 会作为大图标题显示。`gen_travelogue.py` 的 `humanize()` 函数已自动从文件名剥离时间戳/地点前缀，提取主题词作为 `alt`。
