# 高考完全指南：从高一到大学录取

> 适用对象：刚结束中考、即将升入高中的同学（以广东省"3+1+2"新高考模式为范本）
> 说明：高考政策逐年微调，**一切以当年广东省教育考试院发布的《招生专业目录》《志愿填报指南》为准**。本文帮你建立完整认知框架，避免信息差。

---

## 一、为什么现在就要了解高考

你可能觉得：刚中考完，高考还有三年，急什么？

恰恰相反。**高考和你们熟悉的中考，本质完全不同：**

| 维度 | 中考 | 高考 |
|------|------|------|
| 决策复杂度 | 志愿相对简单，主要看分数排位 | 选科、专业、院校、城市、批次，环环相扣 |
| 关键节点 | 基本集中在初三下 | 贯穿高中三年（选科在高一/高二，强基/综评报名在高三上） |
| 信息差影响 | 较小，规则透明 | **极大**，很多人输在不了解路径而非分数不够 |
| 容错空间 | 有补录、中职等多条退路 | 一锤定音色彩更浓，退档代价高 |

**结论：** 高中三年最大的"隐性考试"是**信息战**。提前三年建立框架，你才能在高一选科、高二分流、高三冲刺时做出不后悔的决策。

## 二、高考是什么（基础认知）

### 2.1 一句话定义

普通高考（普通高等学校招生全国统一考试）是合格的高中毕业生参加的选拔性考试，成绩是绝大多数中国学生进入本科/专科院校的主要依据。

### 2.2 广东新高考"3+1+2"模式

广东自 **2021 年起**实行新高考，模式为 **"3+1+2"**：

```
┌─────────────────────────────────────────────────────────────┐
│  3  （必考，原始分）                                          │
│     语文(150) + 数学(150) + 外语(150)                        │
│                                                             │
│  1  （首选，2选1，原始分）                                    │
│     物理(100) 或 历史(100)                                  │
│                                                             │
│  2  （再选，4选2，等级赋分）                                  │
│     化学 / 生物 / 思想政治 / 地理  中选 2 门，各 100         │
└─────────────────────────────────────────────────────────────┘
                        总分 = 750
```

**关键规则：**

- **物理类 / 历史类 分开划线、分开投档、分开录取。** 你选了物理就是"物理类考生"，选了历史就是"历史类考生"，两类考生互不影响、分别竞争。
- 传统的"文科/理科"已取消，但物理类 ≈ 原理科大范畴，历史类 ≈ 原文科大范畴。
- 外语：广东英语科总分 150，**含听说考试 20 分**（笔试 130 + 听说 20），听说考试一般在高三上学期（约 3 月）单独进行。其他语种（日语、俄语等）无听说。

### 2.3 分数构成一览

| 科目 | 分值 | 计分方式 | 备注 |
|------|------|----------|------|
| 语文 | 150 | 原始分 | |
| 数学 | 150 | 原始分 | 物理类/历史类同卷 |
| 外语 | 150 | 原始分 | 含听说 20 分（英语） |
| 物理 或 历史 | 100 | 原始分 | 首选科目 |
| 再选科目① | 100 | **等级赋分** | 化学/生物/政/地 4选2 |
| 再选科目② | 100 | **等级赋分** | |
| **合计** | **750** | | |

### 2.4 等级赋分制（必须理解！）

再选科目（化/生/政/地）**不直接用卷面分，而是按排名转换**。原因：四科难度不同，直接比原始分不公平。

转换规则（以广东为例）：

| 等级 | 人数比例 | 赋分区间 |
|------|----------|----------|
| A | 约 15% | 100 ~ 86 |
| B | 约 35% | 85 ~ 71 |
| C | 约 35% | 70 ~ 56 |
| D | 约 13% | 55 ~ 41 |
| E | 约 2% | 40 ~ 30 |

> 含义：哪怕某科卷面只考了 60 分，只要排名靠前，赋分后可能变成 80+；反之亦然。**再选科目拼的是"相对排名"而非绝对分数。**

## 三、高中学业水平考试（学考）

很多人误以为"高考成绩"就是全部。实际上，高中还有一套**学业水平考试（学考）**，分两类：

### 3.1 合格性考试（合格考）

- 科目：语文、数学、外语、思想政治、历史、地理、物理、化学、生物、信息技术、通用技术、音乐、美术、体育与健康（共 14 门）。
- 作用：**毕业前提 + 录取参考**。不合格可能影响高中毕业，部分特殊招生（如综评）看合格考等级。
- 时间：一般从高一期末开始分批考，不合格可补考。

### 3.2 选择考（选考）

- 即上面"3+1+2"中的"1+2"四门（物理/历史 + 两门再选），在高考时一并考试、计分。
- 选考科目必须已在合格考中"合格"，才能作为高考选考科目。

> **一句话：** 合格考保证你"能毕业、能报考"，选考决定你"高考怎么算分"。

## 四、高中三年路线图

### 高一：探索与奠基（最关键的一年）

- **适应节奏**：高中知识量、难度陡增，先稳住语数外基础。
- **物色选科方向**：
  - 理工农医、计算机、电子信息等 → 必选**物理**；
  - 人文社科、法学、经管部分 → 多走**历史**；
  - 医学、生物类专业常要求"物+化"组合。
- **常见组合参考**：
  - 物化政 / 物化地（覆盖专业最广，约 95%+）
  - 物化生（传统理科，医学友好）
  - 史政地（传统文科）
  - 史政生（偏文但保留部分理工通道）
- **拓展视野**：参加学科竞赛、社团、科创活动，为高二综评/强基积累素材。

### 高二：分化与深化

- **确定选科组合**并锁定（一般高二上完成分班）。
- **主攻选考科目深度**，这是赋分竞争的战场。
- **关注特殊招生苗头**：
  - 竞赛获奖（数理化生信奥赛）→ 强基/保送敲门砖；
  - 研究性学习、社会实践 → 综评材料。
- 合格考剩余科目争取一次性通过。

### 高三：冲刺与决胜

- **上学期**：
  - 英语听说考试（约 3 月）；
  - 期中/期末（第一次接近高考难度）；
  - **11 月前后**：强基计划、综合评价招生简章陆续发布，开始报名准备。
- **下学期**：
  - 一模（约 2-3 月）、二模（约 4 月）、三模（约 5 月）—— 定位全省排位；
  - **6 月 7、8、9 日**：高考（广东考 3 天，9 日为再选科目）；
  - **6 月 25 日前后**：出分、公布省控线、一分一段表；
  - **6 月底 ~ 7 月初**：填报志愿；
  - **7 月**：投档录取、征集志愿。

## 五、关键考试与时间轴（全年大事记）

| 时间 | 事件 | 意义 |
|------|------|------|
| 高三上 3 月 | 英语听说考试 | 占外语 20 分 |
| 高三上 11 月 | 强基/综评简章发布 | 特殊路径报名起点 |
| 高三下 2-3 月 | 一模 | 首次全省定位 |
| 高三下 4 月 | 二模 | 修正志愿预期 |
| 高三下 5 月 | 三模 | 考前状态校准 |
| **6 月 7-9 日** | **高考** | 核心一仗 |
| 6 月 25 日前后 | 出分 + 省控线 + 一分一段表 | 志愿填报依据 |
| 6 月底-7 月初 | 志愿填报 | 录取关键决策 |
| 7 月 | 投档、录取、征集志愿 | 尘埃落定 |

> 中考你只熟悉"考试→填志愿→录取"三步走；高考是**长周期、多战役、路径并行**的体系战。

## 六、多元升学路径（不只看分数）

很多人以为"高考 = 6 月那场考试 + 填志愿"。实际上，通往大学的路至少有以下几条，它们**并行存在**，越早知道越主动：

### 6.1 普通高考统招（主路径）

占绝大多数，按高考成绩 + 志愿填报录取。

### 6.2 强基计划（39 所双一流高校）

- 面向**基础学科**（数学、物理、化学、生物、历史、哲学、古文字学等）。
- 流程：高三下报名 → 高考 → 校测（笔试+面试+体测）→ 录取。
- 录取原则：**高考成绩占 85% 以上**，校测占其余，破格入围（竞赛金奖等）。
- 特点：本硕博衔接培养，低分上名校机会，但专业锁定、转专业受限。

### 6.3 综合评价录取（广东多校参与）

- 代表院校：中山大学、华南理工大学、南方科技大学、浙江大学、北京外国语大学、香港中文大学（深圳）、北师港浸大（UIC）、西交利物浦、上海纽约大学、昆山杜克、深圳北理莫斯科等。
- 典型"631"模式：**高考 60% + 校测 30% + 学考 10%**（各校比例不同）。
- 适合：综合素质强、有特长或面试能力好的同学，是"降分进名校"的重要通道。

### 6.4 专项计划（面向农村/脱贫地区）

- **国家专项**：面向脱贫地区（广东考生多数不符合条件）。
- **地方专项**：广东面向符合条件的农村户籍考生，可降分录取省内重点高校。
- **高校专项**：面向农村学生，由教育部直属高校等单独招生。

### 6.5 保送生

- 外国语学校优秀学生、五大学科奥赛国家集训队成员等，可免高考保送。
- 普通考生基本与此无缘，但竞赛路线值得天赋型学生关注。

### 6.6 艺术 / 体育类

- 需参加省级统考（或校考）+ 文化高考，按综合分录取。
- 文化分要求相对低，但专业训练强度大、不确定性高。

### 6.7 军队 / 公安 / 师范 / 医学定向

- 军校、公安院校（提前批，有政审体检）；
- **公费师范生 / 卫生专项**：免学费、包就业，但需定向服务若干年。

### 6.8 港澳及中外合作办学

- 港澳高校（港大、港中文、澳大等）可独立报名，与高考志愿不冲突；
- 中外合作办学（如西交利物浦、宁诺、上纽）走综评或统招。

> **策略提示：** 强基、综评、专项的报名材料（自述、获奖、实践证明）需要**高一高二提前积累**，高三临时抱佛脚基本来不及。

## 七、志愿填报：录取的核心环节

志愿填报的重要性不亚于考试本身。每年都有高分滑档、退档的案例。

### 7.1 必须懂的核心概念

| 名词 | 含义 |
|------|------|
| **省控线（批次线）** | 各批次录取的最低资格线（如本科线、特殊类型招生线），过线才有对应批次投档资格 |
| **一分一段表** | 显示"每一分有多少人、累计排位多少"，是定位自己全省位次的核心工具 |
| **位次（排名）** | 比绝对分数更可靠——每年试卷难度不同，但院校录取的"位次区间"相对稳定 |
| **院校专业组** | 广东志愿单位：同一院校按选科要求把专业打包成"组"，你按组填报 |
| **退档** | 投档进某院校专业组后，因不服从调剂/身体条件/单科成绩等被退回，本批次其余志愿失效 |
| **滑档（掉档）** | 所有填报的志愿都没投出去（分数不够），只能等征集志愿或下一批次 |

### 7.2 平行志愿规则（广东本科批）

核心三句话：**分数优先、遵循志愿、一轮投档。**

- **分数优先**：系统按全省排位从高到低依次处理，高分者先挑。
- **遵循志愿**：轮到你时，按你填的 1→2→3… 顺序检索，第一个够线的组就投出。
- **一轮投档**：每批次**只有一次投档机会**。一旦投出，本批次后续志愿作废；若被退档，只能走征集志愿或下一批。

> 广东本科批一般可填 **45 个院校专业组志愿**，每个组可填 6 个专业 + 是否服从调剂。**务必勾选"服从调剂"以降低退档风险**（除非坚决不接受某些专业）。

### 7.3 录取批次（简化）

1. **提前批本科**：军检、非军检、教师专项、卫生专项、强基、综评等。
2. **本科批次**：普通类主体（45 个专业组志愿）。
3. **提前批专科 / 专科批次**：高职高专。

### 7.4 填报策略（通用）

- **冲稳保梯度**：前 1/3 冲高（略高于自己位次）、中 1/3 稳妥（匹配位次）、后 1/3 保底（明显低于位次）。
- **以位次定校，不以分数定校**：查近三年目标院校专业的录取位次区间。
- **读懂选科要求**：每个专业组对再选科目有要求（如"物+化"），不符合不能报。
- **研究专业内涵**：同名专业不同学校方向差异大，别只看名字。

## 八、录取流程与时间

```
高考 → 出分/位次 → 填志愿 → 省考试院投档 → 高校阅档 → 录取/退档
                                  │
                         退档 → 征集志愿（补录）→ 下一批次
```

- **投档**：考试院按规则把档案投给院校专业组。
- **阅档/录取**：高校审核专业、身体条件等，决定录取或退档。
- **征集志愿（补录）**：某批次未完成计划，向未录取考生再次开放填报，常是"捡漏"机会，但剩余多为冷门或高学费专业。
- **录取通知书**：7 月底至 8 月陆续发放。

## 九、给高一新生的行动清单

**现在（暑假 + 高一上）就能做的：**

1. **研究选科**：结合兴趣、优势学科、目标专业倒推选科组合（推荐先想"我想学什么专业"）。
2. **建立信息源**：关注「广东省教育考试院」官网/官微、《广东教育考试》等权威渠道。
3. **保持语数外领先**：这三科 450 分是基本盘，永远不嫌早。
4. **适度拓展**：竞赛、科创、志愿服务、研究性学习——为综评/强基埋点。
5. **了解路径**：每年抽空看几所目标大学的招生简章，知道"别人怎么录的"。

**常见误区：**

- ❌ "等高三再想志愿" → 选科错一步，很多专业直接关上门。
- ❌ "只看分数不看位次" → 分数会通胀/通缩，位次才稳。
- ❌ "不服从调剂更保险" → 反而大大增加退档风险。
- ❌ "只知道统招一条路" → 强基/综评/专项是大量"低分上名校"的合法通道。

## 附录 A：重要名词速查

- **3+1+2**：广东新高考科目结构（见 §2.2）。
- **首选科目**：物理或历史，二选一。
- **再选科目**：化/生/政/地，四选二，等级赋分。
- **赋分制**：再选科目按排名换算成 30~100 分的机制。
- **特殊类型招生控制线**：原"一本线"的近似参照，用于强基、综评、高校专项等资格线。
- **院校专业组**：广东志愿填报与投档的基本单位。
- **一分一段表**：定位全省排位的核心工具。
